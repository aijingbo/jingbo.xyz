# 景礴 Skill：化学理论杂志讲解

## Skill 信息

- **名称**：化学理论杂志讲解
- **类型**：杂志讲解型（Lecture）
- **学科**：化学
- **技术栈**：Canvas + CSS Animation

## 框架描述

生成一个杂志风格的化学理论讲解页面，左侧文字逐步讲解化学概念，右侧配以动态可视化。5-6 个步骤递进揭示，每步配合 CSS 动画或 Canvas 图表。适用于元素周期表演进史、化学平衡与勒夏特列原理等任何需要分步讲解的化学理论。暖色调排版，如同翻开一本精心设计的科学杂志。

## 布局规范

```
┌─────────────────────────────────────────────┐
│  [步骤导航条: 1─2─3─4─5─6]    [进度指示]      │
├──────────────────────┬──────────────────────┤
│                      │                      │
│   左侧文字讲解区       │   右侧可视化区        │
│                      │                      │
│   步骤标题             │   Canvas 动画        │
│   理论说明             │   CSS 动画演示       │
│   化学方程式           │   分子结构/图表      │
│   历史背景             │                      │
│                      │                      │
├──────────────────────┴──────────────────────┤
│  [上一步]                    [下一步]         │
└─────────────────────────────────────────────┘
```

- 顶部步骤导航条，显示当前步骤和总进度
- 左侧 50% 文字讲解区：步骤标题、理论说明、化学方程式、历史背景
- 右侧 50% 可视化区：Canvas 动画或 CSS 动画演示
- 底部前进/后退按钮，支持步骤切换
- 部分步骤右侧配有分子结构或图表

## 交互模式

1. **步骤前进/后退**：点击底部按钮或导航条步骤跳转
2. **动画播放/暂停**：右侧可视化区可控制动画播放状态
3. **参数调节**：部分步骤提供按钮调节反应条件，实时更新可视化
4. **元素悬停**：鼠标悬停元素或分子显示详细信息
5. **进度追踪**：导航条显示已完成的步骤，进度指示百分比

## 视觉风格

- **背景**：暖色象牙渐变 `linear-gradient(180deg, #f5ede0, #ede0cc)`
- **主色调**：赤陶色 `#c2410c`（标题、强调）、深炭灰 `#2d2d2d`（正文）
- **辅助色**：琥珀色 `#d97706`（步骤标记）、翠绿色 `#059669`（化学元素）
- **文字**：深炭灰 `#2d2d2d`，暖色背景上高对比度阅读
- **卡片背景**：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(8px)` + `border: 1px solid rgba(194,65,12,0.15)`
- **步骤导航**：已完成步骤填充琥珀色，当前步骤带脉冲动画
- **动画风格**：CSS 关键帧动画为主，配合 Canvas 粒子效果
- **字体**：标题使用衬线字体，正文使用无衬线字体，化学式使用等宽字体

## 数据输入格式

用户用自然语言描述要讲解的化学理论，例如：
- "讲解元素周期表的发展历史"
- "做一个化学平衡原理的讲解"

AI 应根据描述：
1. 确定要讲解的化学理论及其核心知识点
2. 将讲解拆分为 5-6 个递进步骤
3. 为每步设计左侧文字说明和右侧动态可视化
4. 使用 Canvas 或 CSS Animation 实现动画效果
5. 融入化学史和实验背景

## 内容结构要求

- 每个理论拆分为 5-6 个递进步骤
- 第一步：引入问题或历史背景
- 中间步骤：逐步揭示理论、实验验证
- 最后一步：总结与实际应用
- 每步文字 100-200 字，配合右侧可视化
- 化学方程式和分子结构准确呈现

## 动画与交互要求

```javascript
// 步骤切换动画
function goToStep(n) {
  // 左侧文字淡入淡出
  // 右侧可视化过渡动画
  // 更新导航条进度
}

// Canvas 动画循环
function animate() {
  requestAnimationFrame(animate);
  // 根据当前步骤渲染对应可视化
  // 支持播放/暂停控制
}
```

- 步骤切换时左侧文字平滑淡入淡出
- 右侧可视化随步骤切换过渡动画
- CSS 关键帧动画实现化学反应模拟
- 动画播放/暂停按钮控制自动演示

## 质量要求

1. 步骤导航流畅，切换无闪烁
2. 化学方程式和分子结构准确
3. 可视化动画流畅（目标 60fps）
4. 初始加载 < 2 秒
5. 支持响应式（移动端上下布局）
6. 内容准确、科学严谨、逻辑清晰
7. 纯单 HTML 文件，仅依赖 CDN
