# 景礴 Skill：高等微积分可视化

## Skill 信息

- **名称**：高等微积分可视化
- **类型**：杂志讲解型（Lecture）
- **学科**：数学
- **技术栈**：Canvas + MathJax
- **CDN**：
  - `https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js`

## 框架描述

生成一个杂志风格的知识讲解页面，左侧文字逐步讲解高等微积分核心概念，右侧配以动态可视化。5-6 个步骤递进揭示，每步配合动画或图表。适用于导数几何意义、黎曼和与定积分、泰勒级数展开等任何需要分步推导的微积分概念。暖色调排版，如同翻开一本精心设计的科学杂志。

## 布局规范

```
┌─────────────────────────────────────────────┐
│  [步骤导航条: 1─2─3─4─5─6]    [进度指示]      │
├──────────────────────┬──────────────────────┤
│                      │                      │
│   左侧文字讲解区       │   右侧可视化区        │
│                      │                      │
│   步骤标题             │   Canvas动画         │
│   概念说明             │   动态图表/曲线       │
│   公式推导             │   参数调节控件        │
│   关键洞察             │                      │
│                      │                      │
├──────────────────────┴──────────────────────┤
│  [上一步]                    [下一步]         │
└─────────────────────────────────────────────┘
```

- 顶部步骤导航条，显示当前步骤和总进度
- 左侧 50% 文字讲解区：步骤标题、概念说明、公式推导（MathJax 渲染）
- 右侧 50% 可视化区：Canvas 动态图表
- 底部前进/后退按钮，支持步骤切换
- 部分步骤右侧配有参数调节滑块

## 交互模式

1. **步骤前进/后退**：点击底部按钮或导航条步骤跳转
2. **动画播放/暂停**：右侧可视化区可控制动画播放状态
3. **参数调节**：部分步骤提供滑块调节参数，实时更新可视化
4. **公式高亮**：鼠标悬停公式时高亮对应可视化元素
5. **进度追踪**：导航条显示已完成的步骤，进度指示百分比

## 视觉风格

- **背景**：暖色象牙渐变 `linear-gradient(180deg, #f5ede0, #ede0cc)`
- **主色调**：赤陶色 `#c2410c`（标题、强调）、深炭灰 `#2d2d2d`（正文）
- **辅助色**：琥珀色 `#d97706`（步骤标记）、橄榄绿 `#65a30d`（公式高亮）
- **文字**：深炭灰 `#2d2d2d`，暖色背景上高对比度阅读
- **卡片背景**：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(8px)` + `border: 1px solid rgba(194,65,12,0.15)`
- **步骤导航**：已完成步骤填充琥珀色，当前步骤带脉冲动画
- **公式排版**：MathJax 渲染，公式区背景 `rgba(245,237,224,0.8)`
- **字体**：标题使用衬线字体，正文使用无衬线字体，代码/公式使用等宽字体

## 数据输入格式

用户用自然语言描述要讲解的微积分概念，例如：
- "讲解导数的几何意义，割线到切线的极限"
- "做一个黎曼和与定积分的可视化"
- "生成一个泰勒级数展开的讲解"

AI 应根据描述：
1. 确定要讲解的微积分概念及其核心知识点
2. 将讲解拆分为 5-6 个递进步骤
3. 为每步设计左侧文字说明和右侧动态可视化
4. 使用 MathJax 渲染数学公式
5. 使用 Canvas 实现交互式图表

## 内容结构要求

- 每个概念拆分为 5-6 个递进步骤
- 第一步：引入问题或直觉
- 中间步骤：逐步推导、可视化演示
- 最后一步：总结与拓展应用
- 每步文字 100-200 字，配合右侧可视化
- 公式使用 MathJax 正确渲染

- 步骤切换时左侧文字平滑淡入淡出
- 右侧可视化随步骤切换过渡动画
- 部分步骤支持参数滑块，实时更新可视化
- 动画播放/暂停按钮控制自动演示

## 质量要求

1. 步骤导航流畅，切换无闪烁
2. 数学公式渲染正确，排版美观
3. 可视化动画流畅（目标 60fps）
4. 初始加载 < 2 秒
5. 支持响应式（移动端上下布局）
6. 内容准确、逻辑严密、科学严谨
7. 纯单 HTML 文件，仅依赖 CDN
