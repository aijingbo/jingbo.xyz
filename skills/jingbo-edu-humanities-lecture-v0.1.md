# 景礴 Skill：社科人文杂志讲解

## Skill 信息

- **名称**：社科人文杂志讲解
- **类型**：杂志讲解型（Lecture）
- **学科**：地理 · 人文
- **技术栈**：Canvas + D3.js
- **CDN**：
  - `https://cdn.jsdelivr.net/npm/d3@7/dist/d3.min.js`

## 框架描述

生成一个杂志风格的跨学科社科知识讲解页面，左侧文字叙事知识脉络，右侧配以数据可视化。5-6 个步骤递进揭示，每步配合 D3.js 图表或 Canvas 动画。适用于全球变暖气候条纹、供需曲线、唐诗黄金时代等任何需要数据与人文交融的社科知识。暖色调排版，如同翻开一本精心设计的科学杂志。

## 布局规范

```
┌─────────────────────────────────────────────┐
│  [步骤导航条: 1─2─3─4─5─6]    [进度指示]      │
├──────────────────────┬──────────────────────┤
│                      │                      │
│   左侧文字讲解区       │   右侧可视化区        │
│                      │                      │
│   步骤标题             │   D3.js 图表        │
│   知识叙事             │   Canvas 动画       │
│   数据解读             │   时间轴/地图       │
│   人文背景             │                      │
│                      │                      │
├──────────────────────┴──────────────────────┤
│  [上一步]                    [下一步]         │
└─────────────────────────────────────────────┘
```

- 顶部步骤导航条，显示当前步骤和总进度
- 左侧 50% 文字讲解区：步骤标题、知识叙事、数据解读、人文背景
- 右侧 50% 可视化区：D3.js 数据图表或 Canvas 动画
- 底部前进/后退按钮，支持步骤切换
- 部分步骤右侧配有时间轴或地图

## 交互模式

1. **步骤前进/后退**：点击底部按钮或导航条步骤跳转
2. **动画播放/暂停**：右侧可视化区可控制动画播放状态
3. **数据筛选**：部分步骤提供按钮筛选数据维度，实时更新图表
4. **图表悬停**：鼠标悬停图表元素显示详细数据
5. **进度追踪**：导航条显示已完成的步骤，进度指示百分比

## 视觉风格

- **背景**：暖色象牙渐变 `linear-gradient(180deg, #f5ede0, #ede0cc)`
- **主色调**：赤陶色 `#c2410c`（标题、强调）、深炭灰 `#2d2d2d`（正文）
- **辅助色**：琥珀色 `#d97706`（步骤标记）、靛蓝色 `#4338ca`（数据元素）
- **文字**：深炭灰 `#2d2d2d`，暖色背景上高对比度阅读
- **卡片背景**：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(8px)` + `border: 1px solid rgba(194,65,12,0.15)`
- **步骤导航**：已完成步骤填充琥珀色，当前步骤带脉冲动画
- **图表风格**：D3.js 数据可视化，暖色调配色方案
- **字体**：标题使用衬线字体，正文使用无衬线字体，数据使用等宽字体

## 数据输入格式

用户用自然语言描述要讲解的社科人文知识，例如：
- "生成全球变暖气候条纹可视化"
- "做一个供需曲线经济学讲解"
- "讲解唐诗的黄金时代"

AI 应根据描述：
1. 确定要讲解的社科人文知识及其核心脉络
2. 将讲解拆分为 5-6 个递进步骤
3. 为每步设计左侧文字叙事和右侧数据可视化
4. 使用 D3.js 或 Canvas 实现交互式图表
5. 融入历史背景和人文 context

## 内容结构要求

- 每个知识点拆分为 5-6 个递进步骤
- 第一步：引入背景或核心问题
- 中间步骤：逐步展开数据、解读趋势
- 最后一步：总结与启示
- 每步文字 100-200 字，配合右侧可视化
- 数据准确，人文叙事生动

- 右侧可视化随步骤切换过渡动画

- 图表元素悬停显示详细数据

## 质量要求

1. 步骤导航流畅，切换无闪烁
2. 数据可视化准确、美观
3. 图表交互流畅（目标 60fps）
4. 初始加载 < 2 秒
5. 支持响应式（移动端上下布局）
6. 内容准确、数据可靠、叙事生动
7. 纯单 HTML 文件，仅依赖 CDN
