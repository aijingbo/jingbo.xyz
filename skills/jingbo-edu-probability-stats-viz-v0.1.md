# 景礴 Skill：概率统计可视化

## Skill 信息

- **名称**：概率统计可视化
- **类型**：杂志讲解型（Lecture）
- **学科**：数学
- **技术栈**：Canvas + D3.js
- **CDN**：
  - `https://cdn.jsdelivr.net/npm/d3@7`

## 框架描述

生成一个杂志风格的知识讲解页面，左侧文字逐步讲解概率统计核心概念，右侧配以动态可视化。5-6 个步骤递进揭示，每步配合动画或图表。适用于蒲丰投针实验、中心极限定理、概率分布等任何需要分步推导的统计概念。暖色调排版，如同翻开一本精心设计的科学杂志。

## 布局规范

```
┌─────────────────────────────────────────────┐
│  [步骤导航条: 1─2─3─4─5─6]    [进度指示]      │
├──────────────────────┬──────────────────────┤
│                      │                      │
│   左侧文字讲解区       │   右侧可视化区        │
│                      │                      │
│   步骤标题             │   Canvas/D3.js       │
│   概念说明             │   动态图表/模拟       │
│   公式推导             │   参数调节控件        │
│   关键洞察             │                      │
│                      │                      │
├──────────────────────┴──────────────────────┤
│  [上一步]                    [下一步]         │
└─────────────────────────────────────────────┘
```

- 顶部步骤导航条，显示当前步骤和总进度
- 左侧 50% 文字讲解区：步骤标题、概念说明、公式推导
- 右侧 50% 可视化区：Canvas 或 D3.js 动态图表与模拟
- 底部前进/后退按钮，支持步骤切换
- 部分步骤右侧配有参数调节滑块和模拟控制

## 交互模式

1. **步骤前进/后退**：点击底部按钮或导航条步骤跳转
2. **动画播放/暂停**：右侧可视化区可控制模拟动画播放状态
3. **参数调节**：部分步骤提供滑块调节参数，实时更新可视化
4. **模拟控制**：投针实验等可控制投针次数、速度
5. **进度追踪**：导航条显示已完成的步骤，进度指示百分比

## 视觉风格

- **背景**：暖色象牙渐变 `linear-gradient(180deg, #f5ede0, #ede0cc)`
- **主色调**：赤陶色 `#c2410c`（标题、强调）、深炭灰 `#2d2d2d`（正文）
- **辅助色**：琥珀色 `#d97706`（步骤标记）、橄榄绿 `#65a30d`（公式高亮）
- **文字**：深炭灰 `#2d2d2d`，暖色背景上高对比度阅读
- **卡片背景**：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(8px)` + `border: 1px solid rgba(194,65,12,0.15)`
- **步骤导航**：已完成步骤填充琥珀色，当前步骤带脉冲动画
- **图表配色**：D3.js 分类色板，与暖色背景协调
- **字体**：标题使用衬线字体，正文使用无衬线字体，代码/公式使用等宽字体

## 数据输入格式

用户用自然语言描述要讲解的概率统计概念，例如：
- "讲解蒲丰投针实验与π的估算"
- "做一个中心极限定理的可视化"
- "生成一个概率分布的交互式讲解"

AI 应根据描述：
1. 确定要讲解的概率统计概念及其核心知识点
2. 将讲解拆分为 5-6 个递进步骤
3. 为每步设计左侧文字说明和右侧动态可视化
4. 使用 D3.js 或 Canvas 实现交互式图表与模拟
5. 使用公式和统计数据支持讲解

## 内容结构要求

- 每个概念拆分为 5-6 个递进步骤
- 第一步：引入问题或直觉
- 中间步骤：逐步推导、可视化演示、模拟实验
- 最后一步：总结与拓展应用
- 每步文字 100-200 字，配合右侧可视化
- 统计数据与公式正确呈现

## 动画与交互要求

```javascript
// 步骤切换动画
function goToStep(n) {
  // 左侧文字淡入淡出
  // 右侧可视化过渡动画
  // 更新导航条进度
}

// Canvas/D3 动画循环
function animate() {
  requestAnimationFrame(animate);
  // 根据当前步骤渲染对应可视化
  // 支持模拟控制（投针、采样等）
}
```

- 步骤切换时左侧文字平滑淡入淡出
- 右侧可视化随步骤切换过渡动画
- 部分步骤支持参数滑块和模拟控制，实时更新可视化
- 动画播放/暂停按钮控制自动演示

## 质量要求

1. 步骤导航流畅，切换无闪烁
2. 统计图表渲染正确，排版美观
3. 可视化动画流畅（目标 60fps）
4. 初始加载 < 2 秒
5. 支持响应式（移动端上下布局）
6. 内容准确、逻辑严密、科学严谨
7. 纯单 HTML 文件，仅依赖 CDN
