# 景礴 Skill：生化模型模拟器

## Skill 信息

- **名称**：生化模型模拟器
- **类型**：交互工具型（Interactive Tool）
- **学科**：生物 · 化学
- **技术栈**：Canvas + p5.js
- **CDN**：
  - `https://cdn.jsdelivr.net/npm/p5@1.9.0/lib/p5.min.js`

## 框架描述

生成生化模型参数化模拟页面。通过调节实验参数（基因型、浓度、初始种群等），观察模型输出变化。适用于孟德尔遗传杂交、化学平衡移动、种群增长模型等任何需要数据驱动可视化的生化模型。

## 布局规范

```
┌─────────────────────────────────────────┐
│  [标题栏]                                │
├──────────────┬──────────────────────────┤
│              │                          │
│  实验参数面板  │      模型可视化画布        │
│  (基因型/浓度) │    (Canvas / p5.js)      │
│              │                          │
│  [实验控制]   │      [模型图形/数据]      │
│  [结果数据]   │      [图表/统计]          │
└──────────────┴──────────────────────────┘
```

- 左侧实验参数面板（固定宽度 280-320px），暖色浅底
- 右侧可视化画布自适应剩余空间，数据驱动
- 参数面板包含：基因型选择、浓度滑块、种群输入、实验控制按钮
- 可视化区域：模型图形、数据图表、统计结果

## 交互模式

1. **参数调节**：选择基因型、调节浓度、设置初始种群
2. **实验控制**：开始杂交、运行反应、模拟增长
3. **实时数据**：后代比例、平衡浓度、种群数量实时显示
4. **图表可视化**：庞氏表、浓度曲线、增长曲线动态绘制
5. **多代模拟**：支持多代杂交或多周期模拟

## 视觉风格

- **背景**：暖色浅底 `linear-gradient(135deg,#f0e8e0,#e6d8cc)`
- **主色调**：绿色系 `#059669`（交互工具标识）
- **参数面板**：`rgba(255,255,255,0.85)` + 柔和边框
- **可视化画布**：白色背景，清晰的模型图形与数据图表
- **强调色**：基因型红 `#ef4444`、显性绿 `#059669`、隐性蓝 `#3b82f6`
- **字体**：系统无衬线字体，标题 16px bold，数据 13px monospace

## 数据输入格式

用户用自然语言描述要生成的生化模型模拟，例如：
- "生成一个孟德尔遗传杂交模拟"
- "做一个化学平衡移动实验"
- "创建一个种群增长模型"

AI 应根据描述：
1. 确定要模拟的生化模型类型
2. 设计合适的实验参数（基因型、浓度、种群等）
3. 实现模型的数据驱动计算
4. 添加图表可视化与统计结果

## 参数控制要求

- 实验参数使用下拉选择、滑块、输入框等控件
- 模型计算结果以图表形式可视化（柱状图、曲线图、饼图等）
- 关键数据实时显示（比例、浓度、数量）
- 支持多代/多周期迭代模拟
