数学图形工具

参数化数学图形的实时交互工具——圆锥曲线、三角波形、函数绘图、分形几何、复利计算，拖动滑块即时看到图形变化，让抽象的数学关系变得直观可感。

这个技能做什么

数学图形工具是一个交互式参数化可视化框架，使用 Canvas 与 JSXGraph 实现数学图形的实时渲染。左侧参数控制面板提供滑块、输入框等控件，右侧可视化区域随参数变化即时重绘，让学生在"拖动-观察-理解"的循环中掌握数学规律。

核心特征

  • 实时参数化：滑块、输入框控制参数，图形随调节即时刷新
  • 暖色浅底布局：参数面板 + 可视化画布，清晰易读的工程化界面
  • 函数表达式解析：支持输入数学表达式实时绘制函数图像
  • 坐标系交互：滚轮缩放、拖拽平移，自由探索图形细节
  • 实时数据反馈：当前参数值、坐标、计算结果同步显示
  • 参数预设：一键恢复默认值，快速对比不同状态

适用场景

任何需要通过参数变化来理解数学关系的场景：圆锥曲线的离心率与形状关系、三角函数的振幅频率相位、任意函数的图像绘制、分形几何的迭代生成、复利计算的本金利率年限分析等。把"如果改变这个参数会怎样"的疑问，变成可操作、可观察的实时实验。

技术栈

  • Canvas 2D — 高性能图形绘制
  • JSXGraph（CDN 引入）— 交互式几何与函数绘图
  • requestAnimationFrame — 流畅的实时重绘
  • 纯单 HTML 文件，无构建依赖
