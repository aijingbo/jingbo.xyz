# 景礴 Skill：物理天文理论讲解

## Skill 信息

- **名称**：物理天文理论讲解
- **类型**：杂志讲解型（Lecture）
- **学科**：物理 · 天文
- **技术栈**：Canvas + CSS Animation

## 框架描述

生成一个杂志风格的物理与天文理论讲解页面，左侧文字叙事科学发现，右侧配以动态可视化。5-6 个步骤章节递进揭示，每步配合 CSS 动画或 Canvas 图表。适用于时间膨胀、电的发现史、宇宙大爆炸等任何需要叙事式讲解的物理天文理论。暖色调排版，如同翻开一本精心设计的科学杂志。

## 布局规范

```
┌─────────────────────────────────────────────┐
│  [步骤导航条: 1─2─3─4─5─6]    [进度指示]      │
├──────────────────────┬──────────────────────┤
│                      │                      │
│   左侧文字讲解区       │   右侧可视化区        │
│                      │                      │
│   章节标题             │   Canvas 动画        │
│   理论叙事             │   CSS 动画演示       │
│   关键公式             │   时间轴/示意图      │
│   历史背景             │                      │
│                      │                      │
├──────────────────────┴──────────────────────┤
│  [上一步]                    [下一步]         │
└─────────────────────────────────────────────┘
```

- 顶部步骤导航条，显示当前章节和总进度
- 左侧 50% 文字讲解区：章节标题、理论叙事、关键公式、历史背景
- 右侧 50% 可视化区：Canvas 动画或 CSS 动画演示
- 底部前进/后退按钮，支持章节切换
- 部分章节右侧配有时间轴或示意图

## 交互模式

1. **步骤前进/后退**：点击底部按钮或导航条步骤跳转
2. **动画播放/暂停**：右侧可视化区可控制动画播放状态
3. **时间轴拖拽**：部分章节支持拖拽时间轴查看不同阶段
4. **元素悬停**：鼠标悬停可视化元素显示详细说明
5. **进度追踪**：导航条显示已完成的章节，进度指示百分比

## 视觉风格

- **背景**：暖色象牙渐变 `linear-gradient(180deg, #f5ede0, #ede0cc)`
- **主色调**：赤陶色 `#c2410c`（标题、强调）、深炭灰 `#2d2d2d`（正文）
- **辅助色**：琥珀色 `#d97706`（章节标记）、深靛蓝 `#1e40af`（物理元素）
- **文字**：深炭灰 `#2d2d2d`，暖色背景上高对比度阅读
- **卡片背景**：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(8px)` + `border: 1px solid rgba(194,65,12,0.15)`
- **步骤导航**：已完成步骤填充琥珀色，当前步骤带脉冲动画
- **动画风格**：CSS 关键帧动画为主，配合 Canvas 粒子效果
- **字体**：标题使用衬线字体，正文使用无衬线字体，公式使用等宽字体

## 数据输入格式

用户用自然语言描述要讲解的物理或天文理论，例如：
- "讲解爱因斯坦的相对论时间膨胀"
- "做一个电的发现历史讲解"
- "生成宇宙大爆炸理论的可视化讲解"

AI 应根据描述：
1. 确定要讲解的物理或天文理论及其核心知识点
2. 将讲解拆分为 5-6 个递进章节
3. 为每章设计左侧文字叙事和右侧动态可视化
4. 使用 Canvas 或 CSS Animation 实现动画效果
5. 融入历史背景和科学发现过程

## 内容结构要求

- 每个理论拆分为 5-6 个递进章节
- 第一章：引入现象或历史背景
- 中间章节：逐步揭示理论、实验验证
- 最后章节：总结与现代应用
- 每章文字 100-200 字，配合右侧可视化
- 融入科学家的故事和发现过程

## 动画与交互要求

```javascript
// 步骤切换动画
function goToStep(n) {
  // 左侧文字淡入淡出
  // 右侧可视化过渡动画
  // 更新导航条进度
}

// Canvas 动画循环
function animate() {
  requestAnimationFrame(animate);
  // 根据当前章节渲染对应可视化
  // 支持播放/暂停控制
}
```

- 步骤切换时左侧文字平滑淡入淡出
- 右侧可视化随步骤切换过渡动画
- CSS 关键帧动画实现物理现象模拟
- 动画播放/暂停按钮控制自动演示

## 质量要求

1. 步骤导航流畅，切换无闪烁
2. 动画效果准确表达物理现象
3. 可视化动画流畅（目标 60fps）
4. 初始加载 < 2 秒
5. 支持响应式（移动端上下布局）
6. 内容准确、科学严谨、叙事生动
7. 纯单 HTML 文件，仅依赖 CDN
