# 景礴 Skill：生命科学杂志讲解

## Skill 信息

- **名称**：生命科学杂志讲解
- **类型**：杂志讲解型（Lecture）
- **学科**：生物
- **技术栈**：Canvas + CSS Animation

## 框架描述

生成一个杂志风格的生命科学理论讲解页面，左侧文字从宏观到分子层面递进讲解，右侧配以动态可视化。5-6 个步骤逐步揭示，每步配合 CSS 动画或 Canvas 图表。适用于进化论证据链、光合作用原理、人体免疫系统等任何需要分步讲解的生命科学理论。暖色调排版，如同翻开一本精心设计的科学杂志。

## 布局规范

```
┌─────────────────────────────────────────────┐
│  [步骤导航条: 1─2─3─4─5─6]    [进度指示]      │
├──────────────────────┬──────────────────────┤
│                      │                      │
│   左侧文字讲解区       │   右侧可视化区        │
│                      │                      │
│   步骤标题             │   Canvas 动画        │
│   理论说明             │   CSS 动画演示       │
│   生物学机制           │   结构图/流程图      │
│   分子层面解释         │                      │
│                      │                      │
├──────────────────────┴──────────────────────┤
│  [上一步]                    [下一步]         │
└─────────────────────────────────────────────┘
```

- 顶部步骤导航条，显示当前步骤和总进度
- 左侧 50% 文字讲解区：步骤标题、理论说明、生物学机制、分子层面解释
- 右侧 50% 可视化区：Canvas 动画或 CSS 动画演示
- 底部前进/后退按钮，支持步骤切换
- 部分步骤右侧配有结构图或流程图

## 交互模式

1. **步骤前进/后退**：点击底部按钮或导航条步骤跳转
2. **动画播放/暂停**：右侧可视化区可控制动画播放状态
3. **层级切换**：部分步骤支持宏观/微观视角切换
4. **元素悬停**：鼠标悬停生物结构元素显示详细信息
5. **进度追踪**：导航条显示已完成的步骤，进度指示百分比

## 视觉风格

- **背景**：暖色象牙渐变 `linear-gradient(180deg, #f5ede0, #ede0cc)`
- **主色调**：赤陶色 `#c2410c`（标题、强调）、深炭灰 `#2d2d2d`（正文）
- **辅助色**：琥珀色 `#d97706`（步骤标记）、叶绿色 `#16a34a`（生物元素）
- **文字**：深炭灰 `#2d2d2d`，暖色背景上高对比度阅读
- **卡片背景**：`rgba(255,255,255,0.6)` + `backdrop-filter: blur(8px)` + `border: 1px solid rgba(194,65,12,0.15)`
- **步骤导航**：已完成步骤填充琥珀色，当前步骤带脉冲动画
- **动画风格**：CSS 关键帧动画为主，配合 Canvas 粒子效果
- **字体**：标题使用衬线字体，正文使用无衬线字体，术语使用等宽字体

## 数据输入格式

用户用自然语言描述要讲解的生命科学理论，例如：
- "讲解达尔文进化论的证据链"
- "做一个光合作用过程的可视化讲解"
- "生成人体免疫系统的讲解"

AI 应根据描述：
1. 确定要讲解的生命科学理论及其核心知识点
2. 将讲解拆分为 5-6 个递进步骤，从宏观到分子层面
3. 为每步设计左侧文字说明和右侧动态可视化
4. 使用 Canvas 或 CSS Animation 实现动画效果
5. 准确呈现生物结构和分子机制

## 内容结构要求

- 每个理论拆分为 5-6 个递进步骤
- 第一步：引入现象或宏观背景
- 中间步骤：逐步深入机制、分子层面解释
- 最后一步：总结与意义
- 每步文字 100-200 字，配合右侧可视化
- 生物结构和分子机制准确呈现

## 动画与交互要求

```javascript
// 步骤切换动画
function goToStep(n) {
  // 左侧文字淡入淡出
  // 右侧可视化过渡动画
  // 更新导航条进度
}

// Canvas 动画循环
function animate() {
  requestAnimationFrame(animate);
  // 根据当前步骤渲染对应可视化
  // 支持播放/暂停控制
}
```

- 步骤切换时左侧文字平滑淡入淡出
- 右侧可视化随步骤切换过渡动画
- CSS 关键帧动画实现生物过程模拟
- 动画播放/暂停按钮控制自动演示

## 质量要求

1. 步骤导航流畅，切换无闪烁
2. 生物结构和分子机制准确
3. 可视化动画流畅（目标 60fps）
4. 初始加载 < 2 秒
5. 支持响应式（移动端上下布局）
6. 内容准确、科学严谨、层次清晰
7. 纯单 HTML 文件，仅依赖 CDN
