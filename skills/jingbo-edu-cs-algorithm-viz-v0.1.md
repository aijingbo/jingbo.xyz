# 景礴 Skill：计算机科学可视化

## Skill 信息

- **名称**：计算机科学可视化
- **类型**：交互工具型（Interactive Tool）
- **学科**：计算机
- **技术栈**：Canvas + DOM
- **CDN**：无外部依赖（纯原生 Canvas 2D + DOM 操作）

## 框架描述

生成算法过程动态可视化页面。支持步骤播放、速度控制、当前操作高亮，让算法执行过程清晰可见。适用于排序算法、二叉树操作、凯撒密码加密解密等任何需要展示执行过程的计算机科学概念。

## 布局规范

```
┌─────────────────────────────────────────┐
│  [标题栏]                                │
├──────────────┬──────────────────────────┤
│              │                          │
│  控制面板     │      算法可视化画布        │
│  (算法选择)   │    (Canvas + DOM)        │
│  (速度/步骤)  │                          │
│              │      [数据结构]           │
│  [当前操作]   │      [高亮/标注]          │
│  [统计信息]   │      [步骤说明]           │
└──────────────┴──────────────────────────┘
```

- 左侧控制面板（固定宽度 280-320px），暖色浅底
- 右侧可视化画布自适应剩余空间
- 控制面板包含：算法选择、播放/暂停/单步/重置、速度调节
- 可视化区域：数据结构图形、当前操作高亮、步骤说明

## 交互模式

1. **算法选择**：下拉或按钮切换不同算法
2. **步骤控制**：单步前进/后退、自动播放、暂停
3. **速度调节**：滑块控制动画速度
4. **当前操作高亮**：正在比较/交换/插入的元素高亮显示
5. **步骤说明**：每一步操作的文字说明同步显示
6. **统计信息**：比较次数、交换次数、时间复杂度展示

## 视觉风格

- **背景**：暖色浅底 `linear-gradient(135deg,#f0e8e0,#e6d8cc)`
- **主色调**：绿色系 `#059669`（交互工具标识）
- **控制面板**：`rgba(255,255,255,0.85)` + 柔和边框
- **可视化画布**：白色背景，清晰的数据结构图形
- **强调色**：当前操作高亮 `#f59e0b`、已排序 `#059669`、比较中 `#3b82f6`
- **字体**：系统无衬线字体，标题 16px bold，代码 13px monospace

## 数据输入格式

用户用自然语言描述要生成的算法可视化，例如：
- "生成一个排序算法可视化"
- "做一个二叉树操作演示"
- "创建一个凯撒密码加密解密工具"

AI 应根据描述：
1. 确定要可视化的算法或数据结构
2. 设计步骤录制与回放机制
3. 实现当前操作的高亮标注
4. 添加步骤说明与统计信息

## 步骤控制要求

- 算法执行时录制每一步操作状态（快照数组）
- 支持单步前进/后退、自动播放、速度调节
- 当前操作元素高亮，附文字说明
- 统计比较次数、交换次数等指标

## 渲染要求

```javascript
// 步骤快照录制
const steps = [];
function recordStep(array, highlights, description) {
  steps.push({ array: [...array], highlights, description });
}
// 播放指定步骤
function renderStep(index) {
  const step = steps[index];
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  step.array.forEach((val, i) => {
    const color = step.highlights.includes(i) ? '#f59e0b' : '#3b82f6';
    drawBar(i, val, color);
  });
  stepInfo.textContent = step.description;
}
```

## 质量要求

1. 步骤切换流畅，高亮即时
2. 算法逻辑准确无误
3. 初始加载 < 1 秒
4. 支持响应式（移动端纵向布局）
5. 步骤说明清晰易懂，适合教学
6. 纯单 HTML 文件，仅依赖 CDN
