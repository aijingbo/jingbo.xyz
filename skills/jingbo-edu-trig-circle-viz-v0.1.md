# 景礴 Skill：三角函数与单位圆

## Skill 信息

- **名称**：三角函数与单位圆
- **类型**：交互工具型（Interactive Tool）
- **学科**：数学
- **技术栈**：Canvas + requestAnimationFrame
- **CDN**：无外部依赖

## 框架描述

生成交互式参数化三角函数可视化工具页面。左侧或顶部参数控制面板（滑块、角度切换），右侧实时可视化区域。单位圆上动点旋转，实时生成正弦余弦波形。适用于单位圆与三角函数联动、正弦余弦波形生成、角度弧度转换等任何需要参数化可视化的三角函数概念。

## 布局规范

```
┌─────────────────────────────────────────┐
│  [标题栏]                                │
├──────────────┬──────────────────────────┤
│              │                          │
│  参数控制面板  │      实时可视化画布        │
│  (滑块/切换)  │    (Canvas)              │
│              │                          │
│  [角度调节]   │  [单位圆]  [波形图]       │
│  [振幅频率]   │      [实时数据反馈]       │
│              │                          │
└──────────────┴──────────────────────────┘
```

- 左侧参数面板（固定宽度 280-320px），暖色浅底
- 右侧可视化画布自适应剩余空间，分为单位圆区和波形区
- 参数面板包含：角度滑块、振幅/频率/相位滑块、角度弧度切换
- 可视化区域：单位圆、动点、正弦余弦波形、坐标标注

## 交互模式

1. **角度滑块调节**：拖动滑块改变角度，动点旋转，波形同步更新
2. **动画播放/暂停**：自动旋转模式，动点沿单位圆匀速运动
3. **振幅频率相位调节**：滑块控制波形参数，实时更新
4. **角度弧度切换**：一键切换角度制与弧度制显示
5. **实时数据反馈**：当前角度、sin值、cos值、tan值实时显示

## 视觉风格

- **背景**：暖色浅底 `linear-gradient(135deg,#f0e8e0,#e6d8cc)`
- **主色调**：绿色系 `#059669`（交互工具标识）
- **参数面板**：`rgba(255,255,255,0.85)` + 柔和边框
- **可视化画布**：白色背景，浅灰网格线
- **强调色**：单位圆蓝 `#3b82f6`、正弦曲线红 `#ef4444`、余弦曲线绿 `#10b981`
- **字体**：系统无衬线字体，标题 16px bold，参数标签 13px

## 数据输入格式

用户用自然语言描述要生成的三角函数可视化工具，例如：
- "生成一个单位圆与三角函数联动演示"
- "做一个正弦余弦波形生成器"
- "创建一个角度弧度转换可视化"

AI 应根据描述：
1. 确定要生成的三角函数可视化类型
2. 设计合适的参数控制项（角度范围、振幅频率相位）
3. 实现参数到图形的实时映射
4. 添加坐标轴、单位圆、波形、实时数据反馈

## 参数控制要求

- 所有滑块使用原生 `<input type="range">`，支持步进和范围设置
- 角度滑块范围 0-360°（或 0-2π），步进 1°（或 0.01 rad）
- 参数变化触发 `requestAnimationFrame` 重绘，保证流畅
- 动画模式使用 `requestAnimationFrame` 实现匀速旋转
- 支持参数预设（标准正弦波、余弦波、调幅波等一键切换）

## 渲染要求

```javascript
// 参数变化实时重绘
function onParamChange() {
  requestAnimationFrame(draw);
}
// 动画循环
function animate() {
  requestAnimationFrame(animate);
  angle += speed;
  draw();
}
// 清除画布并重绘
function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  drawUnitCircle();
  drawMovingPoint();
  drawSineWave();
  drawCosineWave();
  drawLabels();
}
```

## 质量要求

1. 参数调节响应 < 16ms（目标 60fps）
2. 初始加载 < 1 秒
3. 支持响应式（移动端纵向布局）
4. 所有滑块和输入框有清晰标签
5. 数学计算准确、严谨
6. 纯单 HTML 文件，无外部依赖
