物理实验模拟器

物理实验的参数化模拟——抛体运动、电路、杠杆滑轮、透镜成像、简谐运动，调节参数即可看到物理过程的实时变化，把实验室搬进浏览器。

物理 交互工具 9 个案例

这个技能做什么

物理实验模拟器是一个参数化物理过程模拟框架，使用 Canvas 2D 与 requestAnimationFrame 实现物理实验的实时动画。控制面板调节角度、速度、电阻等物理参数，可视化区域实时展示运动轨迹、电路状态、光路图等物理过程，让物理规律"动"起来。

核心特征

  • 实时物理模拟：参数调节即时驱动物理过程动画
  • 暖色浅底布局：参数面板 + 可视化画布，工程化实验界面
  • 矢量可视化：力的分解、速度方向等矢量箭头直观展示
  • 实时数据显示：速度、加速度、电流、力等物理量同步更新
  • 播放控制：开始、暂停、重置、单步，精细控制实验过程
  • 轨迹追踪：运动轨迹可选保留，便于分析运动规律

适用场景

任何需要通过参数变化来理解物理规律的场景：抛体运动的角度与射程关系、电路的欧姆定律验证、杠杆滑轮的平衡条件、透镜成像的物距焦距关系、简谐运动的振幅频率阻尼分析等。把"看不见摸不着"的物理量，变成可调节、可观察的动态实验。

技术栈

  • Canvas 2D — 物理场景绘制与动画
  • requestAnimationFrame — 流畅的动画循环驱动
  • 纯原生 JavaScript 物理计算，无外部依赖
  • 纯单 HTML 文件，无构建依赖
