# 景礴 Skill：线性代数可视化

## Skill 信息

- **名称**：线性代数可视化
- **类型**：交互工具型（Interactive Tool）
- **学科**：数学
- **技术栈**：Canvas + JSXGraph
- **CDN**：
  - `https://cdn.jsdelivr.net/npm/jsxgraph/distrib/jsxgraphcore.js`
  - `https://cdn.jsdelivr.net/npm/jsxgraph/distrib/jsxgraph.css`

## 框架描述

生成交互式参数化线性代数可视化工具页面。左侧或顶部参数控制面板（矩阵输入、滑块），右侧实时可视化区域。用户调节矩阵元素立即看到空间变换效果。适用于矩阵与线性变换、2D网格变形、特征值特征向量等任何需要参数化可视化的线性代数概念。

## 布局规范

```
┌─────────────────────────────────────────┐
│  [标题栏]                                │
├──────────────┬──────────────────────────┤
│              │                          │
│  参数控制面板  │      实时可视化画布        │
│  (矩阵输入框)  │    (Canvas / JSXGraph)   │
│              │                          │
│  [变换矩阵]   │      [坐标轴/网格]        │
│  [特征值显示] │      [实时数据反馈]       │
│              │                          │
└──────────────┴──────────────────────────┘
```

- 左侧参数面板（固定宽度 280-320px），暖色浅底
- 右侧可视化画布自适应剩余空间
- 参数面板包含：矩阵元素输入框、滑块、下拉选择
- 可视化区域：坐标系、变换网格、特征向量标注

## 交互模式

1. **矩阵元素编辑**：直接输入矩阵元素值，回车确认，图形同步更新
2. **滑块调节**：拖动滑块，参数实时变化，图形同步更新
3. **拖动矩阵元素**：拖动矩阵中的数值，实时看到空间变换
4. **缩放与平移**：鼠标滚轮缩放坐标系，拖拽平移
5. **实时数据反馈**：当前矩阵值、特征值、特征向量、行列式显示在面板

## 视觉风格

- **背景**：暖色浅底 `linear-gradient(135deg,#f0e8e0,#e6d8cc)`
- **主色调**：绿色系 `#059669`（交互工具标识）
- **参数面板**：`rgba(255,255,255,0.85)` + 柔和边框
- **可视化画布**：白色背景，浅灰网格线
- **强调色**：根据具体图形定义（原始网格蓝、变换网格红、特征向量紫）
- **字体**：系统无衬线字体，标题 16px bold，参数标签 13px

## 数据输入格式

用户用自然语言描述要生成的线性代数可视化工具，例如：
- "生成一个线性变换矩阵可视化工具"
- "做一个2D网格变形与矩阵的演示"
- "创建一个特征值特征向量可视化"

AI 应根据描述：
1. 确定要生成的线性代数可视化类型
2. 设计合适的参数控制项（矩阵元素、滑块范围）
3. 实现参数到图形的实时映射
4. 添加坐标轴、网格变形、特征向量标注

## 参数控制要求

- 所有滑块使用原生 `<input type="range">`，支持步进和范围设置
- 矩阵元素使用 `<input type="number">`，支持直接输入
- 参数变化触发 `requestAnimationFrame` 重绘，保证流畅
- 关键参数实时显示当前数值（行列式、特征值、特征向量）
- 支持参数预设（单位矩阵、旋转矩阵、缩放矩阵等一键切换）

## 渲染要求

```javascript
// 参数变化实时重绘
function onParamChange() {
  requestAnimationFrame(draw);
}
// 清除画布并重绘
function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  drawGrid();
  drawOriginalGrid();
  drawTransformedGrid();
  drawEigenvectors();
  drawLabels();
}
```

## 质量要求

1. 参数调节响应 < 16ms（目标 60fps）
2. 初始加载 < 1 秒
3. 支持响应式（移动端纵向布局）
4. 所有矩阵输入框有清晰标签
5. 数学计算准确、严谨（行列式、特征值计算）
6. 纯单 HTML 文件，仅依赖 CDN
