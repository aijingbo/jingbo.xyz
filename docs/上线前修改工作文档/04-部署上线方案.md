# 工作流 D：部署上线方案

> 前置条件：工作流 A + B + C 全部完成
> 预计耗时：1-2 小时
> 目标：将景礴学院网站推到 GitHub 并通过 Cloudflare Pages 上线，绑定 jingbo.xyz 域名

## D1. GitHub 推送

### 仓库信息

- 仓库地址：`https://github.com/aijingbo/jingbo.xyz.git`
- 默认分支：`main`
- 远程名称：`origin`

### 推送步骤

```bash
cd /Users/a1/Desktop/jingbo.xyz

# 1. 检查当前状态
git status

# 2. 添加所有修改
git add -A

# 3. 提交
git commit -m "feat: 上线前修改 — 首页文字/导航/Footer统一/Skill英文化/Demo按钮映射"

# 4. 推送
git push origin main
```

### 推送前检查清单

- [ ] `.gitignore` 已排除不需要的文件（node_modules、.DS_Store 等）
- [ ] 没有遗漏的临时文件
- [ ] 所有 HTML 文件编码为 UTF-8
- [ ] 所有文件路径在部署后可正常访问（绝对路径 vs 相对路径）

### 文件路径规范

当前项目中存在两种路径风格：
- **绝对路径**：`href="/demos.html"`、`src="/assets/css/design-system.css"` — Demo 内页大多使用这种
- **相对路径**：`href="demos.html"`、`src="assets/css/design-system.css"` — index.html、skills.html 等根目录页面使用这种

Cloudflare Pages 部署后，根域访问时两种路径都能正常工作。但需确认：
- 根目录页面使用相对路径（`demos.html`）
- 子目录页面使用绝对路径（`/demos.html`）或正确的相对路径（`../demos.html`）

## D2. Cloudflare Pages 配置

### 配置步骤

1. 登录 Cloudflare Dashboard → Pages
2. 创建新项目 → 连接 Git 仓库
3. 选择 `aijingbo/jingbo.xyz` 仓库
4. 配置构建设置：
   - **框架预设**：无（纯静态站点）
   - **构建命令**：留空（无构建步骤）
   - **构建输出目录**：`/`（根目录）
   - **根目录**：`/`（仓库根目录）
5. 保存并部署

### 预览地址

部署成功后，Cloudflare Pages 会生成默认预览地址：
- `https://jingbo-xyz.pages.dev`

### 环境变量

无需环境变量（纯静态站点）。

## D3. 域名绑定

### 域名信息

- 域名：`jingbo.xyz`
- 域名注册商：星网（或其他国内注册商）
- 目标：绑定到 Cloudflare Pages，支持根域和 www 子域

### 绑定步骤

#### 方案 A：将 NS 记录切到 Cloudflare（推荐）

1. 在 Cloudflare 添加站点 `jingbo.xyz`
2. Cloudflare 会分配两个 NS 服务器地址（如 `xxx.ns.cloudflare.com`）
3. 登录域名注册商（星网），修改域名的 NS 记录为 Cloudflare 分配的 NS 服务器
4. 等待 NS 生效（通常数分钟到数小时）
5. 在 Cloudflare Pages 项目设置中添加自定义域名：
   - 添加 `jingbo.xyz`（根域）
   - 添加 `www.jingbo.xyz`（www 子域）
6. Cloudflare 会自动添加 CNAME 记录指向 Pages 项目

#### 方案 B：仅添加 CNAME 记录（不切 NS）

如果不想将整个 DNS 托管到 Cloudflare：
1. 在域名注册商的 DNS 管理中添加 CNAME 记录：
   - `www.jingbo.xyz` → `jingbo-xyz.pages.dev`
2. 根域 `jingbo.xyz` 使用 ALIAS/ANAME 记录指向 Pages（如果注册商支持）
3. 在 Cloudflare Pages 中添加自定义域名

→ **推荐方案 A**：将 NS 切到 Cloudflare，一站式管理 DNS 和 Pages，更简洁可靠。

### HTTPS 证书

Cloudflare Pages 自动为自定义域名提供 HTTPS 证书，无需手动配置。

## D4. 备案问题解决方案

### 问题

中国大陆域名需要 ICP 备案才能在境内服务器上提供 Web 服务。但备案流程通常需要 1-3 周，无法在 3 天内完成。

### 解决方案

**Cloudflare Pages 为国际服务，无需 ICP 备案**：

1. **网站托管**：Cloudflare Pages 的服务器位于全球（含亚太节点），不需要备案
2. **域名访问**：jingbo.xyz 的 NS 切到 Cloudflare 后，由 Cloudflare 的全球 DNS 解析，不经过国内 DNS
3. **访问速度**：Cloudflare 在中国大陆有边缘节点（需确认），访问速度可接受
4. **Skill 文件下载**：通过 jsdelivr CDN（`cdn.jsdelivr.net`）访问 GitHub 仓库中的 MD 文件，jsdelivr 在国内有节点

### 潜在风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| Cloudflare 在国内被干扰 | 访问变慢或间歇不可达 | 后续可考虑备案后迁移到国内 CDN |
| jsdelivr CDN 在国内不稳定 | Skill 下载链接失效 | 备用方案：直接在网站内提供 MD 文件下载 |
| 域名未备案被运营商拦截 | 部分用户无法访问 | Cloudflare 解析不经过国内运营商 DNS，风险较低 |

### 备用方案：直接下载 Skill 文件

如果 CDN 链接不稳定，可在技能展示页同时提供：
1. CDN 链接（复制到 Trae 对话框）
2. 直接下载按钮（从网站本身下载 MD 文件，不走 CDN）

当前技能展示页已有"下载技能文件"按钮，这个按钮直接从网站下载，不依赖 CDN。
