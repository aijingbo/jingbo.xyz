# 工作流 E：Skill 测试验证

> 可与其他工作流并行执行
> 预计耗时：20-30 分钟
> 目标：下载 1-2 个 Skill，在 Trae 中安装并验证是否可正常生成课件

---

## E1. Skill 下载与安装测试

### 测试选型

选择 2 个不同类型的 Skill 进行测试：

| 测试 Skill | 类型 | 技术栈 | 选择理由 |
|-----------|------|--------|---------|
| jingbo-edu-3d-micro-structure | 沉浸式 3D | Three.js | 最复杂类型，验证 3D 渲染能力 |
| jingbo-edu-math-magazine-lecture | 杂志讲解 | D3.js / Canvas | 最常见类型，验证文字+图表布局 |

### 测试步骤

#### 测试 1：3D物质微观结构

1. **下载 Skill 文件**
   - 打开技能展示页 `skills/jingbo-edu-3d-micro-structure-v0.1.html`
   - 点击"复制链接"获取 CDN URL
   - 或点击"下载技能文件"获取 MD 文件

2. **在 Trae 中安装**
   - 打开 Trae AI 编程助手
   - 将 CDN URL 粘贴到对话框
   - 确认 Skill 被正确识别和加载

3. **生成测试课件**
   - 输入指令："生成一个水分子 3D 结构"
   - 观察 Trae 是否能根据 Skill 规范生成交互式 3D 页面
   - 检查：
     - [ ] 分子结构是否正确（2个H + 1个O）
     - [ ] 3D 模型可拖拽旋转
     - [ ] 滚轮缩放正常
     - [ ] 点击原子有高亮和信息显示
     - [ ] 深色背景 + 毛玻璃浮层效果
     - [ ] 显示模式切换可用（球棍/空间填充/线框）

4. **对比线上案例**
   - 打开 `demos/3d-molecule-viewer/index.html`（线上案例）
   - 对比生成结果与线上案例的差异
   - 记录差异点

#### 测试 2：数学概念杂志讲解

1. **下载 Skill 文件**
   - 同上步骤

2. **在 Trae 中安装**
   - 同上步骤

3. **生成测试课件**
   - 输入指令："帮我做一个勾股定理的可视化讲解"
   - 检查：
     - [ ] 左文右图布局（杂志式）
     - [ ] 分步骤讲解
     - [ ] 图表/动画与文字内容匹配
     - [ ] 交互按钮可用（上一步/下一步）
     - [ ] 数学公式正确渲染
     - [ ] 视觉风格与 Skill 规范一致

4. **对比线上案例**
   - 打开 `demos/pythagorean-proof/index.html`（线上案例）
   - 对比生成结果

### 常见问题与排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| Trae 无法识别 Skill | MD 格式不规范 | 检查 MD 文件的 frontmatter 和结构 |
| 生成的页面空白 | CDN 依赖加载失败 | 检查 CDN URL 是否可访问 |
| 3D 模型不显示 | Three.js 版本不兼容 | 确认 CDN 版本号 |
| 交互不响应 | JS 事件绑定问题 | 检查 Skill 中的交互模式描述 |
| 布局错乱 | CSS 规范不够详细 | 补充 Skill 的布局规范描述 |

## E2. Skill 文件内容审查

在测试过程中，同时审查 Skill MD 文件的内容质量：

### 检查项

- [ ] MD 文件结构清晰，章节完整
- [ ] 框架描述准确，AI 能理解
- [ ] 布局规范有 ASCII 示意图
- [ ] 交互模式描述具体
- [ ] 视觉风格有具体色值和 CSS
- [ ] 数据输入格式有示例
- [ ] CDN 依赖列表完整且版本号明确
- [ ] 参考案例链接可访问（线上 URL）
- [ ] 无内嵌的大段 HTML 代码（已清理）
- [ ] 无本地文件路径引用

### 如发现问题

如果测试中发现 Skill 规范不够详细导致生成质量差：
1. 记录具体问题
2. 补充 Skill MD 文件中的规范描述
3. 重新测试验证

---

## 执行顺序

1. 等待工作流 B 完成（文件重命名 + MD 清理）
2. 下载 2 个测试 Skill（约 5 分钟）
3. 在 Trae 中安装并生成课件（约 15 分钟）
4. 对比线上案例，记录结果（约 10 分钟）

## 输出

测试完成后，向用户汇报：
1. 两个 Skill 是否可正常安装和使用
2. 生成课件的质量评估
3. 如有问题，具体的修复建议
