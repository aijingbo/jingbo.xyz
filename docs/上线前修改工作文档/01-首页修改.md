## A2. 最后一屏视觉区隔

### 当前状态

页面结构为：
- 第 4 屏：`.about`（关于景礴 — 宣言式排版，背景为 `linear-gradient(to bottom, var(--bg) 0%, #f5f0e8 50%, var(--bg) 100%)`）
- 第 5 屏：`.entry`（让每个人看见磅礴，背景为默认 `var(--bg)` + 径向暖光晕）

问题：两屏之间文字密集，视觉上没有明确区隔，"关于景礴"的宣言文字和"让每个人看见磅礴"的标题混在一起。

### 修改方案

给 `.entry`（第 5 屏）增加视觉区隔，任选以下一种或组合：

**方案 1（推荐）：改变背景色 + 顶部装饰线**
```css
.entry {
  background: #f5f0e8; /* 比页面背景稍深的暖米色 */
  border-top: 1px solid var(--border);
}
.entry::before {
  /* 替换现有径向光晕，改为顶部装饰线条 */
  content: '';
  position: absolute;
  top: 0; left: 50%;
  transform: translateX(-50%);
  width: 120px; height: 3px;
  background: var(--brand);
  border-radius: 2px;
  opacity: 0.6;
}
```

**方案 2：增加顶部间距 + 装饰性 SVG 线条**
- 在 `.entry` 顶部添加类似首页 hero 区的科学线描装饰元素
- 如正弦波、椭圆轨道等细线条 SVG，opacity 极低（0.05-0.08）
- 与首页 hero 区的视觉语言呼应

**方案 3：深色色块底**
- 将 `.entry` 背景改为深色暖墨色（`var(--ink)`）
- 文字改为浅色
- 与上方浅色"关于景礴"区形成强烈视觉断点

→ 建议方案 1，保持暖调一致性，用色块 + 装饰线区隔。
