## 四、关键决策点

### 决策 1：Skill 下载机制
- **方案 A（推荐）**：纯 MD 文档，去除内嵌的参考课件 HTML 代码，只保留规范描述 + CDN 链接指向线上案例
- **方案 B**：打包 ZIP（MD + 参考 HTML），但用户下载后仍需解压使用，增加操作复杂度
- → 建议方案 A：MD 文档自包含，参考案例通过线上 URL 访问

### 决策 2：Skill 文件命名
- 当前：`景礴-Edu-3d-micro-structure-v0.1.md`
- 改为：`jingbo-edu-3d-micro-structure-v0.1.md`
- 全小写英文，无中文字符，避免 CDN URL 编码问题

### 决策 3：Demo→Skill 映射
- 需要从 `docs/04-Skill生成/Demo-Skill映射表.md` 和 `skills.html` 的 20 个 Skill 数据中提取映射
- 每个 Demo 的"下载 Skill"按钮需指向其所属 Skill 的展示页
