# 任务交接模板

> 本文档定义了新窗口（新会话）接手任务时的标准格式。每个任务文档都应遵循此结构。

## 新窗口交接流程

### Step 1：给新窗口的提示词模板

当你需要在一个新窗口中完成某个任务时，使用以下提示词：

```
请阅读以下文档并完成任务：

1. 必读规范：
   - 设计系统规范：/Users/a1/Desktop/jingbo.xyz/docs/04-设计系统规范.md
   - 开发框架指引：/Users/a1/Desktop/jingbo.xyz/docs/05-开发框架指引.md

2. 任务文档：
   - [任务文档绝对路径]

3. 参考实现（如需）：
   - 3D参考：/Users/a1/Desktop/jingbo.xyz/demos/M1-solid-geometry.html
   - 化学参考：/Users/a1/Desktop/jingbo.xyz/demos/C1-methane-combustion.html

请先读取上述文档，理解任务要求，然后完成开发。
产出文件保存到任务文档中指定的路径。
```

### Step 2：任务文档标准结构

每个任务文档（`tasks/T01-xxx.md`）应包含以下章节：

```markdown
---
title: 任务标题
type: task
task_id: T01
demo_id: M1
subject: 数学
dimension: 3D
status: pending
output_path: demos/M1-solid-geometry.html
created: 2026-08-06
---

# 任务标题

## 任务概述
一句话描述这个任务要做什么。

## 产出文件
- 路径：`/Users/a1/Desktop/jingbo.xyz/demos/xxx.html`
- 格式：单个自包含 HTML 文件

## 学科信息
- 学科：数学/物理/化学/生物/历史
- 主色：#0ea5e9（对应学科色）
- 维度：3D / 2D / 2D+3D / Video

## 题目/内容
具体的题目或教学内容。

## 设计要求
### 布局
（引用 04-设计系统规范.md 的通用布局）

### 3D/2D 场景
具体的可视化要求。

### 分步解析
步骤列表。

### 交互
交互元素列表。

## 技术要求
- 技术栈：Three.js / Canvas 2D / KaTeX / MathJax
- CDN 地址：（引用 05-开发框架指引.md）

## 验收标准
- [ ] HTML 打开无 Console error
- [ ] 公式渲染正确
- [ ] 3D/2D 可交互
- [ ] 响应式正常
- [ ] 设计系统一致性（色彩/圆角/字体/布局）
```

## 已完成任务的状态更新

完成任务后，在 `00-主索引.md` 中将对应任务的状态从 `⬜ 待做` 改为 `✅ 已完成`。

## 注意事项

1. **每个任务文档必须自包含**：新窗口只读这一个文档 + 两个规范文档就能工作
2. **绝对路径**：所有路径用绝对路径，不用相对路径
3. **不假设上下文**：不引用"之前的对话"或"上文提到"
4. **验收标准明确**：每个任务都有可检查的验收标准
