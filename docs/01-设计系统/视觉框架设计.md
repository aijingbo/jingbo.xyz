# 景礴 · 视觉框架设计文档

> **项目**: 景礴（jingbo.xyz）
> **设计理念**: 教科书的严谨遇上博物馆的精致
> **主基调**: 科学杂志风
> **编制日期**: 2026-08-06

---

## 一、设计语言

### 1.1 核心气质
- **知识感**：厚重、可信、有深度
- **杂志感**：排版精致、留白讲究、图文并茂
- **温度感**：暖色调、不冰冷、有人文气息
- **克制感**：不花哨、不炫技、内容为王

### 1.2 配色体系

| 变量名 | 色值 | 用途 |
|--------|------|------|
| `--bg` | `#faf8f5` | 页面背景（暖米白/象牙白，不是纯白） |
| `--surface` | `#ffffff` | 卡片、面板底色 |
| `--surface-muted` | `#f3efe9` | 次级表面、弱化区域 |
| `--text` | `#1a1a1a` | 主文字（深炭灰，不是纯黑） |
| `--text-muted` | `#6b6b6b` | 次级文字、说明文字 |
| `--border` | `#e5ded4` | 边框、分割线（暖灰，不是冷灰） |
| `--brand` | `#c2410c` | 主强调色（赤陶色/陶土红） |
| `--brand-soft` | `rgba(194, 65, 12, 0.1)` | 主强调色弱化版 |

**学科色（仅用于标记，不做大面积使用）**：
| 变量名 | 色值 | 学科 |
|--------|------|------|
| `--accent-math` | `#0d9488` | 数学（ Teal） |
| `--accent-physics` | `#7c3aed` | 物理（紫） |
| `--accent-chem` | `#d97706` | 化学（琥珀） |
| `--accent-bio` | `#059669` | 生物（ Emerald） |
| `--accent-history` | `#dc2626` | 历史（红） |
| `--accent-geo` | `#0891b2` | 地理（ Cyan） |
| `--accent-cs` | `#64748b` | 计算机（ Slate） |
| `--accent-art` | `#db2777` | 艺术/创意（粉） |
| `--accent-cross` | `#ea580c` | 跨学科（橙） |

> ⚠️ 学科色仅用于小面积标记（标签、小点、细边框），绝不用做大面积背景或按钮底色。

### 1.3 字体体系

| 用途 | 字体 | 字重 |
|------|------|------|
| 标题（杂志感） | `Noto Serif SC` / `Source Han Serif SC` / Georgia | 700 |
| 正文 | `Inter` / `Noto Sans SC` / -apple-system | 400-500 |
| 代码/数值 | `JetBrains Mono` / `SF Mono` / monospace | 500-600 |

**字体层级**：
| 级别 | 大小 | 行高 | 用途 |
|------|------|------|------|
| Hero 标题 | clamp(36px, 5vw, 56px) | 1.2 | 首页主标题 |
| 大标题 | clamp(28px, 3.5vw, 36px) | 1.3 | 章节标题 |
| 中标题 | 20px | 1.4 | Demo 标题、卡片标题 |
| 正文 | 15px | 1.7 | 段落正文 |
| 小字 | 13px | 1.6 | 标签、说明、按钮 |
| 极小字 | 11px | 1.5 | 辅助信息 |

### 1.4 间距体系

基于 4px 网格：
- `--spacer-4`: 4px
- `--spacer-8`: 8px
- `--spacer-12`: 12px
- `--spacer-16`: 16px
- `--spacer-20`: 20px
- `--spacer-24`: 24px
- `--spacer-32`: 32px
- `--spacer-48`: 48px
- `--spacer-64`: 64px
- `--spacer-96`: 96px

### 1.5 圆角 & 阴影

| 变量 | 值 | 用途 |
|------|-----|------|
| `--radius` | 6px | 按钮、输入框 |
| `--radius-card` | 12px | 卡片、面板 |
| `--radius-full` | 999px | 药丸形标签、圆形按钮 |

| 阴影 | 值 | 用途 |
|------|-----|------|
| `--shadow-soft` | `0 4px 24px rgba(0,0,0,0.06)` | 柔和悬浮 |
| `--shadow-card` | `0 8px 32px rgba(0,0,0,0.08)` | 卡片悬浮 |
| `--shadow-deep` | `0 16px 48px rgba(0,0,0,0.12)` | 深度悬浮 |

### 1.6 动效规范
- 过渡时长：`250ms`（标准）、`150ms`（快速）、`400ms`（慢速）
- 缓动函数：`cubic-bezier(0.4, 0, 0.2, 1)`（标准）
- 只对 `transform` 和 `opacity` 做动画，保证性能
- 尊重 `prefers-reduced-motion`

## 二、首页设计

### 2.1 整体结构（4 屏）

| 屏次 | 区域 | 高度 | 核心目的 |
|------|------|------|----------|
| 第1屏 | Hero | 100vh | 震撼第一印象，讲清"知识可以这样子讲" |
| 第2屏 | 特辑展示区 | ~80vh | 精选 Demo 大预览，直观感受品质 |
| 第3屏 | "你也可以做"流程 | ~60vh | 三步讲清：下载→粘贴→生成 |
| 第4屏 | 入口引导 + Footer | ~40vh | 引导浏览全量内容 |

### 2.2 Hero 区域

**布局**：居中对齐，杂志封面式
- 顶部：刊号式标签（如 "ISSUE 01 · 知识可视化特辑"）
- 中部：大标题（衬线字体）+ 副标题
- 底部：CTA 按钮 + 学科色条（6 个学科的细线，象征性展示）

**文案**：
- 主标题：知识，也可以美得像艺术品
- 副标题：50 件交互式知识展品，覆盖 8 大学科。每一件展品背后，都有一个可下载的 Skill，让你用一句话就能生成同款。
- CTA：浏览展品 →

**背景**：暖米白底 + 极淡的径向渐变（赤陶色，透明度 5%）+ 可选：极淡的网格纹理

### 2.3 特辑展示区

**布局**：
- 上方：学科标签行（居中，文字标签，激活态用赤陶色下划线）
- 中部：大尺寸预览图（全出血，无边框，aspect-ratio 约 16:9）
- 预览图上：左下角叠加 Demo 标题 + 学科标签 + "打开展品"按钮

**交互**：
- 点击不同学科标签 → 预览区平滑切换到对应学科的精选 Demo
- 预览图有轻微的视差/缩放 hover 效果
- 切换时有淡入淡出过渡

**性能**：
- 预览用静态 SVG 或高质量截图（WebP），不加载真实 3D 库
- 首屏只加载默认学科的预览图，其他懒加载

### 2.4 "你也可以做"流程区

**三步式**：
1. 复制 Skill — 点击复制按钮，Skill 内容到剪贴板
2. 粘贴到 Trae — 在 Trae 的 Skill 目录下新建文件粘贴
3. 一句话生成 — "帮我做一道勾股定理的几何可视化"

**视觉呈现**：
- 三个步骤横向排列
- 每步一个图标 + 标题 + 简短说明
- 步骤之间有箭头连接

### 2.5 入口引导 + Footer

**两个大入口**：
- 浏览全部展品 →（跳转到 demos.html）
- 查看所有 Skill →（跳转到 skills.html）

**Footer**：
- 景礴 · jingbo.xyz
- © 2026 · 用 Trae 构建
- GitHub 链接

## 三、Demo 展示框架（四种）

### 3.1 通用外壳（所有 Demo 共用）

所有 Demo 页面都有的统一元素：

**顶部导航栏**：
- 左侧：← 返回 + 景礴 logo
- 中间：Demo 标题
- 右侧：学科标签 + "下载 Skill 做同款"按钮
- 样式：半透明毛玻璃效果，滚动时收缩

**底部信息条**（可选，部分框架用）：
- Skill 名称
- 技术栈标签
- "打开/关闭信息"开关

### 3.2 框架一：沉浸式全屏型

**适用**：3D 分子、DNA、太阳系、地球四季、晶体结构等

**布局**：
```
┌─────────────────────────────────────────┐
│  顶部导航（半透明毛玻璃）               │
├─────────────────────────────────────────┤
│                                         │
│                                         │
│           全屏 3D 画布                  │
│     （深灰/近黑背景，内容发光）          │
│                                         │
│                                         │
│    🔄 自动播放        ⤢ 全屏           │
│    （左下浮动）        （右下浮动）      │
├─────────────────────────────────────────┤
│  底部信息条（半透明）                    │
│  DNA 双螺旋 3D 结构探索 · 生物 · [下载]  │
└─────────────────────────────────────────┘
```

**设计要点**：
- 背景色：`#0f0f0f` 或 `#1a1a1a`（深灰，不是纯黑）
- 3D 内容是绝对主角，UI 元素尽量少且半透明
- 控件用图标按钮，圆形，半透明白色背景
- 文字用浅灰色，避免抢戏

### 3.3 框架二：杂志讲解型

**适用**：几何证明、历史时间轴、傅里叶讲解、气候条纹等

**布局**：
```
┌─────────────────────────────────────────┐
│  顶部导航                                │
├────────────┬────────────────────────────┤
│            │                            │
│            │                            │
│  左侧      │     右侧可视化区            │
│  40%       │     60%                    │
│            │                            │
│  标题      │                            │
│  正文讲解   │                            │
│  步骤导航   │                            │
│            │                            │
│  ◀  ▶ 步骤 │                            │
└────────────┴────────────────────────────┘
```

**设计要点**：
- 背景：暖米白（和首页统一）
- 左侧标题用衬线大字体，像杂志文章
- 正文行高 1.7，舒适阅读
- 步骤进度用圆点或线条表示
- 右侧可视化区有细边框，像插图

### 3.4 框架三：交互工具型

**适用**：圆锥曲线、抛体运动、排序算法、色彩理论等

**布局**：
```
┌─────────────────────────────────────────┐
│  顶部导航                                │
├─────────────────────────────────────────┤
│                                         │
│           可视化画布（80%）              │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│  控制面板（20%）                         │
│  ┌───────┬───────────────┬────┐         │
│  │ 参数1 │ ━━━━━●━━━━━━━ │ 42 │         │
│  ├───────┼───────────────┼────┤         │
│  │ 参数2 │ ━●━━━━━━━━━━━ │ 12 │         │
│  └───────┴───────────────┴────┘         │
│  [播放] [重置] [模式切换]               │
└─────────────────────────────────────────┘
```

**设计要点**：
- 背景：暖白或淡灰
- 控制面板用 `--surface-muted` 底色
- 滑块精致，有数值显示
- 按钮用文字+图标，圆角 6px
- 整体感觉像精密仪器，不花哨

### 3.5 框架四：时空叙事型

**适用**：历史人物生平+路线、战役进程、丝绸之路等

**布局**：
```
┌─────────────────────────────────────────┐
│  顶部导航                                │
├──────────────────────────┬──────────────┤
│                          │              │
│                          │  时间轴      │
│                          │  （右侧）    │
│        地图区域           │              │
│      （左侧 70%）         │  事件列表    │
│                          │              │
│                          │  ○ 事件1     │
│                          │  ● 事件2     │
│                          │  ○ 事件3     │
└──────────────────────────┴──────────────┘
```

**设计要点**：
- 地图占主体，时间轴在右侧窄栏
- 点击时间轴事件 → 地图平滑移动到对应位置 + 弹出信息卡片
- 时间轴用竖线 + 圆点，杂志感
- 整体色调偏暖，地图用浅色底图

## 四、列表页设计

### 4.1 展品列表页（demos.html）

**布局**：左侧导航 + 右侧卡片网格
- 左侧：学科分类树（数学、物理、化学...）
- 右侧：Demo 卡片网格（3-4 列）

**卡片样式**：
- 上方：预览图（aspect-ratio 4:3）
- 下方：学科标签 + 标题 + 一句话描述
- Hover：轻微上浮 + 阴影加深

### 4.2 Skill 列表页（skills.html）

**布局**：类似展品列表页
- 左侧：学科分类
- 右侧：Skill 卡片
- 卡片含：Skill 名称、适用场景、技术栈、"复制 Skill"按钮

## 五、组件规范

### 5.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 | 赤陶色底 + 白字 + 圆角 6px | 主要 CTA |
| 次按钮 | 透明底 + 文字色 + 1px 边框 | 次要操作 |
| 文字按钮 | 只有文字 + 下划线/箭头 | 链接型操作 |
| 图标按钮 | 圆形 + 半透明底 + 图标 | 播放器、工具条 |

### 5.2 标签/Tag

- 药丸形（圆角 999px）
- 小号：11px 字，左右 10px 内边距
- 底色：`--surface-muted`，文字：`--text-muted`
- 激活态/强调态：底色用学科色 10% 透明度，文字用对应学科色

### 5.3 卡片

- 圆角 12px
- 1px 边框（`--border`）
- 正常状态无阴影，hover 时有 `--shadow-card`
- 内边距：24px
