# 景礴 · 多窗口 Demo 生成提示词模板

> 使用方法：在新的 Trae 窗口中，复制对应类型的提示词，替换掉 `[具体方向]` 部分，然后执行。

---

## 通用要求（所有 Demo 必须遵守）

### 设计规范
- **配色**：使用景礴设计系统 CSS 变量，赤陶暖调 + 暖米白底
- **字体**：标题用 Noto Serif SC（衬线），正文用 Noto Sans SC
- **风格**：科学杂志风，克制、精致、知识感
- **交互**：按钮友好、操作直观、不要工程化
- **性能**：用 CDN 引入第三方库，单文件 HTML

### 文件结构
- 每个 Demo 一个独立文件夹，放在 `/Users/a1/Desktop/jingbo.xyz/demos/` 下
- 文件夹命名规则：`学科-方向名`（全小写，连字符分隔）
- 示例：`demos/conic-sections/index.html`
- 入口文件固定为 `index.html`

### 必须包含的元素
1. 顶部导航栏（毛玻璃效果）
2. 学科标签 + Demo 标题
3. "下载 Skill 做同款"按钮
4. 响应式布局
5. 引入 `/assets/css/design-system.css`
