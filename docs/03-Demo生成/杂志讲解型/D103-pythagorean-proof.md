## 一、Demo 概述

勾股定理（a² + b² = c²）是数学中最著名的定理之一，也是被证明次数最多的定理——已知有超过 300 种证明方法。这个 Demo 选取其中最优雅的一种几何证明（面积割补法），以杂志文章的形式，用动态可视化一步步展示证明过程。读者将亲眼看到：大正方形中的四个三角形如何移动位置，从而"变出"两个小正方形，而它们的面积之和恰好等于斜边上的正方形面积。

## 三、呈现框架

### 杂志讲解型
- 章节数：5 步
- 布局：左文右图
- 步骤切换方式：上一步/下一步按钮 + 步骤圆点
- 是否有播放模式：是（自动播放，每步 7 秒）

### 各步内容规划

**第 1 步：一个流传了三千年的定理**
- 左侧：以勾股定理的历史开篇——古巴比伦泥板上的勾股数、中国《周髀算经》中的"勾三股四弦五"、古希腊毕达哥拉斯学派的发现。引出问题：为什么这个定理在不同文明中被独立发现？因为它是空间的基本规律。
- 右侧：一个经典的直角三角形，三条边上分别立着三个正方形。每个正方形上标注面积（a²、b²、c²）。用户可以拖动三角形的顶点改变边长，三个正方形的大小实时变化，下方显示 a² + b² 和 c² 的数值，永远相等。

**第 2 步：把四个三角形放进大正方形**
- 左侧：介绍证明的第一步——取四个完全相同的直角三角形，将它们放入一个边长为 a+b 的大正方形中。四个三角形分别放在四个角落，斜边朝内，围成一个中间的正方形。
- 右侧：动画展示四个三角形依次"飞"入大正方形的过程。大正方形边长 = a+b。四个三角形占据角落，中间形成一个边长为 c 的倾斜正方形。用不同颜色区分三角形和中间的正方形。

**第 3 步：面积算一算**
- 左侧：计算面积。大正方形的总面积是 (a+b)²。四个三角形的总面积是 4 × (½ab) = 2ab。中间正方形的面积是 c²。所以：(a+b)² = 2ab + c²。展开左边：a² + 2ab + b² = 2ab + c²。消去 2ab，得到 a² + b² = c²。
- 右侧：在图形上用面积标注来配合推导。大正方形标注 (a+b)²，每个三角形标注 ½ab，中间正方形标注 c²。公式推导过程逐行显示，对应的图形部分高亮闪烁。

**第 4 步：换一种摆法——赵爽弦图**
- 左侧：展示中国古代数学家赵爽的证明方法（弦图）。同样是四个三角形，但摆放方式不同——它们的斜边朝外，围成一个更大的正方形。这种证明同样简洁优美。
- 右侧：展示赵爽弦图的构造。四个直角三角形以斜边朝外排列，形成外框大正方形（边长 c），中间是一个小正方形（边长 b-a）。面积推导：c² = 4×(½ab) + (b-a)² = 2ab + b² - 2ab + a² = a² + b²。

**第 5 步：勾股定理的世界**
- 左侧：介绍勾股定理的广泛应用——从建筑测量到 GPS 定位，从距离计算到欧氏距离公式。展示几组著名的勾股数：(3,4,5)、(5,12,13)、(8,15,17)。
- 右侧：互动区——用户可以输入两个数，自动计算第三边并画出对应的直角三角形和三个正方形。下方展示勾股数探索器：拖动滑块找勾股数，找到时会有惊喜动效。
