## 一、Demo 概述

本 Demo 以科学杂志文章的形式，分步骤深入浅出地讲解交互式创意编程入门画板的核心知识。通过图文并茂的呈现方式，将复杂的创意编程概念拆解为多个易于理解的章节，每章配有交互式可视化辅助说明。用户可以按照自己的节奏逐步阅读，通过动手操作加深理解，体验从"知道"到"理解"的学习过程。

## 三、呈现框架

### 杂志讲解型
- 章节数：5-7 步（根据内容复杂度调整）
- 布局：左文右图（桌面端）/ 上文下图（移动端）
- 步骤切换方式：上一步/下一步按钮 + 步骤圆点导航 + 键盘左右键
- 是否有播放模式：是（自动播放，每步约 8-10 秒）
- 进度指示：顶部进度条 + 步骤编号显示

### 各步内容规划

**第 1 步：引言——问题引入**
- 左侧：以一个有趣的问题或生活现象引入，激发读者好奇心。简要介绍本主题的重要性和应用价值。
- 右侧：展示一个引人入胜的可视化动效或示意图，抓住读者注意力。

**第 2 步：基础概念——从简单开始**
- 左侧：讲解最基础的概念和定义，用通俗的语言解释核心思想。
- 右侧：简单的交互式可视化，展示基础概念，用户可以动手操作感受。

**第 3 步：核心原理——深入理解**
- 左侧：详细讲解核心原理和关键机制，配合公式和图示。
- 右侧：核心可视化，展示原理的动态过程，用户可以调节参数观察变化。

**第 4 步：互动实验——动手验证**
- 左侧：邀请读者动手实验，通过调节参数、改变条件来验证所学知识。
- 右侧：交互式控制面板 + 实时可视化反馈，鼓励探索式学习。

**第 5 步：应用延伸——知识拓展**
- 左侧：介绍该知识在现实世界中的应用场景，以及与其他领域的交叉。
- 右侧：应用场景展示或案例分析，可包含多个小卡片/切换展示。

## 五、技术实现

### 推荐技术栈
- D3.js + SVG（用于图表绘制和交互）
- 或者纯 Canvas API（性能更好，适合复杂动画）
- 数学计算使用原生 JavaScript 或 math.js
- GSAP（用于步骤切换动画和元素过渡）
- KaTeX / MathJax（数学公式渲染，如需要）

### 性能要求
- 首屏加载时间：< 1.5s
- 是否需要加载动画：是（淡入动画 + 首图渐进式显示）
- 动画帧率：60fps（交互式可视化需要流畅）
- 步骤切换动画：300-500ms 平滑过渡

### 响应式
- 移动端适配要求：左右分栏改为上下布局（上文下图），文字区占 40% 高度，可视化区占 60% 高度
- 滑块控件在移动端要放大，便于触摸操作
- 最小支持宽度：375px
- 文字字号自适应，确保可读性

2. 确定最佳呈现方式（是否符合对应框架的规范）
