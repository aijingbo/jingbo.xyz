## 一、Demo 概述

光合作用是地球上最重要的化学反应——它将阳光转化为生命的能量，制造我们呼吸的氧气，撑起整个食物链。但这个过程远比"二氧化碳 + 水 → 葡萄糖 + 氧气"复杂。从叶绿素如何捕获光子，到水的裂解释放氧气，再到卡尔文循环固定二氧化碳，每一步都是大自然的精妙设计。这个 Demo 以杂志科普文章的形式，从叶片到叶绿体，再到分子层面，层层深入，带领读者走进光合作用的微观世界。

- 布局：左文右图
- 步骤切换方式：上一步/下一步按钮 + 步骤圆点

### 各步内容规划

**第 1 步：地球上最重要的化学反应**
- 左侧：以一个震撼的事实开篇——每年光合作用将约 1150 亿吨碳转化为有机物，支撑起整个生物圈。介绍光合作用的发现简史（海尔蒙特柳树实验、普利斯特利小鼠实验、萨克斯半叶法），以及总反应式：6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂（光照、叶绿体）。
- 右侧：一幅宏大的绿色地球插画，阳光照射下来，森林和海洋浮游生物进行光合作用。画面上标注关键数字：年产 1150 亿吨有机物、产生 2600 亿吨氧气、支撑 870 万物种。下方有一个时间线，展示光合作用的演化历程——从 35 亿年前的蓝藻到今天的绿色植物。

**第 2 步：走进叶绿体——光合作用的工厂**
- 左侧：光合作用发生在叶绿体中。介绍叶绿体的结构：双层膜、类囊体（扁平囊状结构，堆叠成基粒）、基质（类囊体之外的液体）。叶绿素就分布在类囊体膜上，它是捕获光能的关键色素——主要吸收红光和蓝紫光，反射绿光，所以叶子是绿色的。
- 右侧：从叶片 → 叶肉细胞 → 叶绿体 → 类囊体的层层放大动画。点击或滚动可以"钻入"下一层结构。最内层展示叶绿体的立体结构，标注各部分名称。有一个吸收光谱图，显示叶绿素 a、叶绿素 b 和类胡萝卜素的吸收峰，以及为什么叶子是绿色的（绿光被反射）。

**第 3 步：光反应——把阳光变成能量货币**
- 左侧：光合作用分为两个阶段——光反应和暗反应。光反应发生在类囊体膜上，需要光。过程：（1）叶绿素吸收光能，电子被激发；（2）水被分解（光解），释放氧气和氢离子；（3）电子沿电子传递链传递，同时将氢离子泵入类囊体腔；（4）氢离子顺浓度梯度通过 ATP 合酶，生成 ATP；（5）电子最终用于生成 NADPH。
- 右侧：类囊体膜上的光反应过程动画。从左到右展示：光系统 II（P680）吸收光能 → 水光解（释放 O₂） → 电子传递链（细胞色素复合物） → 光系统 I（P700）再激发 → 生成 NADPH。同时氢离子在类囊体腔中积累，通过 ATP 合酶（旋转的分子马达）产生 ATP。可以暂停/播放动画，点击每个蛋白复合物查看详情。

**第 4 步：卡尔文循环——把碳变成糖**
- 左侧：暗反应（卡尔文循环）发生在叶绿体基质中，不需要光直接参与，但需要光反应产生的 ATP 和 NADPH。过程分为三步：（1）碳固定：RuBP（五碳化合物）与 CO₂ 结合，生成 2 分子三碳化合物（3-PGA），由 Rubisco 酶催化；（2）还原：利用 ATP 和 NADPH 将 3-PGA 还原为 G3P；（3）再生：大部分 G3P 重新生成 RuBP，一小部分离开循环合成葡萄糖。每循环 3 次，固定 3 个 CO₂，净生成 1 个 G3P。
- 右侧：卡尔文循环的环形动画。三个阶段用不同颜色区分：碳固定（蓝色）、还原（绿色）、再生（橙色）。循环中心显示 CO₂ 进入和 G3P 输出。动画展示分子的流转过程——每一轮循环，碳分子如何被"加工"。旁边显示 ATP 和 NADPH 的消耗统计。可以调节 CO₂ 浓度滑块，观察循环速率的变化。

**第 5 步：光合作用的影响因素与意义**
- 左侧：讲解影响光合作用的三大因素——光照强度（光饱和点）、CO₂ 浓度（CO₂ 饱和点）、温度（酶活性）。介绍农业生产中的应用：温室大棚中增施有机肥、延长光照时间、合理密植等。最后升华主题：光合作用是地球生态系统的能量基础，也是应对气候变化的关键。
- 右侧：三个因素的交互曲线图。（1）光照强度-光合速率曲线：显示光补偿点和光饱和点。（2）CO₂ 浓度-光合速率曲线：显示 CO₂ 补偿点和饱和点。（3）温度-光合速率曲线：钟形曲线，最适温度在 25-30°C。每条曲线都有可拖动的点，显示对应数值。底部有一个"农业应用"的小卡片组，展示几种增产措施的原理。
