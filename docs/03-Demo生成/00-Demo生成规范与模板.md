# 景礴 · Demo 生成规范与模板

> 本文档定义所有 Demo 需求文档的统一格式和生成规范。
> 每个 Demo 对应一个独立的需求文档，交给前端 agent 实现。

---

## 一、编号体系

### 编号规则
```
D + 类型码 + 序号
```

**类型码**：
- `0xx` → 沉浸式全屏型（Immersive）
- `1xx` → 杂志讲解型（Magazine）
- `2xx` → 交互工具型（Interactive）
- `3xx` → 时空叙事型（Narrative）

**示例**：
- D001 = 沉浸式第 1 个
- D105 = 杂志讲解型第 5 个
- D203 = 交互工具型第 3 个
- D301 = 时空叙事型第 1 个

### 文件命名
```
D{编号}-{英文短名}.md
```

示例：
- `D001-DNA-double-helix.md`
- `D101-fourier-series.md`
- `D201-sorting-algorithms.md`

### 存放路径
```
docs/03-Demo生成/
├── 沉浸式全屏型/
│   ├── D001-DNA-double-helix.md
│   ├── D002-3d-molecule.md
│   └── ...
├── 杂志讲解型/
│   ├── D101-fourier-series.md
│   └── ...
├── 交互工具型/
│   ├── D201-sorting-algorithms.md
│   └── ...
└── 时空叙事型/
    ├── D301-libai-life.md
    └── ...
```

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
2. 确定最佳呈现方式（是否符合对应框架的规范）
3. 设计视觉方案（配色、布局、动效）
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
5. 开始编码实现
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
7. 保存到指定路径
