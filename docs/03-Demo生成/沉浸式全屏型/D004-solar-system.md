## 一、Demo 概述

本 Demo 以沉浸式 3D 方式展示太阳系的八大行星及其围绕太阳运行的壮丽景象。用户可以自由穿梭于太阳系中，观察各行星的大小比例、轨道位置、公转速度、以及行星的基本特征（如土星环、木星大红斑、火星极冠等）。Demo 兼顾科学性与视觉美感，用户可调整时间流速观察行星运行规律，也可点击任意行星查看详细信息卡片，在宇宙探索中学习天文知识。

## 二、内容要求

### 知识点覆盖
- 太阳系的组成：太阳、八大行星（水星、金星、地球、火星、木星、土星、天王星、海王星）、矮行星、小行星带
- 行星的分类：类地行星（水金地火）、巨行星（木土）、远日行星（天海）
- 行星运动特征：同向性、共面性、近圆性
- 开普勒行星运动定律：轨道定律、面积定律、周期定律
- 各行星的基本参数：与太阳距离、公转周期、自转周期、直径、质量、卫星数量
- 太阳系小天体：小行星带位于火星与木星之间、柯伊伯带位于海王星轨道外
- 土星环、木星大红斑、火星奥林匹斯山等标志性特征

### 目标用户
- 小学高年级科学课学生（太阳系入门）
- 初中地理/物理学生（天体运动）
- 天文爱好者和科普学习者
- 科技馆/展馆的互动展示项目

## 四、视觉设计要求

### 整体气质
- 宇宙的浩瀚与壮美，带来身临其境的太空漫游感

- 整体光效以太阳为中心，呈现真实的光照感

### 配色方案
- 太阳：炽烈的黄白色（中心 #FFFFFF → 外层 #FFA000），带有辐射状日冕
- 水星：灰褐色（#8D6E63），表面布满陨石坑纹理
- 金星：暖黄色（#FFCC80），浓厚硫酸云层质感
- 地球：蓝色星球（#1565C0 海洋 + #2E7D32 陆地 + 白色云层）
- 火星：红褐色（#D84315），带有极冠和暗色平原
- 木星：橙棕条纹（#E65100 与 #FFF3E0 交替的大气带）+ 大红斑
- 土星：淡金黄色（#FFE082）+ 冰岩质光环（半透明白灰色）
- 天王星：淡青蓝色（#80DEEA），侧躺着自转的独特姿态
- 海王星：深蓝色（#1565C0），带有深蓝色风暴斑点
- 背景色：#050510 深黑蓝 + 银河星云紫色光晕 + 白色星点
- 轨道线：极淡的白色半透明线（rgba(255,255,255,0.08)），选中行星的轨道高亮
- 强调色：青色（#00E5FF）用于选中高亮和交互反馈
- 是否遵循景礴设计系统：是，深色沉浸式宇宙背景、发光天体、半透明圆形控件

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染引擎）
- 行星纹理：程序化生成（Canvas 绘制）或使用低分辨率贴图（每个行星 256x128）
- 星空背景：多层粒子系统（远景星点 + 近景星点 + 银河星云 Sprite）
- OrbitControls（视角控制，需设置合理的缩放范围）
- 太阳光晕：PointLight + 多层 Sprite 加法混合
- 土星环：RingGeometry + 透明纹理贴图
- 小行星带：Points 粒子系统（数千个小行星点）
- GSAP / TWEEN（视角切换动画、信息面板过渡）

### 性能要求
- 首屏加载时间：< 4 秒（八颗行星纹理是主要加载项）
- 是否需要加载动画：是，从星云中逐渐显现太阳系的入场动画
- 帧率目标：60fps（桌面端），45fps+（移动端）
- 纹理优化：使用低分辨率贴图，非选中行星使用简化材质
- LOD 策略：远距离显示简化模型，近距离加载高细节纹理
- 粒子控制：小行星带使用 Points 而非独立 Mesh，控制在 3000-5000 粒子

### 响应式
- 移动端适配要求：触屏单指旋转、双指缩放，行星列表改为底部横向滚动
- 信息卡片在移动端改为全屏弹窗
- 自适应屏幕尺寸，保证太阳系在初始视角完整可见
- 低性能设备自动降低行星纹理分辨率和粒子数量

请按照以下流程工作：
1. 理解知识点和教学目标

   - 整理每颗行星的标志性特征和趣味知识点

2. 确定最佳呈现方式（是否符合对应框架的规范）

   - 交互设计：左侧行星列表（或底部）+ 底部时间控制 + 自由视角

3. 设计视觉方案（配色、布局、动效）
