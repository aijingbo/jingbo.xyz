## 一、Demo 概述

本 Demo 以沉浸式 3D 方式展示地球板块构造和地震形成的原理，用户可以直观地看到六大板块的分布、边界类型以及板块运动如何引发地震、火山和造山运动。Demo 采用地球半剖视视角，既可以看到地球表面的板块分布，也可以看到地球内部的圈层结构（地壳、地幔、地核），通过动画演示板块碰撞、张裂、错动三种边界类型的运动过程，帮助学生理解"板块构造学说"的核心内容和地震的成因机制。

## 二、内容要求

### 知识点覆盖
- 地球的内部圈层结构：地壳、地幔（上地幔+下地幔）、地核（外核+内核）
- 岩石圈和软流层的概念：岩石圈包括地壳和上地幔顶部
- 板块构造学说：
  - 岩石圈被分割成六大板块：亚欧板块、非洲板块、美洲板块、太平洋板块、印度洋板块、南极洲板块
  - 板块漂浮在软流层之上，处于不断运动之中
  - 板块内部地壳比较稳定，板块交界处地壳比较活跃
- 板块边界类型：
  - 消亡边界（碰撞挤压）：海沟、造山带、岛弧
    - 大陆板块与大陆板块碰撞：形成巨大山脉（如喜马拉雅山）
    - 大洋板块与大陆板块碰撞：形成海沟、岛弧、海岸山脉
  - 生长边界（张裂拉伸）：裂谷、海洋、海岭
  - 转换边界（水平错动）：转换断层，如圣安德烈斯断层
- 地震的成因：板块运动导致岩层断裂错动，释放能量形成地震波
- 地震的相关概念：震源、震中、震源深度、震级、烈度
- 火山的分布：环太平洋火山地震带、地中海-喜马拉雅火山地震带

### 目标用户
- 初中地理学生（七年级《海陆的变迁》）
- 高中地理学生（必修1《自然地理》）
- 中学地理教师（课堂演示）
- 地质科普爱好者

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色宇宙（#0a0a14 深蓝黑 + 星点），地球位于画面中心
- 主视觉：3D 地球模型，带有板块边界高亮，可切换为半剖视展示内部结构
- 交互方式：鼠标拖拽旋转视角、滚轮缩放、点击板块高亮显示信息、右侧边界类型选择、底部动画控制
- 动画：板块缓慢漂移动画，三种边界类型的运动过程演示（碰撞/张裂/错动），地震波传播效果，火山喷发效果
- 特殊功能：
  - 视图切换：完整地球 / 半剖视（展示内部圈层） / 平面展开图
  - 边界类型演示：碰撞边界 / 张裂边界 / 转换边界 三种场景动画
  - 地震演示：点击地震带触发地震波传播动画
  - 时间尺度：可查看 2 亿年前（泛大陆）→ 现在 → 未来的板块漂移
  - 圈层显示：地壳 / 地幔 / 地核 可独立开关可见性
  - 热点标记：环太平洋火山地震带、地中海-喜马拉雅带 高亮显示

### 配色方案

  - 海洋：深蓝色（#0D47A1）
  - 陆地：绿色和棕色（#2E7D32 / #6D4C41）
  - 板块边界：橙红色发光线（#FF5722），带有脉动效果
  - 地震带：红色点状标记（#F44336），闪烁动画
  - 火山：橙红色三角标记（#FF9800）
- 地球内部圈层（半剖视）：
  - 地壳：薄的灰色层（#9E9E9E）
  - 上地幔：橙红色（#FF7043），带有对流纹理
  - 下地幔：深红色（#D32F2F）
  - 外核：液态金属亮黄色（#FFD54F），有流动感
  - 内核：固态银白色（#ECEFF1）
- 地震波：白色半透明球面波（rgba(255,255,255,0.5)），从震源向外扩散
- 火山喷发：橙红色粒子向上喷发（#FF5722 → #FFEB3B）
- 背景色：#0a0a14 深蓝黑色 + 星点粒子
- 强调色：橙红色（#FF5722）用于板块边界和交互反馈
- 是否遵循景礴设计系统：是，深色沉浸式背景、发光效果、半透明控件

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染引擎）
- 地球模型：SphereGeometry + 板块纹理贴图（或程序化生成）
- 地球内部：使用多个同心球体表示不同圈层，配合剖切平面
- 板块边界：使用 Line 或 TubeGeometry 沿球面绘制
- 地震波：使用逐渐扩大的半透明球体模拟波前传播
- 火山喷发：Points 粒子系统
- OrbitControls（视角控制）
- 板块漂移动画：顶点动画或 morph target
- GSAP（边界类型演示动画、视图切换动画）

### 性能要求
- 首屏加载时间：< 3 秒
- 是否需要加载动画：是，地球从星云中出现，逐渐聚焦到板块边界的入场动画
- 帧率目标：60fps（桌面端），45fps+（移动端）
- 纹理优化：地球纹理使用低分辨率（512x256）
- 粒子控制：火山喷发粒子 < 500 个
- 地球内部使用简化模型，减少面数

### 响应式
- 移动端适配要求：触屏单指旋转、双指缩放
- 右侧面板在移动端改为底部横向滚动标签
- 信息面板移动端从底部滑出
- 自适应屏幕尺寸，地球始终居中
- 低性能设备简化地球纹理和粒子效果
