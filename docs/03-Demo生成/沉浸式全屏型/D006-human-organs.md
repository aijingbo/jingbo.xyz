## 一、Demo 概述

本 Demo 以沉浸式 3D 方式展示人体主要器官系统的三维解剖结构，用户可以从任意角度观察人体内部器官的形态、位置和毗邻关系。Demo 支持分层显示（骨骼系统、肌肉系统、循环系统、呼吸系统、消化系统、神经系统等），可单独查看心脏、肺、胃、肝、脑等重要器官的精细结构，并通过点击交互了解各器官的功能和相关知识。用户可以逐层"剥开"人体，从皮肤到骨骼，深入探索人体的奥秘。

---

## 二、内容要求

### 知识点覆盖
- 人体的结构层次：细胞 → 组织 → 器官 → 系统 → 个体
- 主要器官系统：
  - 运动系统：骨骼（206块骨）、关节、骨骼肌
  - 循环系统：心脏、动脉、静脉、毛细血管
  - 呼吸系统：鼻、咽、喉、气管、支气管、肺
  - 消化系统：口腔、咽、食管、胃、小肠、大肠、肝、胰
  - 神经系统：脑（大脑、小脑、脑干）、脊髓、神经
  - 泌尿系统：肾、输尿管、膀胱、尿道
  - 内分泌系统：垂体、甲状腺、胰岛等
- 重要器官的结构与功能：
  - 心脏的四腔结构（左/右心房、左/右心室）和血液循环路径
  - 肺的肺泡结构与气体交换
  - 胃的结构与消化功能
  - 肝脏的代谢功能
  - 大脑的分区与功能
- 人体的对称性：左右对称、矢状面/冠状面/水平面

### 目标用户
- 初中生物学生（七年级《人体生理卫生》）
- 高中生物学生（必修3《稳态与环境》）
- 医学院校低年级学生（系统解剖学入门）
- 中学生物教师（课堂演示）
- 对人体奥秘感兴趣的科普爱好者

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色（#0a0f1a 深蓝黑色，带微弱的医学科技感）
- 主视觉：3D 人体模型（站立姿态，正面朝向），可分层显示各系统
- 交互方式：鼠标拖拽旋转视角、滚轮缩放、点击器官高亮显示信息、右侧系统列表切换显示层级、底部器官快速选择
- 动画：默认缓慢自转展示整体，层叠剥离开关动画（各系统淡入淡出）、器官选中时的分离展示动画（器官从原位浮出单独展示）
- 特殊功能：
  - 系统分层显示：可独立开关各个器官系统的可见性
  - 剖切视图：矢状面/冠状面/水平面 三平面剖切
  - 器官分离：选中器官后可"弹出"单独放大查看
  - 透明模式：其他系统半透明显示，突出当前选中系统
  - 搜索定位：输入器官名称快速定位并高亮

- 整体色调偏冷，以蓝紫色系为主，体现科技和医学的专业感

### 配色方案
- 骨骼系统：象牙白（#F5F0E1），带有骨质纹理和微光
- 肌肉系统：深红色（#B71C1C），带有肌肉纤维纹理
- 循环系统：
  - 动脉：鲜红色（#E53935）
  - 静脉：深蓝色（#1565C0）
  - 心脏：深红色渐变（#B71C1C → #E53935）
- 呼吸系统：浅灰蓝色（#B0BEC5），肺部带有海绵质感
- 消化系统：
  - 胃/肠：橙棕色（#D84315 → #BF360C 渐变）
  - 肝脏：红褐色（#A1887F）
  - 胰腺：淡黄色（#FFE082）
- 神经系统：淡黄色（#FFF9C4），带有神经纤维的细微发光
- 皮肤层：半透明肉色（rgba(255, 220, 200, 0.2)）
- 背景色：#0a0f1a 深蓝黑色，带有极淡的径向光效
- 强调色：青色荧光（#00E5FF）用于选中高亮和交互反馈
- 是否遵循景礴设计系统：是，深色沉浸式背景、发光效果、半透明控件

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染引擎）
- 模型方案：使用简化的程序化人体模型（基本几何体组合），或使用低面数 glTF 模型
- 由于人体结构复杂，建议采用"风格化"表现而非解剖学精确
  - 各器官使用简化的几何体组合表现大致形态和位置
  - 重点器官（心脏、脑、肺）可做更多细节
- OrbitControls（视角控制，限制合理的俯仰和缩放范围）
- Raycaster（器官拾取和高亮）
- 剖切功能：Three.js ClippingPlanes（三平面剖切）
- GSAP（系统切换动画、器官分离动画）

### 性能要求
- 首屏加载时间：< 4 秒（如果使用外部模型则需要加载时间）
- 是否需要加载动画：是，人体从轮廓线逐渐填充成形的入场动画
- 帧率目标：60fps（简单系统），45fps+（多系统同时显示）
- 模型优化：使用低面数模型，正常数 < 20000 面
- 材质优化：使用统一的 Shader 减少 Draw Call
- 建议使用程序化生成而非外部模型文件，以保证加载速度和可控性

### 响应式
- 移动端适配要求：触屏单指旋转、双指缩放
- 右侧系统列表在移动端改为底部横向滚动标签
- 信息面板移动端从底部滑出
- 自适应屏幕尺寸，人体模型始终居中
- 低性能设备默认减少同时显示的系统数量

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 梳理人体八大系统的组成和主要器官
   - 确认各器官的相对位置关系和基本功能
   - 明确教学重点：器官的形态结构与功能相适应
   - 识别常见误区：左右心房心室的位置、肝胃的左右位置等

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 采用 Three.js + 程序化建模（简化风格化表现）
   - 遵循沉浸式全屏型框架：深色背景 #0a0f1a、发光器官轮廓、半透明UI
   - 系统分层是核心交互，采用右侧列表勾选式控制
   - 器官点击选中 → 高亮 + 信息面板是二级交互
   - 采用风格化/艺术化表现而非精确解剖模型，平衡科学准确性和实现难度

3. 设计视觉方案（配色、布局、动效）
   - 背景：#0a0f1a 深蓝黑 + 中心径向微光 + 极淡网格
   - 器官材质：半透明 + 边缘发光，呈现医学影像般的质感
   - 骨骼：白色实体材质，带骨质纹理感
   - 选中效果：器官发出青色荧光，周围出现光晕
   - 系统切换：淡入淡出 + 轻微缩放动画
   - 器官分离：选中器官从原位缓慢浮出，背景其他器官半透明化
   - UI：顶部半透明导航栏、左下角播放/暂停、右下角全屏按钮、底部信息条
   - 右侧半透明系统列表面板
