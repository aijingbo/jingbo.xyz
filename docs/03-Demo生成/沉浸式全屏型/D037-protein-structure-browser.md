## 一、Demo 概述

本 Demo 通过沉浸式 3D 可视化方式，深入展示蛋白质结构 3D 浏览器的核心知识内容。用户可以在全屏幕的 3D 空间中自由旋转、缩放、点击交互，从多个角度观察和理解复杂的生物概念。通过精心设计的光影效果和交互体验，将抽象的知识转化为直观可感的三维结构，帮助学习者建立空间想象能力和深度理解。

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色（#0f1115 深灰蓝渐变）
- 主视觉：3D 立体模型 / 粒子系统 / 空间结构
- 交互方式：鼠标拖拽旋转视角、滚轮缩放、点击元素高亮显示详情、拖拽剖切
- 动画：默认自动缓慢旋转展示整体结构，播放/暂停控制，关键结构高亮闪烁动画
- 信息展示：点击模型元素后弹出半透明信息面板，包含名称、参数、说明文字

### 交互层级设计
1. **入门级**：自动旋转 + 缩放，适合快速浏览
2. **进阶级**：拖拽旋转 + 点击选中，适合深入观察
3. **专家级**：剖切模式 + 显示/隐藏图层，适合专业研究

## 四、视觉设计要求

### 整体气质
- 科技感与精密感并重，如同博物馆中的珍贵展品
- 安静、沉浸、细节丰富，鼓励用户仔细观察和探索
- 发光边缘勾勒主体轮廓，营造悬浮于黑暗空间中的科技美感
- 色彩克制而富有层次，避免过度炫技影响知识传达

### 配色方案
- 主色调：#F59E0B（琥珀金），用于主体结构和核心元素
- 背景色：#0f1115 深灰蓝底色，中心区域微微提亮形成聚光灯效果
- 强调色：#D97706，用于选中高亮和交互反馈
- 辅助色：#64748B 暖灰色，用于次要结构和标注线
- 发光效果：主体使用 #F59E0B 色的 Rim Light 边缘光
- 是否遵循景礴设计系统：是，采用深色沉浸式背景、半透明UI控件、发光主视觉效果

### 参考方向
- PhET Interactive Simulations 的 3D 交互风格
- BioDigital 人体解剖的分子可视化质感
- 苹果产品发布会 Keynote 中 3D 产品展示的精致感
- 科技馆中沉浸式展柜的布光思路
- Sketchfab 上高质量 3D 模型的渲染效果

## 五、技术实现

### 推荐技术栈
- 3Dmol.js（分子可视化核心） + Three.js（辅助场景）
- OrbitControls（视角控制：拖拽旋转 + 滚轮缩放 + 阻尼感）
- Raycaster（鼠标拾取，显示详情）
- CSS2DRenderer 或 HTML 覆盖层（信息标签显示）
- GSAP（可选，用于精细的动画过渡效果）
- lil-gui（可选，用于高级参数控制面板）

### 性能要求
- 首屏加载时间：< 2 秒（纯几何构建或轻量模型）
- 是否需要加载动画：是，主体从无到有渐入/组装的加载动画
- 帧率目标：60fps（桌面端），30fps+（移动端）
- 模型面数控制：合理优化，使用 InstanceMesh 等技术提升性能

### 响应式
- 移动端适配要求：支持触屏单指旋转、双指缩放操作
- 控件大小在移动端自动放大，确保触摸可及性
- 信息面板在移动端改为底部抽屉式，避免遮挡主视觉
- 自适应全屏，横竖屏切换无变形
