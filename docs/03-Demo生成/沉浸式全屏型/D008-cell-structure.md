## 一、Demo 概述

本 Demo 以沉浸式 3D 方式展示动物细胞和植物细胞的亚显微结构，用户可以自由旋转、缩放、"进入"细胞内部，观察各种细胞器的形态、结构和空间分布。Demo 涵盖细胞核、线粒体、内质网、高尔基体、核糖体、溶酶体、中心体（动物）、叶绿体和液泡（植物）等主要细胞器的三维结构和功能介绍。用户可以通过点击交互深入了解每个细胞器的结构特点和生理功能，在微观探索中理解"结构与功能相适应"的生物学核心观念。

## 二、内容要求

### 知识点覆盖
- 细胞的基本结构：细胞膜、细胞质、细胞核
- 主要细胞器及其功能：
  - 细胞核：遗传信息库，核膜、核仁、染色质的结构
  - 线粒体：有氧呼吸的主要场所，"动力车间"，双层膜、嵴的结构
  - 叶绿体：光合作用的场所，"养料制造车间"，类囊体堆叠成基粒
  - 内质网：蛋白质合成和加工、脂质合成的"车间"，粗面/滑面内质网
  - 高尔基体：对蛋白质进行加工、分类和包装的"车间"及"发送站"
  - 核糖体：蛋白质合成的场所，游离/附着核糖体
  - 溶酶体："消化车间"，分解衰老损伤的细胞器
  - 中心体：与细胞有丝分裂有关，动物细胞和低等植物细胞特有
  - 液泡：植物细胞特有，调节细胞内环境
- 动物细胞与植物细胞的区别：细胞壁、叶绿体、液泡、中心体
- 生物膜系统：细胞膜、核膜、细胞器膜共同构成
- 细胞的整体性：各细胞器协调配合完成生命活动（如分泌蛋白的合成与分泌）

### 目标用户
- 高中生物学生（必修1《分子与细胞》模块）
- 大学生物学入门课程学习者
- 中学生物教师（课堂演示）
- 对微观生命世界感兴趣的科普爱好者

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色（#0a1510 深墨绿色，带生物科技感）
- 主视觉：3D 动物/植物细胞模型（半透明细胞膜，内部各细胞器悬浮其中）
- 交互方式：鼠标拖拽旋转视角、滚轮缩放（可从细胞整体缩放到单个细胞器）、点击细胞器高亮显示信息、右侧细胞器列表快速定位、顶部动植物细胞切换
- 动画：默认缓慢自转，细胞质微流动效果，细胞器的微小悬浮运动，线粒体的脉动
- 特殊功能：
  - 细胞类型切换：动物细胞 / 植物细胞
  - 显示模式：实体模式 / 透明模式 / 线框模式
  - 分层显示：可独立显示/隐藏各类细胞器
  - 剖切功能：沿任意平面剖切细胞，观察内部切面
  - 飞行进入：相机飞入细胞内部，从内部视角观察
  - 过程演示：分泌蛋白合成与分泌路径动画演示

## 四、视觉设计要求

### 整体气质
- 微观生命世界的精致与灵动，如同步入一个微型宇宙
- 温暖、有机、富有生命力，与物理/化学类 Demo 形成差异
- 细胞器表面有生物膜的质感，半透明、有光泽、微微脉动
- 整体色调以绿蓝色系为主，体现生命和自然的感觉

### 配色方案
- 细胞膜：半透明浅紫色（rgba(200, 180, 255, 0.15)），边缘有微弱发光
- 细胞壁（植物）：淡绿色半透明（rgba(150, 200, 150, 0.2)），纤维质感
- 细胞核：深紫红色（#8E24AA），带有核孔的细微纹理，核仁更亮
- 线粒体：橙红色（#E65100），内膜折叠形成嵴的纹理，有脉动发光
- 叶绿体（植物）：翠绿色（#2E7D32），内部有类囊体堆叠的基粒结构
- 内质网：淡蓝色（#64B5F6），膜状折叠结构，粗面内质网有核糖体颗粒
- 高尔基体：金黄色（#FFB300），扁平囊堆叠结构
- 核糖体：深灰色小点（#455A64）
- 溶酶体：深红色小球（#C62828），半透明
- 中心体（动物）：橙黄色小管状（#FF9800），垂直排列
- 液泡（植物）：大的淡青色半透明球体（rgba(128, 222, 234, 0.3)）
- 细胞质基质：半透明胶状质感，有微弱的颗粒流动
- 背景色：#0a1510 深墨绿色，带微弱的生命粒子光点
- 强调色：荧光绿（#76FF03）用于选中高亮和交互反馈
- 是否遵循景礴设计系统：是，深色沉浸式背景、发光效果、半透明控件

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染）
- 细胞器模型：使用基本几何体组合（球体、环面、平面折叠等）
  - 细胞核：球体
  - 线粒体：胶囊体/拉伸球体 + 内部嵴结构
  - 内质网：折叠平面 + 核糖体颗粒
  - 高尔基体：堆叠的扁圆盘
  - 叶绿体：双凸面透镜形 + 内部基粒
- 细胞膜：SphereGeometry + 半透明材质 + 边缘发光
- 自定义 Shader：实现生物膜的半透明、边缘发光、脉动效果
- OrbitControls（视角控制）
- Raycaster（细胞器拾取）
- GSAP（细胞切换动画、飞行进入动画、分泌蛋白路径动画）

### 性能要求
- 首屏加载时间：< 3 秒（纯程序化构建，无外部模型）
- 是否需要加载动画：是，细胞从粒子逐渐凝聚成形的入场动画
- 帧率目标：60fps（桌面端），45fps+（移动端）
- 面数控制：< 15000 面（使用简化的细胞器模型）
- 材质优化：尽量复用材质，减少 Draw Call

### 响应式
- 移动端适配要求：触屏单指旋转、双指缩放
- 右侧细胞器列表在移动端改为底部横向滚动
- 信息面板移动端从底部滑出
- 自适应屏幕尺寸，细胞模型始终居中
- 低性能设备简化细胞器细节
