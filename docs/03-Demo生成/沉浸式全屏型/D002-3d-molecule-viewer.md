## 一、Demo 概述

本 Demo 是一个沉浸式 3D 分子结构交互查看器，内置多种常见分子模型（水、甲烷、氨、二氧化碳、苯、乙醇、葡萄糖等），用户可以在深色沉浸式环境中自由旋转、缩放、切换分子，观察分子的空间构型、键角、键长等立体化学特征。Demo 重点展示价层电子对互斥理论（VSEPR）、杂化轨道理论以及分子的三维空间结构与化学性质之间的关系，帮助学生建立微观世界的空间想象力。

## 二、内容要求

### 知识点覆盖
- 分子的空间构型：直线形、平面三角形、正四面体、三角锥形、V形、八面体等
- 价层电子对互斥理论（VSEPR）：中心原子价层电子对数与分子空间构型的关系
- 杂化轨道理论：sp、sp²、sp³ 杂化与分子构型的对应关系
- 键参数：键长、键角、键能的概念及其对分子性质的影响
- 极性分子与非极性分子：分子空间构型对分子极性的影响
- 同分异构体：以乙醇和二甲醚为例展示相同分子式不同结构

### 目标用户
- 高中化学学生（必修2《物质结构 元素周期律》、选修3《物质结构与性质》）
- 大学普通化学/无机化学入门学习者
- 中学化学教师（课堂演示分子空间构型）

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色（#1a1a1a 深灰渐变，带微弱星空粒子点缀）
- 主视觉：3D 分子球棍模型 / 空间填充模型（可切换）
- 交互方式：鼠标拖拽旋转、滚轮缩放、点击原子高亮显示信息、底部分子选择器切换分子、双击重置视角
- 动画：默认自动缓慢旋转，键角和键长标注的动态显示动画，分子切换时的溶解过渡效果
- 特殊功能：显示/隐藏孤电子对、显示杂化轨道轮廓、键角测量工具

## 四、视觉设计要求

### 整体气质
- 精密的科技感，如同在高端化学实验室中观察分子模型
- 纯净、深邃、富有秩序感，让用户专注于分子本身的结构美
- 分子表面带有微弱的玻璃质感和环境光反射，显得真实而高级

### 配色方案
- 原子配色遵循 CPK 标准配色方案：
  - 氢 H：白色（#FFFFFF）
  - 碳 C：炭灰色（#404040）
  - 氮 N：深蓝色（#3050F8）
  - 氧 O：红色（#FF0D0D）
  - 氟 F：黄绿色（#90E050）
  - 氯 Cl：绿色（#1FF01F）
  - 硫 S：黄色（#FFFF30）
  - 磷 P：橙色（#FF8000）
  - 钠 Na：紫色（#AB5CF2）
- 化学键：浅灰色金属质感（#C0C0C0），单键/双键/三键分别用1根/2根/3根圆柱表示
- 孤电子对：淡紫色半透明云团（rgba(180, 150, 255, 0.5)）
- 背景色：#1a1a1a 深灰底色，配合微弱的径向光斑
- 强调色：青色荧光（#00BCD4）用于选中高亮、测量标注
- 是否遵循景礴设计系统：是，深色沉浸式背景、发光效果、半透明圆形控件、底部信息条

### 参考方向

- RCSB Protein Data Bank 的 3D 分子渲染
- ChemDraw 3D 的分子展示风格

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染）
- 3Dmol.js 或纯 Three.js 构建（推荐纯 Three.js 以获得更大设计自由度）
- 分子数据：内置 JSON 格式的分子坐标数据（无需外部 PDB 文件）
- OrbitControls（视角控制）
- Raycaster + 自定义 Shader（点击选中高亮效果）
- Tween.js / GSAP（分子切换动画、平滑过渡）

### 性能要求
- 首屏加载时间：< 2.5 秒
- 是否需要加载动画：是，分子从粒子云凝聚成形的入场动画
- 帧率目标：稳定 60fps（小分子），45fps+（大分子如葡萄糖）
- 内存占用：< 100MB
- 建议预加载 3-5 个常用分子数据，其他按需加载

### 响应式
- 移动端适配要求：完整支持触屏操作（单指旋转、双指缩放）
- 分子选择器在移动端改为底部横向滚动列表
- 信息面板在移动端从底部滑出，不遮挡主视觉
- 自适应各种屏幕尺寸，分子始终居中显示
- 低性能设备自动降级：降低模型细分、关闭反射效果

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 梳理 VSEPR 理论的核心要点和典型分子构型
   - 确认各分子的精确键角数据（如水 104.5°、甲烷 109°28'、氨 107°等）
   - 明确杂化轨道类型与分子构型的对应关系
   - 识别学生常见误区：混淆电子对空间构型与分子空间构型

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 采用 Three.js 构建 3D 场景，纯程序化生成分子几何体
   - 遵循沉浸式全屏型框架：深色背景 #1a1a1a、发光主体、极简UI
   - 底部分子选择器采用半透明胶囊式按钮，不抢主体视线
   - 交互层级清晰：旋转缩放为一级交互，分子切换为二级交互

3. 设计视觉方案（配色、布局、动效）
   - 背景：#1a1a1a 深灰径向渐变，四周暗中心亮，模拟聚光灯效果
   - 分子材质：PBR 物理材质，带有微弱的环境反射和次表面散射感
   - 化学键：金属质感圆柱，双键/三键用平行圆柱表示
   - 选中效果：被点击的原子发出青色荧光辉光，周围出现信息浮层
   - 分子切换：旧分子分解为粒子飘散，新分子从粒子凝聚成形
   - UI：顶部半透明导航栏、左下角播放/暂停、右下角全屏、底部信息条 + 分子选择器

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
