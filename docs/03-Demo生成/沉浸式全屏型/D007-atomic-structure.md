## 一、Demo 概述

本 Demo 以沉浸式 3D 方式展示原子的核式结构模型，将微观的原子世界放大到可见尺度，呈现原子核与核外电子的空间关系。用户可以观察电子云的概率分布、能级跃迁、以及不同元素原子的结构差异。Demo 通过粒子动画和发光效果，形象地表现电子的波粒二象性和量子化特征，帮助学生建立原子结构的空间想象，理解原子序数、核外电子排布、同位素等核心概念。

## 二、内容要求

### 知识点覆盖
- 原子的组成：原子核（质子+中子）和核外电子
- 原子核式结构模型：卢瑟福 α 粒子散射实验与核式结构的提出
- 原子的尺度：原子核直径约 10⁻¹⁵m，原子直径约 10⁻¹⁰m，原子核体积极小
- 核外电子排布：
  - 电子层（K/L/M/N...）和能级（s/p/d/f）
  - 泡利不相容原理、能量最低原理、洪特规则
  - 前 20 号元素的核外电子排布规律
- 电子云模型：电子在核外空间的概率分布，而非确定轨道
- 原子序数、核电荷数、质子数、核外电子数的关系
- 同位素概念：质子数相同中子数不同的原子
- 能级跃迁：电子吸收/释放光子在能级间跃迁

### 目标用户
- 初中物理/化学学生（原子结构入门）
- 高中物理学生（选修3-5 波粒二象性 / 原子结构）
- 高中化学学生（必修2 物质结构、选修3 原子结构与性质）
- 中学理化教师（课堂演示）

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色（#050810 深黑蓝，带量子粒子噪点感）
- 主视觉：3D 原子核（质子+中子聚集）+ 核外电子云（粒子系统）
- 交互方式：鼠标拖拽旋转视角、滚轮缩放、点击电子层高亮显示、右侧元素周期表选择器切换元素、底部动画控制
- 动画：
  - 原子核的微振动和发光脉动
  - 电子云的流动闪烁效果（表现电子的概率分布）
  - 能级跃迁动画（电子从低能级到高能级的激发，伴随光子吸收/释放）
  - 电子层切换时的粒子消散/重组效果
- 特殊功能：
  - 元素切换：前 20 号元素可选，展示不同的电子排布
  - 显示模式：电子云模型 / 轨道模型（玻尔行星模型）切换
  - 剖切功能：沿任意平面剖切，观察原子内部结构
  - 同位素切换：同一元素的不同同位素（如氕/氘/氚）
  - 尺度对比：可放大原子核，直观感受"原子内部绝大部分是空的"

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染）
- 原子核：球体组合（质子+中子），使用发光材质
- 电子云：Points 粒子系统（数千个粒子，通过 Shader 控制闪烁和流动）
- 电子层轨道：TorusGeometry 圆环（玻尔模型时显示）
- 自定义 ShaderMaterial：实现电子云的透明度变化、发光效果
- OrbitControls（视角控制）
- Raycaster（点击电子层/原子核交互）
- GSAP（元素切换动画、能级跃迁动画）

### 性能要求
- 首屏加载时间：< 2 秒（纯程序化生成，无外部资源）
- 是否需要加载动画：是，原子从虚无中凝聚生成的入场动画
- 帧率目标：60fps（桌面端），45fps+（移动端）
- 粒子数量：电子云粒子 2000-5000 个（根据性能动态调整）
- 优化策略：使用 Points 而非 Mesh 渲染电子，共享几何体和材质

### 响应式
- 移动端适配要求：触屏单指旋转、双指缩放
- 右侧元素选择器在移动端改为底部横向滚动
- 信息面板移动端从底部滑出
- 自适应屏幕尺寸，原子始终居中显示
- 低性能设备自动减少电子云粒子数量
