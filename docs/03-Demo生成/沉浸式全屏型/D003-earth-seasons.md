## 一、Demo 概述

本 Demo 通过沉浸式 3D 模拟展示地球围绕太阳公转的过程，直观解释四季更替的形成原因。用户可以观察到地球 23.5° 地轴倾斜、公转轨道、太阳直射点的南北移动，以及不同纬度地区在不同季节的昼夜长短变化和太阳高度角差异。Demo 采用可交互的时间控制，用户可以拖动时间滑块快速浏览一年四季的变化，或定格在二分二至日进行详细观察。

## 二、内容要求

### 知识点覆盖
- 地球公转的基本特征：方向（自西向东）、轨道（近似正圆的椭圆）、周期（回归年）
- 黄赤交角：23°26′ 的地轴倾斜及其地理意义
- 太阳直射点的回归运动：春分/秋分直射赤道、夏至直射北回归线、冬至直射南回归线
- 四季的形成原因：太阳高度角的季节变化 + 昼夜长短的季节变化
- 昼夜长短的变化规律：不同纬度、不同季节的昼长变化
- 五带的划分：热带、南北温带、南北寒带的范围和特征
- 正午太阳高度角的计算与变化规律

### 目标用户
- 初中地理学生（七年级《地球的运动》章节）
- 高中地理学生（必修1《行星地球》模块）
- 中小学地理教师（课堂演示地球运动）
- 地理科普爱好者

## 四、视觉设计要求

### 整体气质
- 宇宙探索的壮美与神秘感，如同从太空视角观察地日系
- 宁静、深邃、充满秩序感，展现天体运行的和谐之美
- 地球和太阳均有发光效果，悬浮于浩瀚星空中

### 配色方案
- 太阳：金黄色渐变（中心 #FFF9C4 → 边缘 #FF8F00），外层带有日冕状辉光
- 地球：蓝色星球，海洋 #1565C0、陆地 #2E7D32、云层 #ECEFF1，带有大气层散射光晕
- 公转轨道：淡白色半透明椭圆线（rgba(255,255,255,0.15)），当前位置高亮
- 晨昏线：淡金色渐变（rgba(255, 215, 0, 0.3)），区分昼半球与夜半球
- 回归线/极圈：淡青色虚线（rgba(0, 188, 212, 0.5)）
- 背景色：#0a0a14 深蓝黑色，分布大量星点粒子（白色/淡黄色小点）
- 强调色：金黄色（#FFC107）用于标注和交互反馈
- 是否遵循景礴设计系统：是，深色沉浸式背景（宇宙星空）、发光天体、半透明控件

### 参考方向
- 太阳系模拟器（Solar System Scope）的视觉风格
- NASA 地球观测卫星图像的真实感
- 苹果 macOS 天文壁纸的精致感

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染）
- 地球纹理：使用 Canvas 程序化生成或使用低分辨率地球贴图（256x128 即可）
- 星点背景：Points + 随机分布的粒子系统
- OrbitControls（视角控制，限制俯仰角避免翻转混乱）
- 太阳辉光：Sprite + 渐变贴图 + 加法混合模式
- 大气层效果：自定义 ShaderMaterial 实现大气散射边缘发光
- TWEEN.js（时间轴动画、平滑过渡）

### 性能要求
- 首屏加载时间：< 3 秒（地球纹理是主要加载项）
- 是否需要加载动画：是，从星空粒子中逐渐凝聚出太阳和地球
- 帧率目标：稳定 60fps
- 纹理优化：地球纹理使用压缩格式，云层使用半透明层
- 粒子数量：星空背景 2000-3000 个粒子点

### 响应式
- 移动端适配要求：触屏单指旋转、双指缩放
- 时间轴控件在移动端适当增高，确保触摸操作
- 信息面板在移动端改为底部滑出式
- 自适应横屏和竖屏，地球始终在视野中心
- 低性能设备自动减少星点粒子数量

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 梳理地球公转的关键参数：轨道半径、公转周期、黄赤交角 23°26′
   - 明确教学重点：四季形成的根本原因是地轴倾斜而非距离太阳远近
   - 确认常见误区：学生常误以为夏天热是因为地球离太阳近
   - 理清二分二至日太阳直射点位置和昼夜长短分布规律

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 采用 Three.js 构建 3D 宇宙场景，太阳和地球为核心视觉
   - 遵循沉浸式全屏型框架：深色星空背景、发光天体、半透明UI控件
   - 底部时间轴是核心交互控件，采用半透明胶囊式设计
   - 视角控制支持自由旋转，同时提供预设视角快捷切换

3. 设计视觉方案（配色、布局、动效）

   - 地球：蓝色海洋 + 绿色陆地 + 白色云层 + 边缘大气辉光
