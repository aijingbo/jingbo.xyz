## 一、Demo 概述

本 Demo 以沉浸式 3D 方式展示多种典型晶体的微观结构，包括简单立方、体心立方、面心立方、六方最密堆积、金刚石型、NaCl 型、CsCl 型、闪锌矿型等常见晶体结构。用户可以自由旋转、缩放、剖切晶胞，观察原子的空间排布方式、配位数、晶胞参数、以及原子的空间利用率。Demo 通过交互式的逐层拆解和动画演示，帮助学生理解晶体的周期性结构特征和紧密堆积原理。

## 二、内容要求

### 知识点覆盖
- 晶体与非晶体的区别：晶体具有规则的几何外形、各向异性、固定熔点
- 晶胞的概念：晶胞是晶体结构的最小重复单元，晶胞的无隙并置形成晶体
- 三类晶体结构：
  - 金属晶体：简单立方（SC）、体心立方（BCC）、面心立方（FCC）、六方最密堆积（HCP）
  - 离子晶体：NaCl 型、CsCl 型、闪锌矿（ZnS）型、萤石（CaF₂）型
  - 原子晶体：金刚石型、SiO₂ 晶体
- 紧密堆积原理：面心立方和六方最密堆积的空间利用率（74%）、配位数（12）
- 配位数与空间利用率的计算
- 晶胞中原子数的计算方法：顶点(1/8)、棱上(1/4)、面心(1/2)、体内(1)
- 晶格能与离子晶体性质的关系

### 目标用户
- 高中化学选修3《物质结构与性质》学生
- 大学无机化学/材料科学基础学习者
- 中学化学教师（晶体结构教学演示）
- 材料科学爱好者

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色（#0d1117 深蓝灰，类似 GitHub Dark 底色）
- 主视觉：3D 晶胞模型，可扩展为多晶胞阵列
- 交互方式：鼠标拖拽旋转、滚轮缩放、点击原子高亮、右侧晶体列表切换、顶部显示模式切换
- 动画：默认缓慢自动旋转，晶胞拆解动画（逐层展开）、紧密堆积动画演示、晶胞扩展动画

  - 显示模式切换：球棍模型 / 空间填充模型 / 线框模型

  - 配位数高亮：点击一个原子，高亮显示其所有配位原子
  - 晶胞参数标注：显示晶胞边长 a、b、c 和夹角 α、β、γ

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染）
- 纯程序化构建晶体结构（根据晶格参数和原子坐标生成）
- InstancedMesh（多晶胞扩展时使用实例化渲染提升性能）
- OrbitControls（视角控制）
- Raycaster（原子拾取、配位数高亮）
- 剖切平面：Three.js ClippingPlanes
- GSAP（晶胞拆解动画、过渡动画）

### 性能要求
- 首屏加载时间：< 2.5 秒（纯几何构建，无外部模型）
- 是否需要加载动画：是，晶胞从粒子凝聚成结构的入场动画
- 帧率目标：60fps（单晶胞），45fps+（3x3x3 扩展）
- 面数控制：单晶胞 < 3000 面，使用低多边形球体配合法线贴图
- 实例化渲染：多晶胞扩展必须使用 InstancedMesh，避免性能崩溃

### 响应式
- 移动端适配要求：触屏单指旋转、双指缩放
- 右侧晶体列表在移动端改为底部横向滚动选择器
- 信息面板移动端从底部滑出
- 自适应各种屏幕尺寸
- 低性能设备默认关闭扩展模式和空间填充模式
