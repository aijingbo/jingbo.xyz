## 一、Demo 概述

本 Demo 通过沉浸式 3D 可视化展示 DNA 双螺旋分子的精细结构，用户可以自由旋转、缩放、切割观察 DNA 的双螺旋骨架、碱基配对方式以及氢键连接。Demo 涵盖了脱氧核糖核酸的基本组成单位、四种含氮碱基（A/T/C/G）的互补配对原则、以及 DNA 反向平行双螺旋结构特征等核心知识点。学生通过交互式探索，能够直观理解 DNA 作为遗传物质的结构基础与其功能之间的关系。

## 二、内容要求

### 知识点覆盖
- DNA 的化学组成：脱氧核糖、磷酸基团、含氮碱基（腺嘌呤A、胸腺嘧啶T、胞嘧啶C、鸟嘌呤G）
- 碱基互补配对原则：A-T 之间形成两条氢键，G-C 之间形成三条氢键
- 双螺旋结构特征：右手螺旋、反向平行、螺距 3.4nm、每圈 10 个碱基对
- 大沟与小沟的形态特征及其生物学意义
- DNA 作为遗传信息载体的结构基础

### 目标用户
- 高中生物学学生（必修2《遗传与进化》模块）
- 大学生物学入门课程学习者
- 中学生物学教师（课堂演示辅助教学）

## 三、呈现框架

### 沉浸式全屏型
- 背景：深色（#0f0f0f 深灰渐变）
- 主视觉：3D DNA 双螺旋分子模型（包含糖-磷酸骨架、碱基对、氢键）
- 交互方式：鼠标拖拽旋转视角、滚轮缩放、点击碱基高亮显示信息、拖拽剖切面对 DNA 进行横截面观察
- 动画：默认自动缓慢旋转展示整体结构，播放/暂停控制，碱基配对高亮闪烁动画
- 剖切模式：可沿螺旋轴方向剖切，展示内部碱基堆叠结构

## 五、技术实现

### 推荐技术栈
- Three.js（核心 3D 渲染引擎）
- 纯几何构建 DNA 结构（球体+圆柱体组合，无需外部模型文件）
- OrbitControls（视角控制：拖拽旋转 + 滚轮缩放）
- Raycaster（鼠标拾取碱基对，显示详情）
- CSS3DRenderer 或 HTML 覆盖层（信息标签显示）
- GSAP（可选，用于精细的动画过渡效果）

### 性能要求
- 首屏加载时间：< 2 秒（纯几何构建，无外部资源依赖）
- 是否需要加载动画：是，DNA 分子从无到有逐层组装的加载动画
- 帧率目标：60fps（桌面端），30fps+（移动端）
- 模型面数控制：< 5000 面（使用低多边形球体和圆柱体，配合法线贴图增强质感）

### 响应式
- 移动端适配要求：支持触屏单指旋转、双指缩放操作
- 控件大小在移动端自动放大，确保触摸可及性
- 信息面板在移动端改为底部抽屉式，避免遮挡主视觉
- 自适应全屏，横竖屏切换无变形
