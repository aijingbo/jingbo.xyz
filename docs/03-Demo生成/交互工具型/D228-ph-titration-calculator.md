## 一、Demo 概述

本 Demo 是一个交互式化学工具，用户可以通过调节各种参数，实时观察pH 计算器与酸碱滴定模拟的变化规律。通过动手操作和即时反馈，帮助学习者建立直觉理解，探索不同条件下的行为模式。工具提供多种预设场景和可调参数，既适合课堂演示，也适合学生自主探索。

## 二、内容要求

### 知识点覆盖
- pH 计算器与酸碱滴定模拟的基本原理和公式
- 各参数对结果的影响规律
- 典型场景下的行为特征
- 相关化学学定律和应用
- 参数变化的边界条件和极值情况

### 目标用户
- 中学/大学化学学生（自主探索学习）
- 化学教师（课堂演示工具）
- 对化学现象感兴趣的爱好者
- 需要直观理解该概念的初学者

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 主参数滑块：2-4 个核心参数，每个有明确的范围和步长
  - 模式选择：下拉菜单或切换按钮，选择不同的工作模式
  - 显示选项：复选框组，控制显示/隐藏各种辅助元素
  - 预设场景：3-5 个一键切换的预设配置
- 实时反馈：
  - 主可视化区域实时响应参数变化
  - 数据面板显示关键数值和计算结果
  - 参数变化时有平滑过渡动画
  - 超限或特殊情况有视觉提示
- 预设模式：
  - 预设 1：默认演示（最典型的参数配置）
  - 预设 2：边界情况（参数取极值）
  - 预设 3：对比案例（两种不同条件对比）
- 播放/暂停：
  - 支持自动播放模式（参数自动变化）
  - 播放速度可调
  - 单步模式（逐帧观察）

### 布局结构
- 上方/左侧：主可视化画布（占 60-70% 空间）
- 下方/右侧：控制面板（占 30-40% 空间）
- 底部：状态栏/数据显示区

## 五、技术实现

### 推荐技术栈
- 纯 Canvas 2D 或 SVG 绘制可视化内容
- JavaScript 实现核心计算逻辑
- 原生 CSS 打造精致滑块和按钮样式
- 或使用 D3.js 辅助图表绘制
- GSAP（可选，用于平滑数值过渡动画）

### 性能要求
- 首屏加载时间：< 500ms
- 是否需要加载动画：否，内容轻量可直接渲染
- 动画帧率：60fps，参数变化时实时响应
- 计算性能：确保滑块拖动时无卡顿，实时更新

### 响应式
- 移动端适配要求：控制面板在小屏上可折叠或变为底部抽屉
- 画布区域自适应屏幕尺寸
- 触控设备支持手指滑动调节滑块
- 最小支持宽度：375px
