## 一、Demo 概述

本 Demo 通过交互式色轮和实时色彩混合演示，帮助学习者理解色彩理论的核心概念。用户可以探索三原色、间色、复色的关系，学习互补色、类似色、三角色等经典配色方案，并通过调节色相、饱和度、明度三个维度直观感受色彩的变化。配合实时颜色对比、配色方案生成和色彩心理联想，为艺术设计初学者提供沉浸式的色彩学习体验。

## 二、内容要求

### 知识点覆盖
- 三原色（红、黄、蓝）与色彩混合原理：原色混合产生间色，间色混合产生复色
- 色环/色轮的结构：12色色轮的构成与排列规律
- 色彩三要素：色相（Hue）、饱和度（Saturation）、明度（Value/Brightness）的含义与相互关系
- 互补色（Complementary）：色轮上相对位置的颜色，对比强烈
- 类似色（Analogous）：色轮上相邻的颜色，和谐统一
- 三角色（Triadic）：色轮上等距三角分布的三种颜色，平衡丰富
- 分裂互补色（Split Complementary）：一种颜色与其互补色两侧的颜色组合
- 冷暖色调：色彩的温度感及其心理效应
- 色彩的情感与象征：不同颜色带给人的心理感受和文化含义
- RGB 与 CMYK 色彩模式的区别（加色法 vs 减色法）

### 目标用户
- 美术/设计初学者，学习色彩理论基础
- 中小学美术课学生和教师
- UI/UX 设计入门者，学习配色基础
- 对色彩感兴趣的普通大众

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 色相（Hue）：范围 0°-360°，步长 1°，默认值 210°（蓝色）
  - 饱和度（Saturation）：范围 0%-100%，步长 1%，默认值 80%
  - 明度（Value）：范围 0%-100%，步长 1%，默认值 70%
  - 配色方案：下拉选择，选项包括【单色 / 互补色 / 类似色 / 三角色 / 分裂互补 / 四方色】，默认互补色
  - 色轮模式：下拉选择，选项包括【RYB 艺术色轮 / RGB 光色轮 / CMY 印刷色轮】，默认 RYB 艺术色轮
  - 显示选项：多选开关组，包括【色值标签 / 色相环刻度 / 色彩名称 / 明暗渐变带 / 冷暖分区】，默认显示色值标签+色相环刻度
- 实时反馈：
  - 中央大色块实时显示当前选中的颜色
  - 色轮上高亮显示当前配色方案的所有颜色
  - 下方配色方案面板显示完整的配色组合，每个色块可点击选中
  - 右侧信息面板显示：HEX 值、RGB 值、HSV 值、色彩名称、冷暖属性
  - 调节 H/S/V 滑块时，色轮上的选取点实时移动
  - 色轮可直接点击选色，滑块数值同步更新
- 预设模式：
  - 预设1：经典三原色（红/黄/蓝）——基础色彩教学
  - 预设2：大自然配色（绿为主的类似色）——自然和谐感
  - 预设3：高对比互补（橙蓝互补）——强烈视觉冲击
  - 预设4：莫兰迪色系（低饱和配色）——高级灰调美学
  - 预设5：暖色调组合（红橙黄类似色）——温暖热情氛围
- 播放/暂停：
  - 支持色相自动循环播放，观察色轮旋转效果
  - 播放速度可调（慢速/中速/快速）
  - 暂停时可精确调节到任意色相

## 四、视觉设计要求

### 整体气质
- 清新艺术感 + 精致设计感
- 色彩丰富但不杂乱，有高级感
- 像专业设计师的色彩工作台

### 配色方案
- 主色调：随当前选中颜色动态变化（取当前色的同色系深色调）
- 背景色：暖白 #faf8f5（默认），可切换为纯黑/纯白以观察颜色在不同背景下的效果
- 强调色：
  - 色轮外圈：彩色渐变，按色相顺序排列
  - 选中标记：白色圆环 + 阴影，在色轮上突出显示
  - 配色方案色块：带圆角的方形色块，悬停有放大效果
- 是否遵循景礴设计系统：是，暖白背景 + 暖灰控制面板 + 精致控件，同时允许色彩展示区有丰富的色彩变化

### 参考方向
- Adobe Color 色轮工具的专业感
- Pantone 色卡的精致呈现方式
- 现代设计工具（Figma/Sketch）的取色器设计

## 五、技术实现

### 推荐技术栈
- Canvas 2D 绘制色轮和色彩渐变，性能好、颜色精准
- SVG 绘制色块和交互元素，便于点击交互
- 纯 JavaScript 实现色彩空间转换（HSV ↔ RGB ↔ HEX）
- 无需额外库，轻量实现

### 性能要求
- 首屏加载时间：< 400ms
- 是否需要加载动画：否
- 交互响应：滑块调节时颜色实时更新，无卡顿
- 色轮渲染：使用 Canvas 预渲染色轮图，交互时只更新选中标记

### 响应式
- 移动端适配要求：小屏下色轮尺寸自适应，控制面板可折叠
- 色轮保持正圆形，不被拉伸
- 触控支持直接点击色轮选色

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：让学习者通过交互理解色彩理论基础概念
   - 重点：色彩三要素、色轮结构、常见配色方案
   - 难点：RGB加色法与RYB减色法的区别与联系
   - 注意事项：色值计算要准确，配色方案要符合专业标准
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（色轮+大色块+配色方案展示），下20%控制面板
   - 左侧参数滑块组：色相、饱和度、明度
   - 右侧功能按钮组：播放/暂停 + 配色方案选择 + 色轮模式 + 预设按钮
   - 画布中央为色轮，右侧为信息面板，下方为配色方案条
3. 设计视觉方案（配色、布局、动效）
   - 色轮：圆形渐变，从外圈高饱和到内圈低饱和（或从亮到暗）
   - 选中标记：白色描边圆环，有轻微外发光，在色轮上醒目但不刺眼
   - 大色块：圆角矩形，占据画布显著位置，颜色饱满
   - 配色方案色块：一排圆角方块，悬停时轻微上浮+阴影加深
   - 色值标签：等宽字体，深灰色，专业感
   - 控制面板：暖灰背景，滑块轨道使用渐变色（色相滑块用彩虹渐变）
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一个简单的取色器？有没有教学价值？
   - 优化点：加入色彩混合动画演示——展示三原色如何混合出间色和复色
   - 增加"色彩情绪"标签——每个颜色附带情感联想词
   - 加入色轮模式切换动画——RYB 与 RGB 色轮的平滑过渡对比
5. 开始编码实现
   - 先实现色彩计算模块：HSV/RGB/HEX 互转、配色方案生成算法
   - 再实现 Canvas 色轮渲染和 SVG 交互元素
   - 最后实现控制面板和交互逻辑
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 测试色相滑块拖动时颜色是否平滑过渡
   - 验证所有配色方案的色值计算是否正确
   - 检查色轮点击选色与滑块的双向联动
   - 移动端色轮点击精度测试
7. 保存到指定路径
