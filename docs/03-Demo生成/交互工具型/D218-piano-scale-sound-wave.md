## 一、Demo 概述

本 Demo 将音乐与物理结合，通过交互式钢琴键盘和实时声波可视化，展示声音的物理本质。用户可以点击琴键弹奏音符，同时观察对应的声波波形、频谱分析和音高频率。Demo 支持多种音阶模式、波形选择（正弦波/方波/三角波/锯齿波），以及和声叠加效果。通过视听结合的方式，帮助学生理解声音的频率、振幅、谐波等物理概念，建立音乐与物理之间的联系。

## 二、内容要求

### 知识点覆盖
- 声音的本质：机械波与振动
- 音高与频率的关系：频率越高音越高
- 十二平均律：半音频率比为 2^(1/12)
- 音阶的构成：自然大调、自然小调、五声音阶等
- 纯律与平均律的区别
- 波形与音色：正弦波、方波、三角波、锯齿波的频谱差异
- 谐波与泛音：基频与倍频的关系
- 声波的干涉与拍频现象
- 分贝与振幅的关系（对数刻度）

### 目标用户
- 初中物理声学部分
- 高中物理波动与声波
- 音乐启蒙与乐理入门
- 音乐教师用于音准和乐理教学

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 键盘范围：1个八度 / 2个八度 / 3个八度，默认 2个八度
  - 波形选择：正弦波 / 方波 / 三角波 / 锯齿波 / 钢琴采样，默认正弦波
  - 音量：0-100%，步长 1%，默认 70%
  - 衰减时间：0.1-5.0 秒，步长 0.1，默认 1.0（模拟钢琴延音）
  - 显示模式：波形图 / 频谱图 / 同时显示，默认同时显示
  - 音阶选择：C大调 / A小调 / 五声音阶 / 全音阶 / 半音阶，默认C大调
  - 显示选项：显示频率值 / 显示音名 / 显示键盘快捷键 / 显示谐波标注，可多选
  - 特效模式：普通 / 回声 / 混响，默认普通
  - 自动播放：内置旋律（小星星/欢乐颂/卡农片段），可一键播放
- 实时反馈：
  - 上半部分：波形 + 频谱可视化区域
    - 波形图：实时显示声波的时域波形，不同音高用不同颜色
    - 频谱图：显示各频率成分的能量分布（柱状频谱或连续频谱）
  - 下半部分：钢琴键盘
    - 点击琴键发出对应频率的声音
    - 按下的琴键高亮变色
    - 黑键白键布局与真实钢琴一致
  - 音符信息面板：显示当前音的音名、频率(Hz)、波长、在频谱中的位置
  - 多音同时弹奏时，波形叠加显示，频谱多条谱线
- 预设模式：
  - 预设1：C大调音阶演示（Do Re Mi Fa Sol La Si Do）
  - 预设2：波形音色对比（同一音符不同波形）
  - 预设3：谐波分析（展示方波的奇次谐波）
  - 预设4：拍频现象（两个相近频率叠加产生的拍）
  - 预设5：五声音阶（中国风即兴演奏）
  - 预设6：八度关系（同一音名不同八度的频率对比）
- 播放/暂停：
  - 支持内置旋律自动播放
  - 支持播放/暂停
  - 支持停止并清除当前声波
  - 速度调节：0.5x / 1x / 1.5x / 2x（旋律播放速度）
  - 支持录音与回放（简单模式）

### 配色方案

- 背景色：暖白色 #faf8f5（画布区域）
- 强调色：
  - 白键：象牙白 #fdfefe（带轻微木纹渐变）
  - 黑键：深黑 #2c3e50（带高光）
  - 按下的键：金黄色 #f1c40f（发光效果）
  - 波形曲线：渐变色（低音蓝 → 高音红）#3498db → #e74c3c
  - 频谱柱：彩虹渐变色（按频率从低到高）
  - 基频标记：金色 #f1c40f
  - 泛音标记：浅金色 #f9e79f
  - 音名标注：深灰色 #34495e
- 是否遵循景礴设计系统：是，上下分栏布局（上方波形+下方键盘），精密仪器风格，控制面板精致

## 五、技术实现

### 推荐技术栈
- Web Audio API 生成声音和分析频谱
- Canvas 2D 绘制波形图和频谱图
- HTML/CSS 构建钢琴键盘
- 纯 JavaScript 实现交互逻辑
- AnalyserNode 获取频域数据

### 性能要求
- 首屏加载时间：< 2s
- 是否需要加载动画：是，声波扩散加载动画
- 波形和频谱 60fps 流畅更新
- 多音同时播放无明显延迟
- 移动端需注意音频上下文的解锁策略

### 响应式
- 移动端适配要求：键盘自适应宽度，琴键数量可自动调整
- 最小支持宽度：375px
- 触摸设备支持多点触摸（同时弹多个键）
- 小屏下波形图和键盘纵向排列
- 琴键最小宽度不小于 24px

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确声波的物理特性和音乐乐理基础
   - 确保频率计算、十二平均律等内容准确
   - 确定教学重点：音高与频率对应 + 波形音色关系 + 谐波理解

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 采用上下分栏：上部声波可视化，下部钢琴键盘
   - 控制面板在顶部或侧边浮动
   - 确保符合交互工具型精密仪器规范

3. 设计视觉方案（配色、布局、动效）
   - 钢琴键盘有真实的立体感和材质感
   - 按键按下有深度变化和光晕效果
   - 波形曲线流畅优美，有发光效果
   - 频谱柱有弹性跳动动画
   - 声音衰减时波形逐渐淡出，有自然的余韵

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是普通的钢琴+柱状图
   - 波形可视化要有艺术感和流动美感
   - 琴键按下的反馈要精致有质感
   - 考虑加入音符粒子效果（弹琴时飞出彩色粒子）
   - 频谱可以做成更有设计感的可视化形式（如圆环频谱）
   - 多音合奏时波形叠加的视觉效果要震撼

5. 开始编码实现
   - 先搭建 Web Audio API 音频引擎
   - 实现振荡器和增益节点控制
   - 构建钢琴键盘 UI 和交互
   - 实现波形图和频谱图的实时绘制
   - 添加音阶选择和预设模式
   - 实现自动播放旋律功能

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 弹琴时声音响应是否即时无延迟？
   - 波形和频谱动画是否流畅？
   - 琴键按下反馈是否清晰有质感？
   - 多音同时播放时音频是否清晰不爆音？
   - 预设旋律播放是否准确有节奏感？

7. 保存到指定路径
