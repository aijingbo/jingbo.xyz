## 一、Demo 概述

本 Demo 通过平面切割圆锥的动态过程和统一的极坐标方程，直观展示椭圆、抛物线、双曲线三种圆锥曲线的形成原理与几何性质。用户可以调节离心率、焦距、切割角度等参数，实时观察曲线形状的连续变化，理解三种圆锥曲线之间的内在联系与过渡关系。配合焦点、准线、渐近线等几何元素的可视化，帮助学习者建立圆锥曲线的完整知识体系。

## 二、内容要求

### 知识点覆盖
- 圆锥曲线的统一定义：到定点（焦点）与定直线（准线）的距离之比为常数 e（离心率）的点的轨迹
- 离心率与曲线类型的关系：e<1 为椭圆，e=1 为抛物线，e>1 为双曲线
- 椭圆的几何性质：长轴、短轴、焦距、离心率 e=c/a 的关系，椭圆标准方程 x²/a² + y²/b² = 1
- 双曲线的几何性质：实轴、虚轴、渐近线、离心率 e=c/a，双曲线标准方程 x²/a² - y²/b² = 1
- 抛物线的几何性质：焦点、准线、标准方程 y² = 2px
- 圆锥曲线的光学性质：椭圆的从一焦点发出经反射到另一焦点、抛物线的平行光线经反射会聚到焦点
- 圆锥曲线的参数方程与极坐标方程
- a, b, c, e, p 等参数之间的换算关系

### 目标用户
- 高中数学学生，正在学习圆锥曲线章节
- 高中数学教师，用于课堂演示和讲解
- 大学解析几何入门学生，复习圆锥曲线基础

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 离心率（e）：范围 0.1-3.0，步长 0.01，默认值 0.6（椭圆）
  - 半长轴/实半轴（a）：范围 1-10，步长 0.5，默认值 5
  - 旋转角度：范围 0°-360°，步长 1°，默认值 0°
  - 中心平移：X 偏移范围 -5~5，步长 0.5，默认 0；Y 偏移范围 -5~5，步长 0.5，默认 0
  - 显示选项：多选开关组，包括【焦点 / 准线 / 对称轴 / 渐近线 / 顶点 / 刻度网格 / 几何定义（动点演示）】，默认显示焦点+对称轴+刻度网格
  - 视图模式：下拉选择，选项包括【2D 曲线视图 / 圆锥切割视图 / 双视图对比】，默认 2D 曲线视图
- 实时反馈：
  - 画布上实时绘制圆锥曲线，参数变化时曲线形状连续变化
  - 焦点用红色圆点标注，准线用绿色虚线标注
  - 双曲线模式下显示渐近线（橙色虚线）
  - 顶部信息栏显示：曲线类型、离心率 e、a 值、b 值、c 值、焦距、标准方程
  - 开启"几何定义"模式时，显示一个动点 P，以及 P 到焦点的距离 |PF| 和 P 到准线的距离 d，两者比值恒等于 e
  - 离心率从小于1连续变到大于1时，曲线从椭圆→抛物线→双曲线平滑过渡
- 预设模式：
  - 预设1：正圆（e=0.1，a=5）——理解圆是椭圆的特例
  - 预设2：标准椭圆（e=0.6，a=5）——典型椭圆形态
  - 预设3：抛物线（e=1.0，p=4）——抛物线标准形态
  - 预设4：等轴双曲线（e=√2≈1.414，a=3）——渐近线垂直的双曲线
  - 预设5：离心率过渡动画（e 从 0.5 到 2.0 自动变化）——展示连续演变
- 播放/暂停：
  - 支持离心率自动变化播放/暂停，观察曲线连续演变
  - 动点轨迹绘制播放/暂停，展示"点动成线"的过程
  - 重置按钮：恢复默认参数

- 纯前端实现，无需额外数学库（基础计算自行实现）

### 性能要求
- 首屏加载时间：< 600ms
- 是否需要加载动画：否
- 交互响应：参数调节时曲线实时更新，无明显延迟（< 50ms）
- 动点动画：60fps 流畅播放

### 响应式
- 移动端适配要求：小屏下控制面板可折叠，曲线视图自适应
- 坐标系等比缩放，保持曲线形状不变形
- 触屏支持双指缩放和平移画布

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：理解圆锥曲线的统一定义，掌握三种曲线的几何性质与关系
   - 重点：离心率的意义，e 与曲线类型的对应关系
   - 难点：三种曲线的内在统一性、参数 a/b/c/e/p 的换算
   - 科学准确性：所有公式推导正确，几何定义严格符合数学规范
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（坐标系+曲线+几何元素），下20%控制面板
   - 左侧参数滑块组：离心率、半长轴、旋转角、X偏移、Y偏移
   - 右侧功能按钮组：播放/暂停 + 重置 + 预设按钮 + 显示选项 + 视图模式切换
   - 画布左上角浮动信息卡：显示曲线类型和关键参数
3. 设计视觉方案（配色、布局、动效）
   - 坐标系：浅灰网格，坐标轴加深，刻度标注清晰
   - 曲线：靛蓝色实线，2px 线宽，端点处有渐隐效果
   - 焦点：红色实心小圆点，带光晕效果，旁边标注 F₁、F₂
   - 准线：绿色虚线，两端延伸出曲线范围
   - 渐近线：橙色虚线，标注方程
   - 动点演示：紫色小圆点沿曲线运动，拉出到焦点和准线的距离线段
   - 控制面板：暖灰背景，滑块有精致轨道和拇指
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一条曲线加几个参数？有没有揭示数学之美？
   - 优化点：离心率连续变化时的平滑过渡动画，强调"统一定义"的核心思想
   - 增加几何定义动点演示：让学生亲眼看到 |PF|/d = e 恒成立
   - 加入圆锥切割视角切换，从三维角度理解"圆锥"曲线名称的由来
5. 开始编码实现
   - 先实现数学计算模块：根据 e 和 a 计算 b, c, p，推导曲线方程
   - 再实现 SVG 渲染层：坐标系、曲线、焦点、准线、渐近线等
   - 最后实现控制面板和交互逻辑
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 测试离心率从 0.99 变到 1.01 时曲线的平滑过渡
   - 验证所有参数计算的正确性（对照标准公式）
   - 检查几何定义演示中距离比值是否恒等于 e
   - 移动端双指缩放体验测试
7. 保存到指定路径
