## 一、Demo 概述

本 Demo 通过可视化方式模拟可逆化学反应达到平衡的过程，展示浓度、温度、压强等因素对化学平衡移动的影响。用户可以调节反应物和生成物的初始浓度、温度、催化剂等参数，实时观察反应速率变化和平衡移动方向。通过交互式操作，帮助学生直观理解勒夏特列原理，掌握化学平衡常数的计算方法。

---

## 二、内容要求

### 知识点覆盖
- 可逆反应与化学平衡状态的建立
- 化学平衡常数（Kc）的概念与计算
- 勒夏特列原理：浓度、温度、压强对平衡移动的影响
- 正逆反应速率与平衡的关系
- 催化剂对反应速率和平衡的影响
- 平衡转化率的计算

### 目标用户
- 高中化学选修阶段学生（高二、高三）
- 大学普通化学入门学习者
- 化学教师用于课堂演示

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 反应类型选择：合成氨（N₂+3H₂⇌2NH₃）、SO₂催化氧化（2SO₂+O₂⇌2SO₃）、酯化反应（CH₃COOH+C₂H₅OH⇌CH₃COOC₂H₅+H₂O）
  - 初始浓度：反应物A浓度 0.1-5.0 mol/L，步长 0.1，默认 1.0
  - 初始浓度：反应物B浓度 0.1-5.0 mol/L，步长 0.1，默认 1.0
  - 初始浓度：生成物C浓度 0-3.0 mol/L，步长 0.1，默认 0
  - 温度：200K-800K，步长 10K，默认 500K
  - 压强：0.5-10 atm，步长 0.5，默认 1 atm
  - 催化剂：开启/关闭，默认关闭
  - 反应速率系数：0.1-5.0，步长 0.1，默认 1.0
- 实时反馈：
  - 左侧容器内粒子动画：反应物（蓝色粒子）与生成物（红色粒子）数量实时变化
  - 右侧浓度-时间曲线图：正逆反应速率曲线与各物质浓度曲线同步绘制
  - 平衡常数 Kc 数值实时计算并显示
  - 平衡移动方向箭头指示（正向→、逆向←、平衡=）
- 预设模式：
  - 预设1：合成氨工业条件（高压、低温、催化剂）
  - 预设2：SO₂接触氧化（常压、高温、催化剂）
  - 预设3：浓度突增实验（某一时刻突然增加反应物浓度）
  - 预设4：温度骤变实验（观察温度对平衡的影响）
- 播放/暂停：
  - 支持播放/暂停模拟过程
  - 支持重置到初始状态
  - 支持单步前进（逐步观察平衡建立过程）
  - 速度调节：0.25x / 0.5x / 1x / 2x / 4x

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确化学平衡的核心概念：可逆反应、动态平衡、平衡常数
   - 确保勒夏特列原理的呈现准确无误
   - 确定教学重点：平衡建立过程 + 影响因素

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 采用左右分栏的画布布局：左侧粒子模拟区，右侧数据图表区
   - 底部控制面板：参数滑块组 + 功能按钮组
   - 确保符合精密仪器的交互工具型规范

3. 设计视觉方案（配色、布局、动效）
   - 分子粒子采用圆形渐变，模拟立体效果
   - 反应发生时粒子有碰撞闪光效果
   - 浓度曲线用平滑贝塞尔曲线，带渐变填充
   - 平衡达成时有绿色提示光效

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是简单的滑块+图表组合
   - 粒子碰撞动画要有真实感，分子运动轨迹自然
   - 平衡移动时的视觉反馈要明显且有科学依据
   - 考虑加入浓度渐变的容器液面效果

5. 开始编码实现
   - 先搭建 HTML 结构和 CSS 样式框架
   - 实现粒子系统和碰撞检测
   - 编写化学动力学计算逻辑
   - 实现浓度曲线实时绘制
   - 连接参数控制与模拟逻辑

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 拖动滑块时反应是否即时？
   - 粒子动画是否流畅无卡顿？
   - 数据标注是否清晰易读？
   - 预设模式切换是否平滑过渡？

7. 保存到指定路径
