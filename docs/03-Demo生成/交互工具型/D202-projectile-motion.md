## 一、Demo 概述

本 Demo 通过交互式动画模拟斜抛运动的完整过程，直观展示物体在重力作用下的运动轨迹、速度变化与受力分解。用户可以调节初速度、抛射角度、重力加速度等参数，实时观察轨迹曲线的变化，并通过速度矢量箭头理解水平匀速与竖直匀变速的合成运动。配合最高点、最远射程、飞行时间等物理量的实时计算，帮助学习者建立抛体运动的定量分析能力。

## 二、内容要求

### 知识点覆盖
- 运动的合成与分解：曲线运动可分解为水平方向和竖直方向的独立分运动
- 斜抛运动规律：水平方向匀速直线运动（vₓ = v₀cosθ），竖直方向竖直上抛运动（vᵧ = v₀sinθ - gt）
- 速度的分解：任意时刻的速度可分解为水平分量和竖直分量，合速度为矢量和
- 力的分解：重力沿速度方向和垂直速度方向的分解，切向加速度与法向加速度
- 轨迹方程：抛物线轨迹 y = x·tanθ - gx²/(2v₀²cos²θ)
- 射程公式：R = v₀²sin2θ/g，最大射程出现在 45° 时
- 射高公式：H = v₀²sin²θ/(2g)
- 飞行时间：T = 2v₀sinθ/g
- 空气阻力的影响（可选）：对比理想情况与有阻力时的轨迹差异

### 目标用户
- 高中物理学生，正在学习曲线运动与抛体运动章节
- 物理教师用于课堂演示，帮助学生理解运动的合成与分解
- 大学物理入门学生，复习运动学基础

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 初速度（v₀）：范围 5-50 m/s，步长 1 m/s，默认值 20 m/s
  - 抛射角度（θ）：范围 5°-85°，步长 1°，默认值 45°
  - 重力加速度（g）：范围 1-20 m/s²，步长 0.5 m/s²，默认值 9.8 m/s²
  - 初始高度（h₀）：范围 0-50 m，步长 1 m，默认值 0 m
  - 显示选项：多选开关组，包括【速度矢量 / 分速度箭头 / 受力分析 / 轨迹 / 刻度网格 / 数据标签】，默认显示轨迹+速度矢量+刻度网格
  - 空气阻力开关：开关切换，选项【无 / 有（线性阻力）】，默认无
- 实时反馈：
  - 画布上实时绘制运动轨迹，物体沿轨迹运动
  - 速度矢量箭头：蓝色箭头表示合速度，橙色虚线箭头表示水平/竖直分速度
  - 受力分析：红色箭头表示重力，可展开显示切向/法向分量
  - 顶部数据面板显示：当前时间 t、位置坐标 (x,y)、速度大小 v、速度方向角 α
  - 右侧结果面板显示：最大高度 H、水平射程 R、飞行时间 T、落地速度
  - 参数变化时轨迹实时更新，无需重新发射
- 预设模式：
  - 预设1：最大射程演示（θ=45°，v₀=20m/s）——直观展示45度最远
  - 预设2：互补角对比（θ=30°和θ=60°，同射程不同高度）——展示射程对称性
  - 预设3：月球环境（g=1.62m/s²）——对比不同重力场中的抛体运动
  - 预设4：从高处发射（h₀=30m，θ=0°平抛）——理解平抛运动
- 播放/暂停：
  - 支持发射/暂停/重置/慢放四种控制
  - 发射按钮触发物体从原点抛出
  - 慢放按钮切换 0.25x / 0.5x / 1x 速度
  - 暂停时可拖动时间滑块跳转到任意时刻

## 五、技术实现

### 推荐技术栈
- Canvas 2D 绘制坐标系、轨迹、矢量箭头和运动物体
- JavaScript 物理引擎：基于运动学公式的解析计算（非数值积分），保证精度
- 原生 CSS 打造精致的滑块与旋钮控件
- 无需额外物理引擎库，运动轨迹用公式精确计算

### 性能要求
- 首屏加载时间：< 500ms
- 是否需要加载动画：否
- 动画帧率：60fps，物体位置和矢量箭头实时更新
- 轨迹绘制使用路径缓存，参数变化时重新计算路径

### 响应式
- 移动端适配要求：控制面板在小屏上可收起，画布占满屏幕
- 坐标系自适应画布尺寸，保持正确的宽高比（或提供等比缩放选项）
- 滑块和按钮在触屏设备上有足够的点击面积（≥44px）

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：理解运动的合成与分解，掌握抛体运动规律
   - 重点：水平匀速 + 竖直匀变速的独立性原理
   - 难点：速度矢量的动态变化、切向法向加速度的理解
   - 科学准确性：所有公式必须正确，物理量单位要规范
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（坐标系+轨迹+物体），下20%控制面板
   - 左侧参数滑块组：初速度、抛射角、重力加速度、初始高度
   - 右侧功能按钮组：发射/暂停/重置 + 慢放 + 预设按钮 + 显示选项开关
   - 画布右上角浮动数据面板：显示当前物理量
3. 设计视觉方案（配色、布局、动效）
   - 坐标系：浅灰色网格线，刻度数字标注，坐标轴加粗带箭头
   - 轨迹：蓝色实线，渐变色表示速度大小（快的地方亮，慢的地方暗）
   - 运动物体：深色小球带高光，拖尾效果增强运动感
   - 速度矢量：从物体出发的箭头，蓝色实线，旁边标注 v
   - 分速度：橙色（水平）和紫色（竖直）虚线箭头，有直角标记
   - 控制面板：暖灰背景，滑块有刻度标记，按钮有按压反馈
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一个抛物线加滑块？有没有教学深度？
   - 优化点：加入速度矢量的实时变化演示，让学生"看见"加速度
   - 增加轨迹对比模式：同时显示两条不同参数的轨迹，便于对比
   - 加入能量守恒可视化：动能和势能的实时柱状图
5. 开始编码实现
   - 先实现物理计算模块：位置、速度、射程、射高、飞行时间公式
   - 再实现 Canvas 渲染层：坐标系、轨迹、物体、矢量箭头
   - 最后实现控制面板：滑块、按钮、数据面板
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 测试参数调节时轨迹是否实时更新、无卡顿
   - 检查所有物理量计算的准确性（对照手算结果验证）
   - 确认矢量箭头方向和长度比例正确
   - 移动端横屏体验测试
7. 保存到指定路径
