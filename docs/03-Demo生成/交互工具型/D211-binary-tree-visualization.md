## 一、Demo 概述

本 Demo 提供二叉树数据结构的交互式可视化工具，支持动态插入、删除、查找节点，并实时展示树的结构变化。用户可以直观理解二叉搜索树（BST）、AVL 平衡树、红黑树等经典树结构的工作原理，观察前序、中序、后序、层序遍历的执行过程。通过动手操作，帮助学习者建立数据结构的空间想象力。

---

## 二、内容要求

### 知识点覆盖
- 二叉树的基本概念：根节点、叶子节点、深度、高度、层
- 二叉搜索树（BST）的插入、删除、查找操作
- 树的四种遍历方式：前序、中序、后序、层序遍历
- AVL 平衡树的旋转操作（左旋、右旋、左右旋、右左旋）
- 红黑树的性质与变色旋转
- 时间复杂度分析（O(log n) vs O(n)）
- 堆结构与堆排序（扩展）

### 目标用户
- 计算机专业大一、大二学生
- 数据结构与算法初学者
- 准备算法面试的求职者
- 信息技术教师用于课堂演示

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 树类型选择：二叉搜索树（BST）/ AVL树 / 红黑树，默认 BST
  - 节点数值输入：支持手动输入数值插入节点
  - 随机生成节点数量：1-30 个，步长 1，默认 10
  - 节点数值范围：最小值 1-50，步长 1，默认 1；最大值 50-200，步长 1，默认 99
  - 动画速度：0.25x / 0.5x / 1x / 2x / 4x，默认 1x
  - 布局方式：紧凑 / 标准 / 宽松，默认标准
  - 显示选项：显示节点高度 / 显示平衡因子 / 显示子树大小，可多选
  - 遍历方式：前序 / 中序 / 后序 / 层序，默认中序
- 实时反馈：
  - 画布区树形结构实时更新，节点位置自动布局
  - 插入/删除操作有动画过渡，高亮显示操作路径
  - 平衡树旋转时节点平滑移动，展示旋转过程
  - 遍历过程中节点依次高亮变色，遍历序列同步显示
  - 右侧信息面板显示树的高度、节点数、平衡状态等统计信息
- 预设模式：
  - 预设1：BST 基本操作演示（插入5个节点+删除根节点）
  - 预设2：AVL 旋转演示（依次插入触发四种旋转的序列）
  - 预设3：红黑树插入演示（展示变色与旋转）
  - 预设4：遍历对比演示（同一棵树的四种遍历方式对比）
  - 预设5：最坏情况演示（有序插入导致退化为链表）
- 播放/暂停：
  - 支持播放/暂停遍历动画
  - 支持单步执行（前进一步/后退一步）
  - 支持重置到初始状态
  - 支持清空整棵树重新开始

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确二叉树核心概念：结构定义、性质、操作
   - 确保各树种操作算法准确无误
   - 确定教学重点：操作过程可视化 + 遍历顺序理解

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 画布区居中展示树形结构，左右两侧可配置信息面板
   - 底部控制面板：参数输入区 + 操作按钮组 + 遍历控制
   - 确保符合交互工具型的精密仪器规范

3. 设计视觉方案（配色、布局、动效）
   - 节点采用圆形渐变填充，带轻微阴影增加立体感
   - 连线使用贝塞尔曲线，端点有小圆点装饰
   - 插入/删除时节点有缩放弹性动画
   - 旋转操作时节点沿弧线平滑移动
   - 遍历时节点有呼吸灯效果的高亮

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是简单的圆圈+连线
   - 节点状态变化要有丰富的视觉反馈（缩放、发光、颜色渐变）
   - 平衡旋转动画要流畅自然，能看清旋转过程
   - 考虑加入节点连线的流光效果表示数据流向

5. 开始编码实现
   - 先实现树数据结构类（BST/AVL/红黑树）
   - 实现树形布局算法（计算每个节点的坐标）
   - 使用 SVG 渲染节点和连线
   - 实现操作动画和遍历动画
   - 连接控制面板与树操作逻辑

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 插入删除节点后树结构重排是否平滑？
   - 遍历动画节奏是否合适，快慢可调？
   - 红黑树颜色变化是否清晰可辨？
   - 信息面板数据是否实时更新？

7. 保存到指定路径
