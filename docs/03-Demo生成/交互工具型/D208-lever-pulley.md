## 一、Demo 概述

本 Demo 通过交互式虚拟实验模拟杠杆和滑轮的工作原理，直观展示杠杆平衡条件和各类滑轮的省力规律。用户可以调节杠杆两端的钩码数量和位置，观察杠杆的转动与平衡；也可以切换到定滑轮、动滑轮、滑轮组模式，比较不同机械的省力效果和绳子移动距离。配合力的示意图、力矩标注和机械效率计算，帮助学习者建立"功的原理"的物理直觉。

## 二、内容要求

### 知识点覆盖
- 杠杆的五要素：支点、动力、阻力、动力臂、阻力臂
- 杠杆平衡条件：F₁L₁ = F₂L₂（动力×动力臂 = 阻力×阻力臂）
- 杠杆的分类：省力杠杆（L₁>L₂）、费力杠杆（L₁<L₂）、等臂杠杆（L₁=L₂）
- 定滑轮：不省力但可以改变力的方向，实质是等臂杠杆
- 动滑轮：省一半力但费一倍距离，实质是动力臂为阻力臂二倍的杠杆
- 滑轮组：由定滑轮和动滑轮组合而成，省力情况由承担物重的绳子段数 n 决定，F = G/n
- 功的原理：使用任何机械都不省功，省力必然费距离
- 机械效率：η = W有用/W总 = Gh/Fs，实际机械效率小于1
- 生活中的杠杆实例：撬棍、镊子、天平、门把手等

### 目标用户
- 初中物理学生，正在学习简单机械章节
- 物理教师用于课堂演示杠杆和滑轮原理
- 对机械原理感兴趣的科普爱好者

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 实验类型：下拉选择，选项包括【杠杆实验 / 定滑轮 / 动滑轮 / 滑轮组（2段绳） / 滑轮组（3段绳）】，默认杠杆实验
  - 左侧钩码重量（G₁）：范围 0-10 N，步长 0.5 N，默认值 4 N
  - 左侧力臂（L₁）：范围 1-10 格，步长 1 格，默认值 5 格
  - 右侧钩码重量（G₂）：范围 0-10 N，步长 0.5 N，默认值 5 N
  - 右侧力臂（L₂）：范围 1-10 格，步长 1 格，默认值 4 格
  - 滑轮模式下的物重（G）：范围 10-100 N，步长 5 N，默认值 40 N
  - 显示选项：多选开关组，包括【力的示意图 / 力臂标注 / 力矩数值 / 刻度网格 / 绳子张力 / 机械效率】，默认显示力的示意图+力臂标注+刻度网格
- 实时反馈：
  - 杠杆模式：画布显示带刻度的杠杆，两端挂有钩码，杠杆会根据力矩差倾斜或平衡
  - 倾斜角度与力矩差成正比，平衡时杠杆水平
  - 力臂用橙色虚线标注，从支点到力的作用线的垂直距离
  - 滑轮模式：显示滑轮装置，绳子自由端有拉力 F，物体被吊起
  - 右侧数据面板显示：动力 F₁、阻力 F₂、动力臂 L₁、阻力臂 L₂、动力矩、阻力矩、是否平衡
  - 滑轮模式下显示：物重 G、拉力 F、绳子段数 n、机械效率 η、绳子自由端移动距离 s
  - 参数调节时，杠杆倾斜角度实时变化，滑轮模式下拉力实时更新
- 预设模式：
  - 预设1：杠杆平衡（G₁=4N, L₁=5, G₂=5N, L₂=4）——验证 F₁L₁=F₂L₂
  - 预设2：省力杠杆（左端长右端短，左端小力平衡右端大力）
  - 预设3：费力杠杆（左端短右端长，费力但省距离）
  - 预设4：定滑轮（G=40N，F=40N）——不省力改变方向
  - 预设5：动滑轮（G=40N，F=20N）——省一半力
  - 预设6：滑轮组（n=3，G=60N，F=20N）——滑轮组省力
- 播放/暂停：
  - 杠杆释放/固定：点击"释放"让杠杆自由转动，"固定"锁定当前角度
  - 滑轮升降动画：播放物体匀速上升过程，观察绳子自由端移动距离
  - 重置按钮：恢复默认参数
  - "加一个钩码"快捷按钮：便于学生进行实验探究

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：理解杠杆平衡条件，掌握各类滑轮的省力规律
   - 重点：F₁L₁ = F₂L₂、滑轮组的省力与费距离关系
   - 难点：力臂的概念（支点到力的作用线的垂直距离，不是到作用点的距离）
   - 科学准确性：严格遵循杠杆原理和功的原理，计算准确
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（实验装置+动画），下20%控制面板
   - 左侧参数滑块组：根据实验类型显示对应参数（钩码重量/力臂/物重）
   - 右侧功能按钮组：实验类型选择 + 释放/固定 + 播放动画 + 预设按钮 + 显示选项
   - 画布右侧浮动数据面板：显示各力学量
3. 设计视觉方案（配色、布局、动效）
   - 杠杆：带刻度的金属杆，中央有三角形支点，两端挂钩码
   - 钩码：标准实验室钩码样式，带挂钩，堆叠显示数量
   - 滑轮：金属质感的滑轮，带支架和挂钩，绳子绕在滑轮槽中
   - 力的箭头：从作用点出发的红色箭头，标注力的大小
   - 力臂：橙色虚线，从支点到力的作用线，有直角符号
   - 杠杆倾斜动画：以支点为轴平滑转动，平衡时减速停止
   - 控制面板：暖灰背景，精致的滑块和选择器
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一张杠杆图加几个数字？有没有实验探究感？
   - 优化点：加入杠杆的真实倾斜动画，让学生"看见"力矩的作用
   - 增加"释放"机制——不是自动平衡，而是让学生自己调节找到平衡条件
   - 加入滑轮升降时的绳子长度变化，直观展示"省力费距离"
5. 开始编码实现
   - 先实现力学计算模块：杠杆力矩平衡、滑轮拉力、机械效率
   - 再实现 SVG 渲染层：杠杆、滑轮、钩码、力的示意图
   - 最后实现控制面板和动画逻辑
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 验证杠杆平衡条件计算的准确性
   - 测试不同实验类型切换时的平滑过渡
   - 检查滑轮模式下绳子绕法是否正确
   - 移动端显示清晰度和触控体验测试
7. 保存到指定路径
