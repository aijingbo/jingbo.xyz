## 一、Demo 概述

本 Demo 通过交互式虚拟电路实验，直观演示欧姆定律的基本原理以及串联、并联电路的电流电压规律。用户可以调节电源电压、电阻阻值，观察电流大小的变化，通过灯泡亮度、电流表读数等可视化反馈理解电压、电流、电阻三者之间的定量关系。支持串联和并联两种电路结构切换，并可添加多个电阻进行复杂电路的探究学习。

## 二、内容要求

### 知识点覆盖
- 欧姆定律：I = U/R，电流与电压成正比，与电阻成反比
- 电路基本组成：电源、开关、导线、用电器（电阻/灯泡）、电流表、电压表
- 串联电路特点：电流处处相等（I = I₁ = I₂），总电压等于各部分电压之和（U = U₁ + U₂），总电阻等于各电阻之和（R = R₁ + R₂）
- 并联电路特点：各支路电压相等（U = U₁ = U₂），干路电流等于各支路电流之和（I = I₁ + I₂），总电阻的倒数等于各电阻倒数之和（1/R = 1/R₁ + 1/R₂）
- 电阻的概念：导体对电流的阻碍作用，单位欧姆（Ω）
- 电压的概念：推动电荷定向移动的动力，单位伏特（V）
- 电流的概念：电荷的定向移动，单位安培（A）
- 电功率：P = UI = I²R = U²/R，灯泡亮度与功率的关系
- 短路与断路的区别及危害（安全教育）

### 目标用户
- 初中物理学生，正在学习电学章节
- 物理教师用于课堂演示电路原理
- 对电学感兴趣的科普爱好者

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 电源电压（U）：范围 0-24 V，步长 0.5 V，默认值 6 V
  - 电阻 R₁ 阻值：范围 1-100 Ω，步长 1 Ω，默认值 10 Ω
  - 电阻 R₂ 阻值：范围 1-100 Ω，步长 1 Ω，默认值 20 Ω
  - 电路类型：下拉选择，选项包括【简单电路（1个电阻）/ 串联电路 / 并联电路 / 混联电路】，默认串联电路
  - 显示选项：多选开关组，包括【电流方向（电子流动） / 电流方向（正电荷流动） / 电压标注 / 电阻值标注 / 各点电位 / 实时数据面板】，默认显示电流方向+实时数据面板
  - 动画速度：范围 0.5x-3x，步长 0.5x，默认值 1x（电流粒子流动速度）
- 实时反馈：
  - 画布上绘制完整的电路图，包含电源、开关、电阻（灯泡）、导线
  - 电流以流动的发光粒子形式显示，粒子速度与电流大小成正比
  - 灯泡亮度随实际功率变化，功率越大越亮
  - 电流表显示实时电流值，电压表显示被测元件两端电压
  - 右侧数据面板显示：总电压 U、总电流 I、总电阻 R、总功率 P、各电阻的电压/电流/功率
  - 参数变化时，所有数值实时更新，灯泡亮度平滑过渡
  - 开关可点击控制通断，断开时电流停止流动
- 预设模式：
  - 预设1：欧姆定律验证（简单电路，调电压看电流变化）——探究 I-U 关系
  - 预设2：串联分压（R₁=10Ω, R₂=20Ω, U=6V）——验证 U₁:U₂ = R₁:R₂
  - 预设3：并联分流（R₁=10Ω, R₂=20Ω, U=6V）——验证 I₁:I₂ = R₂:R₁
  - 预设4：短路演示（导线直接接电源两端）——展示短路电流过大的危害
  - 预设5：调光灯电路（滑动变阻器+灯泡）——模拟实际调光应用
- 播放/暂停：
  - 开关控制电路通断（点击开关图标）
  - 电流粒子动画的播放/暂停
  - 重置按钮：恢复默认参数和电路状态

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：理解欧姆定律，掌握串并联电路的电流电压规律
   - 重点：I = U/R 的定量关系、串并联电路的特点对比
   - 难点：并联电路总电阻的计算、电流方向的理解
   - 科学准确性：所有电路计算必须准确，单位规范
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（电路图+动画），下20%控制面板
   - 左侧参数滑块组：电源电压、R₁阻值、R₂阻值、动画速度
   - 右侧功能按钮组：电路类型选择 + 开关控制 + 预设按钮 + 显示选项
   - 画布右上角浮动数据面板：显示各电学量
3. 设计视觉方案（配色、布局、动效）
   - 电路图：标准电路符号风格，导线水平垂直走线，元件均匀分布
   - 电源：长短线符号，正极红色标注，负极蓝色标注
   - 灯泡：圆形灯泡符号，通电后发出暖黄色光晕，亮度随功率变化
   - 电阻：矩形锯齿符号（标准电阻符号），标注阻值
   - 电流粒子：绿色发光小圆点，沿导线定向移动，速度与电流成正比
   - 开关：可点击的刀闸式开关，有开/关两种状态
   - 控制面板：暖灰背景，精致的旋钮和滑块样式
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一个电路图加几个读数？有没有交互深度？
   - 优化点：加入电流粒子的可视化，让"电流"从抽象概念变成可见的流动
   - 增加灯泡亮度随功率变化的直观反馈，建立感性认识
   - 加入各点电位显示，用颜色深浅表示电位高低，帮助理解电压概念
5. 开始编码实现
   - 先实现电路计算模块：根据电路类型和参数计算各电学量
   - 再实现 SVG 电路绘制和 Canvas 电流粒子动画
   - 最后实现控制面板和交互逻辑
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 验证所有电学计算的准确性（对照标准公式手算验证）
   - 测试电路类型切换时的平滑过渡
   - 检查灯泡亮度与功率的对应关系是否合理
   - 移动端电路显示清晰度测试
7. 保存到指定路径
