## 一、Demo 概述

本 Demo 通过几何光学的方法，直观模拟凸透镜和凹透镜的成像过程。用户可以调节物距、焦距、物体高度、透镜类型等参数，实时观察三条特殊光线的传播路径和成像结果。通过交互式操作，帮助学生理解透镜成像规律，掌握透镜公式 1/f = 1/u + 1/v 的应用，建立几何光学的空间思维能力。

---

## 二、内容要求

### 知识点覆盖
- 凸透镜与凹透镜的基本概念：光心、焦点、焦距、主光轴
- 三条特殊光线：平行于主光轴的光线、过光心的光线、过焦点的光线
- 凸透镜成像规律：u>2f、u=2f、f<u<2f、u=f、u<f 五种情况
- 凹透镜成像特点：始终成正立缩小的虚像
- 透镜公式：1/f = 1/u + 1/v（含符号法则）
- 放大率公式：m = v/u = h'/h
- 实像与虚像的区别
- 眼睛、照相机、投影仪、放大镜的成像原理

### 目标用户
- 初中物理八年级学生
- 高中物理光学复习
- 物理教师课堂演示工具

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 透镜类型：凸透镜 / 凹透镜，默认凸透镜
  - 焦距 f：5-30 cm，步长 1cm，默认 15cm
  - 物距 u：2-60 cm，步长 1cm，默认 30cm
  - 物体高度 h：2-15 cm，步长 1cm，默认 8cm
  - 透镜直径：8-25 cm，步长 1cm，默认 18cm
  - 显示选项：平行光线 / 过光心光线 / 过焦点光线 / 辅助线，可独立开关
  - 显示数据：物距/像距数值 / 放大率 / 成像性质描述，可独立开关
  - 光线数量：3条（特殊光线）/ 多条（漫射光线），默认 3条
- 实时反馈：
  - 画布区显示透镜、主光轴、物体和像
  - 三条特殊光线用不同颜色绘制，路径清晰可见
  - 实像用实线箭头表示，虚像用虚线箭头表示
  - 像的位置、大小、正倒随参数实时变化
  - 右侧数据面板显示：物距u、像距v、焦距f、放大率m、成像性质
  - 透镜公式动态验证：1/f = 1/u + 1/v 数值实时显示
- 预设模式：
  - 预设1：照相机原理（u>2f，倒立缩小实像）
  - 预设2：投影仪原理（f<u<2f，倒立放大实像）
  - 预设3：放大镜原理（u<f，正立放大虚像）
  - 预设4：等大实像（u=2f，倒立等大实像）
  - 预设5：不成像（u=f，平行光出射）
  - 预设6：凹透镜成像（始终正立缩小虚像）
- 播放/暂停：
  - 支持物体从远到近自动移动的动画（观察成像变化全过程）
  - 支持播放/暂停自动移动
  - 支持重置到默认位置
  - 速度调节：慢速 / 正常 / 快速

## 四、视觉设计要求

### 整体气质
- 精密光学仪器感，像物理实验室的光学实验台
- 清晰、明亮、科学严谨
- 光线效果精致，有光束的通透感

### 配色方案
- 主色调：墨蓝色 #1e3a5f（光学仪器感）
- 背景色：淡米白色 #faf8f5（画布区域，模拟实验台）
- 强调色：
  - 凸透镜：浅蓝渐变 #aed6f1 → #85c1e9
  - 凹透镜：浅紫渐变 #d7bde2 → #bb8fce
  - 平行光线：金黄色 #f4d03f（带发光效果）
  - 过光心光线：青蓝色 #3498db
  - 过焦点光线：橙红色 #e67e22
  - 物体：深绿色 #27ae60（实心箭头）
  - 实像：红色 #e74c3c（实心箭头）
  - 虚像：红色 #e74c3c（虚线箭头，半透明）
  - 主光轴：深灰色 #34495e（带刻度）
- 是否遵循景礴设计系统：是，上下分栏布局，精密仪器风格控制面板，精致的滑块设计

## 五、技术实现

### 推荐技术栈
- SVG 或 Canvas 2D 绘制光路图（SVG 更清晰，便于交互）
- 纯 JavaScript 实现几何光学计算
- CSS 自定义控件样式
- 光线发光效果可用 SVG filter（feGaussianBlur）实现

### 性能要求
- 首屏加载时间：< 2s
- 是否需要加载动画：是，简洁的光线扫描加载动画
- 参数调节时光路实时更新，无延迟感
- 动画模式下 60fps 流畅

### 响应式
- 移动端适配要求：画布自适应宽度，保持宽高比
- 最小支持宽度：375px
- 触摸设备可拖动透镜和物体位置
- 控制面板在小屏可折叠展开

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确透镜成像的核心规律和公式
   - 确保三条特殊光线的画法准确无误
   - 确定教学重点：成像规律 + 实虚像区别 + 公式应用

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 画布区水平居中展示光路图，主光轴横贯画面
   - 底部控制面板：参数滑块组 + 显示选项 + 预设按钮
   - 确保符合交互工具型精密仪器规范

3. 设计视觉方案（配色、布局、动效）
   - 透镜用半透明渐变填充，边缘有高光效果
   - 光线用发光线条，端点有渐变淡出效果
   - 实像和虚像视觉差异明显（实线/虚线、饱和度差异）
   - 主光轴带精确刻度，像尺子一样
   - 参数变化时光线平滑过渡，有流动感

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是简单的线条图
   - 透镜要有玻璃质感，光线要有光束效果
   - 成像变化时要有过渡动画，不是突变
   - 考虑加入光线在透镜内部的折射细节
   - 可以加入漫射光线效果，增强真实感

5. 开始编码实现
   - 先搭建画布和主光轴、透镜的基础绘制
   - 实现几何计算函数（物像公式、放大率计算）
   - 绘制三条特殊光线，精确计算路径
   - 实现物体和像的绘制
   - 添加数据面板和参数控制
   - 实现预设模式和动画模式

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 拖动滑块时光路更新是否即时流畅？
   - 虚像和实像的视觉区别是否清晰？
   - 光线是否有发光通透的质感？
   - 预设切换是否平滑过渡？
   - 数据标注是否准确不遮挡光路？

7. 保存到指定路径
