## 一、Demo 概述

本 Demo 是一个交互式函数图像绘制工具，用户可以输入任意函数表达式，实时生成对应的函数图像。支持一次函数、二次函数、指数函数、对数函数、三角函数等多种常见函数类型，并可同时绘制多条曲线进行对比。配合可拖动的坐标平面、缩放平移、交点标注、切线绘制等功能，帮助学习者直观理解函数的图像特征与变化规律。

## 二、内容要求

### 知识点覆盖
- 一次函数 y = kx + b：斜率 k 和截距 b 对图像的影响
- 二次函数 y = ax² + bx + c：开口方向、顶点、对称轴、与坐标轴交点
- 反比例函数 y = k/x：双曲线、渐近线
- 指数函数 y = aˣ：底数 a 对增减性和图像的影响
- 对数函数 y = logₐx：与指数函数的反函数关系，图像关于 y=x 对称
- 幂函数 y = xᵅ：不同指数 α 对应的图像形态
- 三角函数 y = sin(x), y = cos(x), y = tan(x)：周期性、振幅、相位
- 函数图像的变换：平移、伸缩、对称、翻折
- 函数的零点、极值点、拐点等特殊点
- 函数的单调性、奇偶性、周期性等性质
- 两个函数图像的交点与方程求解的关系

### 目标用户
- 初高中数学学生，学习各类函数图像
- 数学教师用于课堂绘制函数图像
- 大学微积分入门学生，复习函数基础

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 函数表达式输入：文本输入框，支持数学表达式，如 "x^2 + 2*x - 3"、"sin(x)"、"2^x" 等
  - 第二条函数（可选）：开关切换是否显示第二条函数，同样支持表达式输入
  - 第三条函数（可选）：开关切换是否显示第三条函数
  - X 轴范围：左边界范围 -50~0，步长 1，默认 -10；右边界范围 0~50，步长 1，默认 10
  - Y 轴范围：下边界范围 -50~0，步长 1，默认 -10；上边界范围 0~50，步长 1，默认 10
  - 显示选项：多选开关组，包括【网格线 / 坐标轴刻度 / 函数值标注 / 零点标记 / 顶点标记 / 交点标记 / 切线工具 / 积分面积】，默认显示网格线+坐标轴刻度+零点标记
  - 常用函数快捷按钮：一行快捷按钮，点击可快速填入常见函数（一次/二次/三次/指数/对数/正弦/余弦/绝对值/根号）
- 实时反馈：
  - 画布上实时绘制函数图像，修改表达式或参数后立即更新
  - 多条函数用不同颜色区分（蓝、紫、橙）
  - 鼠标悬停在图像上时，显示该点坐标 (x, y) 和切线斜率
  - 零点用红色圆点标注，顶点用绿色圆点标注
  - 多条函数时，交点用黄色圆点标注，显示交点坐标
  - 右侧信息面板显示：当前函数表达式、定义域提示、特殊点坐标（零点/顶点/交点）
  - 坐标系支持鼠标拖动平移和滚轮缩放
- 预设模式：
  - 预设1：标准二次函数（y = x²）——认识抛物线
  - 预设2：二次函数一般式（y = x² - 4x + 3）——求零点和顶点
  - 预设3：指数 vs 对数（y = 2^x 和 y = log2(x)）——反函数对称关系
  - 预设4：正弦曲线（y = sin(x)）——周期性与振幅
  - 预设5：函数对比（y = x², y = x³, y = 2^x）——增长速度对比
  - 预设6：绝对值与分段函数（y = |x|, y = |x² - 4|）——翻折变换
- 播放/暂停：
  - 支持参数动画播放：如 y = x² + bx 中 b 从 -5 变到 5，观察抛物线平移
  - 切线动画：切点沿曲线移动，展示切线斜率的变化
  - 播放速度可调（慢速/中速/快速）
  - 重置视图按钮：恢复默认坐标范围

## 五、技术实现

### 推荐技术栈
- Canvas 2D 绘制坐标系和函数曲线，性能好，支持大量采样点
- JavaScript 数学表达式解析：可用 math.js 或自行实现简单表达式解析器
- 数值计算：求零点用二分法/牛顿法，求导用数值微分
- 推荐使用轻量级数学库 math.js 处理表达式解析和计算

### 性能要求
- 首屏加载时间：< 600ms（含数学库加载）
- 是否需要加载动画：否，可显示简短的加载提示
- 交互响应：表达式修改后图像更新 < 200ms
- 坐标系拖动和缩放流畅，60fps

### 响应式
- 移动端适配要求：小屏下控制面板可折叠，画布占满屏幕
- 坐标系自适应屏幕尺寸，保持正确的比例
- 触屏支持双指缩放和单指拖动
- 移动端输入框优化，便于输入数学表达式

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：通过交互式绘图帮助理解各类函数的图像特征
   - 重点：函数图像与表达式参数的对应关系、函数的基本性质
   - 难点：函数变换的规律、复合函数的图像特征
   - 科学准确性：函数计算准确，特殊点求解精度足够
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（坐标系+函数图像），下20%控制面板
   - 左侧参数区：函数表达式输入 + 快捷函数按钮 + 坐标范围调节
   - 右侧功能区：显示选项 + 切线/积分工具 + 预设按钮 + 动画播放控制
   - 画布占据主要空间，信息面板可浮动在角落
3. 设计视觉方案（配色、布局、动效）
   - 坐标系：浅灰网格，坐标轴加深，刻度标注清晰
   - 函数曲线：平滑曲线，不同函数用不同颜色区分
   - 特殊点：彩色圆点标注，悬停时显示坐标
   - 切线工具：点击曲线上某点显示切线和斜率
   - 积分面积：淡蓝色半透明填充区域，显示面积数值
   - 表达式输入框：带语法高亮，输入错误时有提示
   - 控制面板：暖灰背景，精致的输入框和按钮
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一个简单的绘图计算器？有没有教学亮点？
   - 优化点：加入参数动画功能，让学生直观看到参数变化如何影响图像
   - 增加反函数对称演示，y=x 对称轴的镜像动画
   - 加入"函数生长"动画——曲线从左到右逐步绘出，有叙事感
5. 开始编码实现
   - 先实现数学计算模块：表达式解析、函数求值、零点/极值/交点求解
   - 再实现 Canvas 渲染层：坐标系、函数曲线、标注、工具
   - 最后实现控制面板和交互逻辑
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 测试各种函数表达式的渲染正确性
   - 检查坐标系拖动和缩放的流畅度
   - 验证特殊点标注的准确性
   - 移动端输入体验和触控操作测试
7. 保存到指定路径
