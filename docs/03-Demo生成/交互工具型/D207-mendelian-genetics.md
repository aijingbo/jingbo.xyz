## 一、Demo 概述

本 Demo 通过交互式虚拟实验模拟孟德尔豌豆杂交实验，直观展示基因分离定律和自由组合定律的遗传规律。用户可以选择亲本基因型，观察子代的性状表现和基因型比例，通过 Punnett 方格（棋盘法）和真实的子代群体模拟，理解显性/隐性、纯合/杂合、基因型/表现型等核心概念。支持单基因和双基因两种遗传模式，配合大样本统计验证 3:1 和 9:3:3:1 的经典分离比。

## 二、内容要求

### 知识点覆盖
- 基本概念：基因、等位基因、显性基因、隐性基因、基因型、表现型、纯合子、杂合子
- 基因分离定律：杂合子（Aa）产生配子时，等位基因分离，分别进入不同配子
- 杂交实验：P（亲本）→ F₁（子一代）→ F₂（子二代）的遗传规律
- 表现型比例：Aa × Aa → 显性:隐性 = 3:1
- 基因型比例：Aa × Aa → AA:Aa:aa = 1:2:1
- 测交实验：杂合子与隐性纯合子杂交（Aa × aa），后代比例 1:1，用于验证基因型
- 基因自由组合定律：两对或多对等位基因独立遗传
- 双基因杂交：AaBb × AaBb → 表现型比例 9:3:3:1
- Punnett 方格法：用棋盘法推导子代基因型和比例
- 概率统计：大样本下实验结果接近理论比例，样本越小偏差越大

### 目标用户
- 高中生物学生，正在学习遗传与进化章节
- 生物教师用于课堂演示遗传规律
- 对遗传学感兴趣的科普爱好者

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 遗传模式：下拉选择，选项包括【单基因遗传 / 双基因遗传】，默认单基因遗传
  - 父本基因型：下拉选择，单基因时为【AA / Aa / aa】，双基因时为【AABB / AABb / AAbb / AaBB / AaBb / Aabb / aaBB / aaBb / aabb】，默认父本 Aa
  - 母本基因型：下拉选择，选项同父本，默认母本 Aa
  - 性状类型：下拉选择，选项包括【豌豆花色（紫/白） / 豌豆粒形（圆/皱） / 果蝇翅型（长/残） / 自定义】，默认豌豆花色
  - 子代数量：范围 10-1000，步长 10，默认值 100
  - 显示选项：多选开关组，包括【Punnett 方格 / 基因型标注 / 配子类型 / 统计图表 / 系谱图样式 / 逐代繁殖】，默认显示 Punnett 方格+统计图表
- 实时反馈：
  - 画布中央展示 Punnett 方格，显示配子组合和子代基因型
  - 下方展示子代群体模拟，用不同颜色/形状的豌豆（或果蝇）表示不同表现型
  - 右侧统计面板显示：各基因型数量和比例、各表现型数量和比例
  - 统计图表用柱状图直观展示表现型比例，与理论比例对比
  - 改变亲本基因型时，Punnett 方格和统计结果实时更新
  - 点击"随机交配"按钮，随机生成指定数量的子代个体，观察统计波动
- 预设模式：
  - 预设1：经典分离比（Aa × Aa，单基因，n=200）——观察 3:1 分离比
  - 预设2：测交实验（Aa × aa，单基因，n=200）——验证 1:1 比例
  - 预设3：显性纯合 × 隐性纯合（AA × aa）——F₁ 全为杂合显性
  - 预设4：双基因自由组合（AaBb × AaBb，n=400）——观察 9:3:3:1
  - 预设5：大样本验证（Aa × Aa，n=1000）——体会统计规律与样本量的关系
- 播放/暂停：
  - 支持逐个子代生成的动画播放，观察个体逐个出现的过程
  - 播放速度可调（慢速/中速/快速）
  - 重置按钮：清空子代，重新开始
  - "再繁殖一代"按钮：用当前子代继续繁殖 F₂ 代

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：理解基因分离定律和自由组合定律
   - 重点：基因型与表现型的关系、分离比的由来、Punnett 方格的使用
   - 难点：自由组合定律的 9:3:3:1 比例、概率与统计的关系
   - 科学准确性：遗传规律严格遵循孟德尔定律，基因型配子组合正确
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（Punnett方格+子代群体+统计图），下20%控制面板
   - 左侧参数控制：遗传模式、父本基因型、母本基因型、子代数量
   - 右侧功能按钮：性状选择 + 播放/暂停 + 重置 + 再繁殖一代 + 预设按钮
   - 画布左侧 Punnett 方格，右侧统计面板，下方子代群体展示
3. 设计视觉方案（配色、布局、动效）
   - Punnett 方格：清晰的表格布局，配子在表头，子代基因型在格子中
   - 基因型标注：用颜色区分显隐性基因，显性大写，隐性小写
   - 子代个体：可爱的豌豆/果蝇图标，颜色/形状对应表现型
   - 统计图表：柱状图展示表现型比例，理论比例用虚线标注
   - 逐代繁殖动画：个体"长大"然后产生下一代的动画效果
   - 控制面板：暖灰背景，精致的选择器和按钮
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一个 Punnett 方格加数字？有没有实验感？
   - 优化点：加入真实的子代群体模拟，让学生看到随机过程和统计规律
   - 增加"逐代繁殖"功能，模拟多代遗传，观察基因频率变化
   - 加入样本量对比，直观展示大样本下比例趋近理论值
5. 开始编码实现
   - 先实现遗传计算模块：配子生成、随机组合、基因型统计
   - 再实现 SVG 渲染层：Punnett 方格、个体图形、统计图表
   - 最后实现控制面板和交互逻辑
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 验证单基因和双基因模式下的遗传比例是否正确
   - 测试大样本（1000个）时的渲染性能
   - 检查 Punnett 方格与实际统计结果的一致性
   - 移动端显示清晰度测试
7. 保存到指定路径
