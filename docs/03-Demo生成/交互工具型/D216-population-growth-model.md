## 一、Demo 概述

本 Demo 通过数学建模的方式，可视化展示种群数量的动态变化过程。用户可以调节出生率、死亡率、环境容纳量、初始种群数量等参数，对比观察指数增长（J型曲线）和逻辑斯蒂增长（S型曲线）的差异，并扩展到捕食者-猎物模型（Lotka-Volterra）的周期性振荡。通过交互式操作，帮助学生理解种群生态学的核心规律，掌握微分方程建模的思想。

## 二、内容要求

### 知识点覆盖
- 种群增长的基本概念：出生率、死亡率、增长率
- 指数增长模型（J型曲线）：dN/dt = rN，N(t) = N₀·e^(rt)
- 逻辑斯蒂增长模型（S型曲线）：dN/dt = rN(1-N/K)
- 环境容纳量 K 值的概念与意义
- 种群增长速率的变化规律
- 捕食者-猎物模型（Lotka-Volterra 方程）
- 种间竞争模型
- 人口增长与环境承载力的现实意义

### 目标用户
- 高中生物必修3（稳态与环境）学生
- 大学生态学入门课程
- 数学建模课程微分方程应用
- 地理课人口增长专题

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 模型类型：指数增长 / 逻辑斯蒂增长 / 捕食者-猎物模型，默认逻辑斯蒂
  - 初始种群数量 N₀：10-10,000，步长 10，默认 100
  - 内禀增长率 r：0.01-2.0（每年），步长 0.01，默认 0.5
  - 环境容纳量 K：100-100,000，步长 100，默认 5,000
  - 模拟时间跨度：10-200 年，步长 5，默认 50
  - 捕食者参数（捕食者-猎物模式）：
    - 捕食者初始数量：10-1,000，步长 10，默认 50
    - 猎物被捕食率：0.001-0.1，步长 0.001，默认 0.01
    - 捕食者死亡率：0.1-1.0，步长 0.01，默认 0.5
    - 捕食者转化率：0.001-0.1，步长 0.001，默认 0.02
  - 显示选项：J型曲线对比 / 增长速率曲线 / K值标记线 / 平衡点标注，可多选
  - 显示数据：当前种群数 / 增长率 / 增长速率 / 达到K值时间
- 实时反馈：
  - 画布区显示种群增长曲线（N-t 图）
  - 逻辑斯蒂曲线用实线，指数增长用虚线对比
  - 下方显示增长速率曲线（dN/dt - N 图）
  - 捕食者-猎物模式下显示两条曲线（猎物种群 + 捕食者种群）
  - 右侧显示相空间轨迹图（捕食者-猎物模式）
  - 数据面板实时显示当前年份的种群数量和增长率
  - 曲线上有动态标记点随时间移动
- 预设模式：
  - 预设1：指数增长（理想条件，J型曲线）
  - 预设2：逻辑斯蒂增长（有限环境，S型曲线）
  - 预设3：K/2 增长点（最大持续产量原理）
  - 预设4：捕食者-猎物振荡（经典 Lotka-Volterra）
  - 预设5：不同 r 值对比（r-策略 vs K-策略）
  - 预设6：人口增长（历史数据拟合与未来预测）
- 播放/暂停：
  - 支持逐年播放种群增长动画
  - 支持播放/暂停
  - 支持重置到初始状态
  - 速度调节：1年/秒 / 5年/秒 / 10年/秒 / 20年/秒

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确各增长模型的数学原理和生物学意义
   - 确保微分方程求解和参数含义准确
   - 确定教学重点：J型vs S型对比 + K值理解 + 捕食者猎物振荡

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 画布区主图展示 N-t 增长曲线
   - 可切换显示增长速率曲线或相空间图
   - 底部控制面板：参数滑块组 + 模型切换 + 播放控制
   - 确保符合交互工具型精密仪器规范

3. 设计视觉方案（配色、布局、动效）
   - 增长曲线用渐变填充，从透明到绿色，有累积感
   - S型曲线的拐点处有特殊标记和说明
   - 播放时曲线有"生长"动画效果
   - 捕食者猎物两条曲线有节奏地此消彼长
   - 相空间轨迹用渐变色表示时间方向

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是普通的数学曲线图
   - 曲线要有生命力和流动感
   - 可以加入种群数量的可视化小人/动物图标
   - 考虑用粒子系统表现种群个体
   - 捕食者猎物模式要有生态系统的视觉叙事感

5. 开始编码实现
   - 先实现各模型的数值计算函数
   - 搭建图表画布，绘制坐标轴和网格
   - 实现增长曲线和面积填充
   - 添加数据点和标记
   - 实现捕食者-猎物双曲线和相空间图
   - 连接参数控制和动画播放

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 调节参数时曲线更新是否即时？
   - 曲线过渡是否平滑自然？
   - J型和S型对比是否清晰直观？
   - 捕食者猎物振荡是否有节奏感？
   - 数据标注是否准确易读？

7. 保存到指定路径
