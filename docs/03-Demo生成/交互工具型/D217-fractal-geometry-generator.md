## 一、Demo 概述

本 Demo 是一个交互式分形几何生成工具，支持科赫雪花、谢尔宾斯基三角形、曼德博集合、分形树等经典分形图案的可视化生成。用户可以调节迭代次数、缩放比例、角度、颜色等参数，实时观察分形图案的变化过程，体验"自相似"的数学之美。通过动手操作，帮助学生理解分形几何的核心概念，感受数学与艺术的融合。

---

## 二、内容要求

### 知识点覆盖
- 分形的定义与特征：自相似性、分数维度、无限精细
- 科赫雪花（Koch Snowflake）：等边三角形迭代生成
- 谢尔宾斯基三角形（Sierpinski Triangle）：中点连线迭代
- 分形树：二叉分支递归生长
- 曼德博集合（Mandelbrot Set）：复数迭代 z → z² + c
- 朱利亚集合（Julia Set）：固定参数的复数迭代
- 分形维度的计算：豪斯多夫维度
- 迭代与递归的数学思想
- 分形在自然界中的体现（海岸线、树叶、山脉等）

### 目标用户
- 初中数学拓展课（几何与图案）
- 高中数学选修（迭代与分形）
- 大学计算机图形学入门
- 数学爱好者与艺术爱好者

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 分形类型：科赫雪花 / 谢尔宾斯基三角 / 分形树 / 曼德博集合 / 朱利亚集合，默认分形树
  - 迭代次数：1-8（几何分形）/ 10-500（曼德博），步长 1，默认 5
  - 分形树角度：15°-75°，步长 1°，默认 30°
  - 分形树缩放比例：0.5-0.9，步长 0.01，默认 0.7
  - 科赫雪花边数：3-8，步长 1，默认 3（扩展为科赫曲线变体）
  - 曼德博参数：
    - 缩放级别：1x-100x，步长 0.5，默认 1x
    - 中心点 X：-2.0 到 1.0，步长 0.001，默认 -0.5
    - 中心点 Y：-1.0 到 1.0，步长 0.001，默认 0
    - 配色方案：火焰 / 海洋 / 彩虹 / 黑白，默认火焰
  - 显示选项：显示迭代步骤 / 显示分形维度值 / 显示坐标网格，可多选
  - 动画模式：逐步生成 / 直接显示，默认直接显示
- 实时反馈：
  - 画布区居中显示分形图案
  - 参数调节时分形图案实时重绘
  - 迭代生成模式下有逐步生长动画
  - 曼德博集合支持鼠标点击放大探索
  - 底部显示分形维度计算结果
  - 右上角显示当前迭代次数和生成时间
- 预设模式：
  - 预设1：经典科赫雪花（3阶迭代）
  - 预设2：谢尔宾斯基三角（6阶迭代）
  - 预设3：分形生命树（自然角度和比例）
  - 预设4：曼德博集合全景图
  - 预设5：曼德博海马谷放大
  - 预设6：朱利亚集合（兔子形状）
- 播放/暂停：
  - 支持逐阶迭代动画播放（观察分形生成过程）
  - 支持播放/暂停
  - 支持重置到第0阶
  - 速度调节：慢速 / 正常 / 快速
  - 曼德博模式支持自动漫游动画

## 五、技术实现

### 推荐技术栈
- Canvas 2D 用于几何分形绘制
- 曼德博/朱利亚集合推荐使用 WebGL（性能更好）或 Canvas 2D + 离屏渲染
- 纯 JavaScript 实现递归/迭代生成算法
- CSS 自定义控件样式
- 可用 OffscreenCanvas 提升性能

### 性能要求
- 首屏加载时间：< 2s（简单分形）/ < 3s（曼德博初始渲染）
- 是否需要加载动画：是，分形生长式加载动画
- 几何分形参数调节实时响应
- 曼德博集合渲染有进度条提示
- 建议使用低分辨率预览 + 高分辨率渐进渲染

### 响应式
- 移动端适配要求：画布自适应，保持正方形比例
- 最小支持宽度：375px
- 触摸设备支持双指缩放曼德博集合
- 控制面板在小屏可左右滑动切换参数组

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确各分形的数学定义和生成算法
   - 确保自相似性、分形维度等概念呈现准确
   - 确定教学重点：迭代/递归思想 + 自相似性 + 数学之美

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 画布区大面积展示分形图案
   - 底部控制面板：分形类型切换 + 参数滑块 + 播放控制
   - 确保符合交互工具型精密仪器规范

3. 设计视觉方案（配色、布局、动效）
   - 分形图案居中展示，有呼吸感
   - 逐阶生成时，每一层有淡入或生长动画
   - 曼德博集合用渐变色带，过渡平滑
   - 分形树有风吹动的微动画效果
   - 颜色渐变精致，避免色带断层

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是简单的几何图形堆砌
   - 分形图案要有艺术感和视觉冲击力
   - 生成动画要有生长的生命力
   - 曼德博的配色要精致，有深度感
   - 考虑加入分形维度的实时计算显示
   - 可以加入"无限放大"的探索体验

5. 开始编码实现
   - 先实现各分形的核心生成算法
   - 搭建画布和渲染循环
   - 实现几何分形的递归绘制
   - 实现曼德博/朱利亚集合的像素级渲染
   - 添加逐步生成动画
   - 连接参数控制和渲染更新

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 参数调节后重绘是否及时？
   - 分形图案边缘是否清晰无锯齿？
   - 生成动画是否流畅有美感？
   - 曼德博渲染是否有进度提示？
   - 配色是否有艺术感不俗气？

7. 保存到指定路径
