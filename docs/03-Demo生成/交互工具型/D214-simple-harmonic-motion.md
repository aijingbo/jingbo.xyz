## 一、Demo 概述

本 Demo 通过弹簧振子和单摆两种经典模型，可视化展示简谐运动的规律，并延伸到机械波的传播。用户可以调节振幅、频率、相位、阻尼系数等参数，实时观察位移-时间图像、速度-时间图像、能量变化曲线，以及横波纵波的传播过程。通过交互式操作，帮助学生建立振动与波动的物理图像，理解简谐运动的周期性和相位概念。

## 二、内容要求

### 知识点覆盖
- 简谐运动的定义与条件：回复力 F = -kx
- 描述简谐运动的物理量：振幅、周期、频率、角频率、相位
- 简谐运动的位移公式：x = A·cos(ωt + φ)
- 简谐运动的速度和加速度变化规律
- 简谐运动的能量：动能与势能的相互转化，机械能守恒
- 单摆的周期公式：T = 2π√(L/g)
- 阻尼振动：欠阻尼、过阻尼、临界阻尼
- 受迫振动与共振现象
- 机械波的形成与传播：横波与纵波
- 波长、波速、频率的关系：v = λf
- 波的叠加原理与干涉现象

### 目标用户
- 高中物理选修3-4学生
- 大学普通物理力学部分学习者
- 物理教师课堂演示

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 振动模型：弹簧振子 / 单摆 / 波动，默认弹簧振子
  - 振幅 A：1-10 cm（弹簧）/ 5-45°（单摆），步长 1，默认 5
  - 角频率 ω：0.5-5 rad/s，步长 0.1，默认 2
  - 初相位 φ：0-2π，步长 π/12，默认 0
  - 阻尼系数 γ：0-1，步长 0.01，默认 0（无阻尼）
  - 驱动力频率：0.5-5 Hz，步长 0.1，默认 2（受迫振动模式）
  - 波动参数：波长 50-300px，步长 10，默认 150；波速 20-200px/s，步长 10，默认 80
  - 显示选项：位移曲线 / 速度曲线 / 加速度曲线 / 能量曲线 / 参考圆，可多选
  - 显示数据：实时位移/速度/加速度数值 / 周期频率 / 当前相位
- 实时反馈：
  - 上半部分：振动动画区（弹簧振子左右振动或单摆摆动）
  - 下半部分：实时绘制的 x-t 图像（位移-时间曲线）
  - 可切换显示 v-t、a-t、E-t 图像
  - 参考圆（旋转矢量）与振动同步运动，展示相位关系
  - 能量条形图实时显示动能和势能的转化
  - 波动模式下显示波形传播，可暂停观察各质点振动
- 预设模式：
  - 预设1：无阻尼简谐运动（标准SHM）
  - 预设2：欠阻尼振动（振幅逐渐衰减）
  - 预设3：共振现象（驱动力频率=固有频率）
  - 预设4：单摆的等时性（不同振幅同期相同）
  - 预设5：横波传播（展示振动与波动的关系）
  - 预设6：波的叠加（两列波相遇干涉）
- 播放/暂停：
  - 支持播放/暂停振动动画
  - 支持单步前进（逐帧观察）
  - 支持重置到初始状态
  - 速度调节：0.25x / 0.5x / 1x / 2x
  - 慢动作模式：观察能量转化细节

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确简谐运动的核心公式和物理意义
   - 确保相位、阻尼、共振等概念呈现准确
   - 确定教学重点：振动图像理解 + 能量转化 + 波动形成

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 画布区分上下两部分：上半振动动画，下半曲线图
   - 底部控制面板：参数滑块组 + 模型切换 + 播放控制
   - 确保符合交互工具型精密仪器规范

3. 设计视觉方案（配色、布局、动效）
   - 弹簧用螺旋线绘制，压缩拉伸时有弹性形变效果
   - 摆球用渐变球体，摆动时有运动模糊效果
   - 曲线用平滑贝塞尔曲线，带渐变发光效果
   - 参考圆与振动之间有虚线连接，展示相位对应关系
   - 能量条形图有流畅的填充动画

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是简单的球+弹簧动画
   - 弹簧形变要自然真实，有物理弹性的感觉
   - 曲线绘制要有"示波器"的科技感
   - 考虑加入质点轨迹的残影效果
   - 共振时可以有特别的视觉强调

5. 开始编码实现
   - 先实现简谐运动的物理计算引擎
   - 绘制弹簧振子/单摆的动画
   - 实现实时曲线绘制功能
   - 添加参考圆和能量图
   - 实现波动传播和叠加效果
   - 连接参数控制和动画更新

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 振动动画是否流畅自然？
   - 曲线绘制是否平滑无锯齿？
   - 参数调节时响应是否即时？
   - 各图像之间的同步是否精确？
   - 阻尼效果是否真实自然？

7. 保存到指定路径
