## 一、Demo 概述

本 Demo 通过交互式波形图直观展示正弦、余弦、正切等三角函数的图像特征，以及振幅、周期、相位、垂直位移四个参数对波形的影响。用户可以实时调节 A、ω、φ、k 四个参数，观察 y = Asin(ωx + φ) + k 函数图像的连续变化，深入理解三角函数图像变换的规律。配合单位圆联动演示和波形叠加功能，帮助学习者建立三角函数的几何直观。

## 二、内容要求

### 知识点覆盖
- 正弦函数 y = sin(x) 的图像与性质：定义域、值域、周期性、奇偶性
- 余弦函数 y = cos(x) 的图像与性质：与正弦函数的相位关系
- 正切函数 y = tan(x) 的图像与性质：定义域、渐近线、周期
- 振幅变换（A）：y = Asin(x)，A 决定函数的最大值和最小值，|A| 为振幅
- 周期变换（ω）：y = sin(ωx)，周期 T = 2π/ω，ω 影响波形的疏密
- 相位变换（φ）：y = sin(x + φ)，图像左右平移，"左加右减"
- 垂直平移（k）：y = sin(x) + k，图像上下平移
- 综合变换：y = Asin(ωx + φ) + k 中各参数的综合作用
- 单位圆与三角函数线：正弦线、余弦线与波形图的对应关系
- 三角函数的物理意义：简谐振动、波动方程

### 目标用户
- 高中数学学生，正在学习三角函数章节
- 高中数学教师用于课堂演示图像变换
- 物理学生理解简谐运动和波动的数学基础

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 振幅（A）：范围 -5~5，步长 0.1，默认值 1
  - 角频率（ω）：范围 0.2~5，步长 0.1，默认值 1（对应周期 T = 2π）
  - 初相位（φ）：范围 -π~π，步长 π/12（15°），默认值 0
  - 垂直位移（k）：范围 -5~5，步长 0.1，默认值 0
  - 函数类型：下拉选择，选项包括【正弦 sin / 余弦 cos / 正切 tan / sin+cos 叠加】，默认正弦
  - 显示选项：多选开关组，包括【网格线 / 坐标轴刻度 / 振幅标注 / 周期标注 / 相位标注 / 单位圆联动 / 五点标记】，默认显示网格线+坐标轴刻度+周期标注
  - 显示范围：X 范围（0~2π / -2π~2π / 0~4π），Y 范围（自适应 / -5~5 / -10~10）
- 实时反馈：
  - 画布上实时绘制函数图像，参数变化时波形平滑过渡
  - 红色虚线标注振幅（最大值/最小值位置）
  - 蓝色虚线标注周期（一个完整波形的宽度）
  - 绿色点标注"五点法"的五个关键点
  - 开启单位圆联动时，左侧显示单位圆，角 x 对应的正弦线/余弦线与波形图上的点实时对应
  - 右侧信息面板显示：函数表达式、振幅 |A|、周期 T、频率 f、初相位 φ、最大值、最小值
  - 参数调节时，函数表达式中的 A、ω、φ、k 数值实时更新
- 预设模式：
  - 预设1：标准正弦（A=1, ω=1, φ=0, k=0）——基础波形
  - 预设2：振幅变换（A=2, ω=1, φ=0, k=0）——理解振幅概念
  - 预设3：周期压缩（A=1, ω=2, φ=0, k=0）——频率加倍，周期减半
  - 预设4：相位移动（A=1, ω=1, φ=π/2, k=0）——sin(x+π/2) = cos(x) 的关系
  - 预设5：简谐振动（A=2, ω=3, φ=-π/4, k=1）——综合变换实例
- 播放/暂停：
  - 支持相位自动变化播放，观察波形向左/向右移动（行波效果）
  - 支持角频率自动变化，观察波形疏密渐变
  - 播放速度可调（慢速/中速/快速）
  - 重置按钮：恢复默认参数

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 核心目标：理解三角函数图像的四个参数变换（A、ω、φ、k）
   - 重点：振幅、周期、相位的概念及其对图像的影响
   - 难点：相位变换的"左加右减"容易混淆，需要直观演示
   - 科学准确性：函数计算准确，周期公式 T=2π/ω 正确，单位圆对应关系准确
2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 上下分栏：上80%画布区（波形图+单位圆），下20%控制面板
   - 左侧参数滑块组：振幅 A、角频率 ω、初相位 φ、垂直位移 k
   - 右侧功能按钮组：函数类型选择 + 播放/暂停 + 预设按钮 + 显示选项
   - 画布上波形图占据主要区域，单位圆可放置在左上角或左侧
3. 设计视觉方案（配色、布局、动效）
   - 坐标系：浅灰网格，X 轴用 π 刻度标注（π、2π、π/2 等）
   - 波形：平滑曲线，2px 线宽，颜色鲜明
   - 振幅标注：橙色虚线从平衡位置到最高点，标注 A
   - 周期标注：绿色双向箭头标注一个完整周期的宽度
   - 五点标记：红色小圆点，标注"起点/最高点/中点/最低点/终点"
   - 单位圆：灰色圆，角度用蓝色半径线指示，正弦线/余弦线用对应颜色
   - 控制面板：暖灰背景，滑块有精致的轨道和拇指
4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 检查：是不是只是一条正弦曲线加四个滑块？有没有教学深度？
   - 优化点：加入单位圆联动，让学生看到角度变化如何"展开"成波形
   - 增加波形叠加功能，展示傅里叶级数的初步思想
   - 加入"五点法"绘图动画，展示手工画图的过程
5. 开始编码实现
   - 先实现数学计算模块：根据参数计算各点坐标、周期、振幅等
   - 再实现 Canvas 波形渲染和 SVG 单位圆/标注
   - 最后实现控制面板和交互逻辑
6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 测试参数调节时波形的平滑过渡
   - 验证单位圆与波形的对应关系是否准确
   - 检查函数表达式显示是否正确（注意符号处理，如 φ 为负时的显示）
   - 移动端双指缩放和平移体验测试
7. 保存到指定路径
