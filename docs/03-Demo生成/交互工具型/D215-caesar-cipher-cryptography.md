## 一、Demo 概述

本 Demo 是一个交互式古典密码学学习工具，通过可视化方式展示凯撒密码和替换密码的加密解密过程。用户可以输入明文、调节移位参数、观察字母映射关系，实时查看加密结果，并尝试通过频率分析破解密文。通过动手操作，帮助学生理解密码学的基本原理，建立信息安全的初步概念。

## 二、内容要求

### 知识点覆盖
- 凯撒密码的原理：字母移位替换
- 加密公式：C = (P + k) mod 26
- 解密公式：P = (C - k) mod 26
- 单表替换密码：随机字母映射
- 频率分析：字母出现频率与破解
- 密钥空间与安全性分析
- 维吉尼亚密码简介（多表替换扩展）
- 密码学基本概念：明文、密文、密钥、加密、解密

### 目标用户
- 初中信息技术课学生
- 高中信息技术选修模块
- 密码学入门爱好者
- 数学拓展课（模运算应用）

## 三、呈现框架

### 交互工具型
- 参数控制：
  - 密码类型：凯撒密码 / 单表替换密码 / 维吉尼亚密码，默认凯撒
  - 移位密钥 k：0-25，步长 1，默认 3（凯撒密码模式）
  - 操作模式：加密 / 解密，默认加密
  - 自定义替换表：可点击字母修改映射关系（替换密码模式）
  - 密钥词输入：维吉尼亚密码的密钥词（字母组成）
  - 显示选项：字母映射连线 / 频率柱状图 / 字母轮 / 步骤说明，可多选
  - 动画速度：慢速 / 正常 / 快速，默认正常
  - 明文输入框：支持直接输入或粘贴英文文本
- 实时反馈：
  - 中部显示字母映射轮：明文字母环 + 密文字母环，连线显示对应关系
  - 下方明文与密文对照显示，每个字母高亮对应
  - 右侧频率分析图：明文字母频率 vs 密文字母频率柱状图
  - 字符逐个加密时有高亮流动动画
  - 底部显示当前密钥和加密公式
  - 破解模式下显示频率匹配结果和可能的密钥猜测
- 预设模式：
  - 预设1：凯撒密码经典示例（移位3，"HELLO"）
  - 预设2：凯撒密码破解（密文+频率分析）
  - 预设3：单表替换加密（随机映射表）
  - 预设4：维吉尼亚密码演示（多表替换）
  - 预设5：对称加密原理示意（加密解密可逆性）
- 播放/暂停：
  - 支持逐字符加密动画播放
  - 支持播放/暂停动画
  - 支持重置
  - 支持单步前进（一个字符一个字符地加密）

## 七、设计与实现流程

请按照以下流程工作：
1. 理解知识点和教学目标
   - 明确凯撒密码和替换密码的核心原理
   - 确保加密解密算法和频率分析准确
   - 确定教学重点：替换原理 + 密钥概念 + 频率分析破解思想

2. 确定最佳呈现方式（是否符合对应框架的规范）
   - 画布区中心展示字母轮和映射关系
   - 上下分布：上方输入输出区，下方控制面板
   - 确保符合交互工具型精密仪器规范

3. 设计视觉方案（配色、布局、动效）
   - 字母轮采用同心圆设计，内外环可相对旋转
   - 映射连线用贝塞尔曲线，高亮时发光
   - 字符加密时有"传送"动画效果
   - 频率柱状图有弹性增长动画
   - 字母轮旋转有机械齿轮的节奏感

4. 自我审查：有没有落入模板化默认设计？够不够震撼？
   - 避免只是简单的文本输入输出
   - 字母轮的旋转动画要有机械感
   - 字符映射的视觉连线要清晰美观
   - 考虑加入密码盘的立体效果
   - 破解模式要有"侦探推理"的趣味感

5. 开始编码实现
   - 先实现凯撒密码和替换密码的核心算法
   - 绘制字母轮和映射连线
   - 实现文本输入和实时加密
   - 添加频率分析图表
   - 实现逐字符加密动画
   - 连接参数控制和交互逻辑

6. 自我审查：交互是否流畅？视觉是否精致？哪里可以再优化？
   - 调整移位时字母轮旋转是否流畅？
   - 加密动画是否有趣味性？
   - 明密文对应关系是否清晰？
   - 频率分析图是否直观易懂？
   - 替换密码模式下自定义映射是否方便？

7. 保存到指定路径
