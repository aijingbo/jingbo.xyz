## 一、Demo 概述

本 Demo 以时空叙事的方式，通过地图 + 时间轴的双维度呈现，讲述多维度历史事件筛选交互时间轴的历史故事。用户可以跟随时间的推进，看到事件在空间中的展开和演变，理解历史进程的时空关联性。精心设计的叙事节奏和视觉呈现，让历史不再是枯燥的年份堆砌，而是一段可感知、可探索的时空旅程。

## 三、呈现框架

### 时空叙事型
- 地图范围：根据主题确定（世界 / 中国 / 某区域）
- 时间跨度：根据主题确定（从 X 年到 Y 年）
- 事件数量：8-15 个关键事件节点
- 叙事主线：一句话概括故事线，贯穿整个 Demo

### 交互方式
1. **时间轴驱动**：底部时间轴，拖拽/点击跳转到不同时间点
2. **地图探索**：地图可平移缩放，点击事件标记查看详情
3. **自动播放**：播放/暂停按钮，按时间顺序自动推进叙事
4. **事件卡片**：点击地图标记或时间轴节点，弹出事件详情卡片
5. **路径动画**：事件之间有连线/路径动画，展示空间关联

### 信息层级
- **宏观层**：整体时间跨度 + 地图全局，鸟瞰全貌
- **中观层**：时间段落 + 区域聚焦，理解阶段特征
- **微观层**：单个事件 + 具体地点，深入细节

## 四、视觉设计要求

### 整体气质
- 历史厚重感 + 人文气息，如同一本精美的历史地图册
- 叙事感强，有起承转合的节奏
- 配色稳重而不沉闷，有年代感但不陈旧
- 地图风格统一，标注清晰有层次

### 配色方案
- 主色调：#B45309（赭石色），用于事件标记、路径线、强调元素
- 地图底色：#f5f0e8 暖米色（古地图质感）或 #e8e4df 浅灰色
- 背景色：#faf8f5 暖米白（与景礴设计系统统一）
- 时间轴颜色：#d4c4b0 暖棕色调，有历史感
- 事件标记：#B45309 实心圆点 + 白色外圈，选中时放大并发光
- 路径线：#92400E 半透明曲线，带流动光效
- 是否遵循景礴设计系统：是，暖米白底色、赤陶暖调色系、杂志质感

### 参考方向
- 国家地理杂志的历史地图风格
- 纽约时报的交互式历史报道
- 丝绸之路历史地图的视觉风格
- Atlas Obscura 的地图设计
- 复古地图集的配色和字体

## 五、技术实现

### 推荐技术栈
- Leaflet.js（交互式地图，轻量且无需 API Key）
- 或 D3.js + SVG（手绘风格地图，更有杂志感）
- 时间轴：vis-timeline 或自定义实现
- GSAP（路径动画、元素过渡、叙事节奏控制）
- 地图数据：GeoJSON 格式（可使用公开的简化版地图数据）

### 性能要求
- 首屏加载时间：< 2s（地图瓦片或 SVG 加载）
- 是否需要加载动画：是，地图渐入 + 时间轴出现动画
- 动画帧率：60fps（路径动画需要流畅）
- 地图瓦片：使用 CDN 加速的开源地图底图，或使用纯 SVG 手绘地图

### 响应式
- 移动端适配要求：地图占满上半屏，时间轴在底部可展开/收起
- 事件卡片在移动端改为全屏模态框
- 触控设备支持双指缩放地图
- 最小支持宽度：375px
