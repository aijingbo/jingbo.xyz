## 新窗口交接流程

```
1. 读取本文件（00-主索引）了解全局
2. 读取 04-设计系统规范 + 05-开发框架指引 了解技术约束
3. 读取对应的任务文档（tasks/T01-xxx.md）了解具体要做什么
4. 执行任务，产出文件
5. 更新本文件中对应任务的状态
```
