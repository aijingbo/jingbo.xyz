## 执行步骤

### 第一步：统计现状

1. 读取 `skills/` 目录，列出已完成的 16 个技能：名称、学科、对应的 demo
2. 读取 `skill-prompts/` 目录，列出 40 个提示词草稿：名称、学科
3. 遍历 `demos/` 目录，列出所有 demo：目录名、标题、学科
4. 读取 `docs/04-Skill生成/Demo-Skill映射表.md`，获取规划的 39 个 Skill
5. 生成「技能现状总表」（保存到 `docs/04-Skill生成/技能现状总表.md`），包含四个分类：
   - **已完成**：有 .md + .html 的技能（16个）
   - **有草稿未制作**：有 skill-prompts 草稿但无 skills/ 下的正式文件
   - **有 demo 无技能**：demos/ 中有 demo 但无对应 Skill
   - **完全空白**：映射表中规划了但既无 demo 也无 Skill

### 第二步：统一命名

1. 将 `skills/` 下现有的 16 个技能文件重命名为新规范：
   - 旧名：`math-graph-tool.md` → 新名：`景礴-Edu-math-graph-tool-v0.1.md`
   - 旧名：`physics-experiment-sim.md` → 新名：`景礴-Edu-physics-experiment-sim-v0.1.md`
   - 以此类推
2. 同步更新 `skills.html` 中的所有引用路径

### 第三步：编写缺失技能

1. 优先为「有 demo 无技能」的方向编写 Skill 文件
2. 每个 Skill 的 `.md` 文件结构：
   ```markdown
   # 景礴-Edu-[方向名称] v0.1

   ## 基本信息
   - 技能名称：[中文名称]
   - 学科：[学科]
   - 对应 Demo：[demo 目录名]
   - 框架类型：[沉浸式全屏型/杂志讲解型/交互工具型/时空叙事型]

   ## 技能描述
   [一段话描述这个技能做什么]

   ## 提示词
   [完整的 Trae Skill 提示词，用户粘贴到 Trae 后说一句话即可生成对应课件]

   ## 示例输入
   用户：[示例输入]

   ## 示例输出
   [描述生成的课件效果]
   ```
3. 每个 Skill 的 `.html` 预览页：
   - 展示该技能的名称、学科、简介
   - 展示该技能能生成的 demo 效果（可嵌入对应 demo 的 iframe 或截图）
   - 「复制提示词」按钮
   - 「进入课件」链接
   - 风格与现有 skills/ 下的 .html 保持一致（科学杂志风，赤陶暖调）

4. 技能提示词要求：
   - 自然语言驱动，用户在 Trae 中粘贴后说一句话即可生成对应课件
   - 提示词应包含：角色设定、能力描述、输出规范、设计风格要求
   - 设计风格统一要求：科学杂志风，赤陶暖调，赤陶色 #c2410c，暖米白 #faf8f5

### 第四步：更新技能库页面

1. 读取当前 `skills.html`，理解现有结构
2. 将全部技能录入技能库页面
3. 按学科分组展示
4. 每个技能卡片包含：
   - 技能名称
   - 学科标签
   - 简介
   - 「复制提示词」按钮
   - 「查看预览」链接（指向 .html 预览页）
   - 「进入课件」链接（指向对应 demo）
5. 保留搜索、筛选功能
6. 统计区域显示：总技能数、覆盖学科数
