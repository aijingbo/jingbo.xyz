## 验收路径（按顺序走）

### 第一遍：首页 → 展品列表页

1. 打开 `index.html`
2. 检查首屏视觉是否正常
3. 点击顶部导航的"展品库" → 应该跳到 `demos.html`
4. 点击顶部 logo → 应该跳回首页
5. 点击"查看所有 Skill" → 应该跳到 `skills.html`

### 第二遍：展品列表页 → Demo 页

1. 在 `demos.html` 上
2. 切换左侧学科分类，确认卡片筛选正常
3. 切换类型筛选，确认正常
4. **每个类型至少点 3 个 Demo** 进去看：
   - 沉浸式 3 个（推荐 D004 太阳系、D006 人体器官、D010 板块构造）
   - 杂志 3 个（推荐 D106 相对论、D107 微积分、D112 免疫系统）
   - 工具 3 个（推荐 D211 二叉树、D217 分形、D218 钢琴）
   - 时空 2 个（推荐 D301 李白、D303 太平洋战场）
5. 每个 Demo 检查：
   - [ ] 页面能正常加载，没有白屏
   - [ ] 控制台有没有报错（F12 看 Console）
   - [ ] 顶部导航栏显示正常
   - [ ] 点击返回按钮能回到 demos.html
   - [ ] 点击 logo 能回到 index.html
   - [ ] Demo 的核心交互功能正常
   - [ ] 视觉风格统一（和设计系统一致）

### 第三遍：Demo 页 → 列表页 → 另一个 Demo

1. 从 demos.html 点进一个 Demo
2. 点返回回到 demos.html
3. 切换学科筛选
4. 再点进另一个 Demo
5. 再返回
6. 确认链路顺畅，没有路径错误

## 常见 Bug 类型及修复优先级

### 🔴 致命（必须修）
- 页面白屏 / 完全打不开
- 点击返回跳错页面 / 404
- 导航被画布遮挡，点不到
- 控制台有红色报错导致功能失效

### 🟡 中等（尽量修）
- 标题格式不统一
- 学科标签颜色不对
- 动画卡顿 / 性能差
- 移动端样式错乱

### 🟢 轻微（有时间再修）
- 字体加载慢或 fallback
- 某些边缘 case 的样式问题
- 文案错别字

---

## 修复原则

1. **优先修链路问题**：导航、返回、跳转，这些是骨架
2. **其次修功能问题**：Demo 本身的交互 bug
3. **最后修视觉细节**：统一间距、颜色、字体
4. **不要大改结构**：只修 Bug，不重构
5. **改一个测一个**：每修完一个，刷新确认修好再改下一个
