## 检查清单

对每个 Demo，检查以下项目：

### 1. 导航结构完整性
- [ ] 有返回按钮（← 或 "返回" 文字）
- [ ] 有品牌/logo 区域
- [ ] 中间有 Demo 标题
- [ ] 右侧有学科标签
- [ ] 右侧有"下载 Skill"或类似按钮（可选，不强求）

### 2. 导航样式
- [ ] 深色模式适配（因为沉浸式背景是深灰/近黑）
- [ ] 毛玻璃/半透明效果
- [ ] 文字是浅灰色，在深色背景上可读
- [ ] 高度合理，不要太粗太笨
- [ ] 圆角/边框风格和设计系统一致

### 3. 功能正确性
- [ ] 返回按钮链接到 `../demos.html`
- [ ] logo 链接到 `../index.html`
- [ ] 导航不被 3D 画布遮挡（z-index 够高）
- [ ] 鼠标可以正常点击导航元素
- [ ] 滚动时导航行为正常（如果有滚动效果的话）

### 4. 底部信息条（可选）
- [ ] 是否有底部半透明信息条（Skill 信息 + 技术栈）
- [ ] 如果有，样式是否统一

---

## 修复原则

1. **以最优的那个为标杆**：先看 9 个里面哪个导航做得最好、最完整，就以它为标准
2. **最小改动原则**：如果某个 Demo 的导航已经很好了，就不要动
3. **不要破坏 3D 功能**：改导航时注意不要影响 Three.js 画布的初始化和渲染
4. **统一是目标**：9 个 Demo 打开后，导航栏看起来应该是一套的

---

## 沉浸式导航规范（参考）

根据设计文档：
- 背景色：深灰 #0f0f0f 或 #1a1a1a
- 导航：半透明毛玻璃，深色模式
- 左下角浮动：播放/暂停按钮（圆形图标按钮）
- 右下角浮动：全屏按钮（圆形图标按钮）
- 底部半透明信息条（Skill 信息 + 技术栈）
- UI 元素尽量少且半透明，不抢内容的戏
- 控件用圆形图标按钮，半透明白色背景
- 文字用浅灰色
