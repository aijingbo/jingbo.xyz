## 修复要求

### 通用要求
1. 两个 Demo 的顶部导航必须和其他同类型 Demo 保持一致
2. 必须有返回按钮，点击后跳转到 `../demos.html`（展品列表页）
3. 必须有 logo/品牌标识，点击后跳转到 `../index.html`（首页）
4. 中间显示 Demo 标题
5. 右侧显示学科标签
6. 导航样式：半透明毛玻璃效果

### D001 沉浸式的特殊要求
- 导航栏必须是**深色模式**的（因为背景是深灰近黑的沉浸式）
- 参考 D002（3d-molecule-viewer）或 D003（earth-seasons）的导航样式
- 导航文字用浅灰色，不要用深色
- 毛玻璃效果在深色背景上要看得出来

### D206 交互工具型的特殊要求
- 导航栏是**浅色模式**的（暖米白背景）
- 参考 D205（circuit-simulation）或 D207（mendelian-genetics）的导航样式
- 导航样式和其他交互工具型 Demo 保持一致

1. **不要破坏原有功能**：D001 的 Three.js 3D 渲染、D206 的波形生成功能都必须完好
