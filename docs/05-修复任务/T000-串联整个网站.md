## 你要做的三件事

### 第一件：更新 demos.html 展品列表页

当前 demos.html 只有 11 张卡片（用的旧命名），需要：

1. 把卡片扩展到所有已有的 49 个 Demo
2. 每个卡片链接到对应的 `demos/{文件夹名}/index.html`
3. 卡片需要包含：
   - 学科标签（小药丸形，用对应学科色）
   - Demo 名称（衬线字体）
   - 一句话描述（15-20 字）
   - 类型标签（沉浸式/杂志讲解/交互工具/时空叙事）
4. 左侧学科筛选功能要能正常工作（数学、物理、化学、生物、地理、历史、计算机、艺术、天文、经济、音乐、跨学科）
5. 类型筛选也要能用
6. 卡片的预览区（目前是 SVG 占位）可以先用 CSS 渐变 + 学科色 + 图标占位，不用做真实预览图
7. 保持原有的设计风格和动效（hover 上浮、阴影、过渡动画等）
8. 卡片按一定顺序排列（建议按编号顺序：沉浸式→杂志→工具→时空）

### 第二件：更新 index.html 首页

1. 首页特辑展示区的"打开展品"按钮，要链接到真实的 Demo 页面
   - 特辑区选 4-6 个最有视觉冲击力的 Demo 作为封面
   - 推荐：D004 太阳系、D001 DNA、D002 分子、D301 李白、D101 傅里叶、D203 圆锥曲线
   - 每个特辑的"打开展品"按钮链接到对应 Demo
2. 首页底部的"浏览全部展品"按钮链接到 `demos.html`
3. 首页底部的"查看所有 Skill"按钮链接到 `skills.html`
4. 导航栏的链接也要对应正确（首页→index.html，展品库→demos.html，Skill 库→skills.html）
5. 导航栏 logo 链接到 `index.html`

### 第三件：检查导航闭环

1. 抽查至少 10 个不同类型的 Demo 页面
   - 沉浸式 3 个
   - 杂志讲解 3 个
   - 交互工具 2 个
   - 时空叙事 2 个
2. 确认顶部导航栏有"返回"按钮能回到 demos.html
3. 确认导航栏的 logo 能回到 index.html
4. 如果 Demo 页面的导航有问题，记录下来（不要自己改，因为 T002 和 T003 专门处理导航问题）
5. 只记录问题，不修复——导航修复交给其他任务
