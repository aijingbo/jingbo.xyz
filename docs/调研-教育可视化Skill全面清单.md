## 未纳入但值得关注的方向

### 1. Manim 数学动画生态

- **方向**: Manim 是 3Blue1Brown 开发的数学动画引擎（原版 75K+ Star，社区版 ManimCommunity 极活跃，495 位贡献者）
- **未纳入原因**: Manim 是 Python 生态，产出为视频而非 Web 交互式内容，不符合"单 HTML 文件"的 Skill 要求
- **价值**: 可作为动画设计理念参考；ManimCommunity 有 Jupyter 集成，未来或可实现交互式 notebook
- **中文社区**: manim-kindergarten 维护中文文档 (docs.manim.org.cn)

### 2. PhET Scenery 框架

- **方向**: PhET 自研的 HTML5 场景图库 Scenery，MIT 许可，支持 WebGL/SVG/Canvas 多后端
- **未纳入原因**: 虽然框架层 MIT 可复用，但依赖完整 PhET 工具链（assert/axon/chipper/dot/kite 等 10+ 仓库），定制化成本极高
- **价值**: 作为构建自定义教育仿真的底层框架，scenerystack.org 有文档

### 3. GeoGebra 全功能嵌入

- **方向**: GeoGebra Apps API 功能极强（2D/3D 几何、代数、CAS、导出 SVG/PDF/PNG）
- **未纳入原因**: 依赖加载 GeoGebra 运行时（非纯单 HTML 自包含），GPL/非商用许可限制再分发
- **价值**: 适合做交互式数学 applet 的快速原型

### 4. Wolfram Demonstrations

- **方向**: 13,000+ 交互演示，覆盖数学/物理/化学等
- **未纳入原因**: 依赖 Mathematica/Wolfram Player，不适合单 HTML 实现
- **价值**: 作为知识点覆盖度参考

### 5. VR/AR 教育可视化

- **方向**: WebXR 设备下的沉浸式教育体验（如 Geo-AR 的 3D 几何学习）
- **未纳入原因**: 需要 VR/AR 设备支持，受众面窄，不符合"浏览器打开即可交互"的便捷性要求
- **价值**: 未来发展方向，随着设备普及可纳入

### 6. AI 驱动的自适应可视化

- **方向**: 结合大语言模型，根据学生输入自动生成交互式可视化
- **未纳入原因**: 当前调研聚焦于标准化的知识点可视化 Skill，AI 自适应生成是更高层次的编排
- **价值**: 作为 Trae Skill 生态的终极目标——教师描述需求，AI 自动选择并定制可视化

### 7. 中文虚拟实验平台开源替代

- **方向**: NOBOOK 虚拟实验室验证了中文 K12 市场需求，但其为商业闭源产品
- **未纳入原因**: 构建完整的虚拟实验平台（含物理引擎、器材库）超出单 HTML Skill 的范围
- **价值**: 可从简单实验（光学/力学）入手，逐步构建开源替代

## 关键发现与建议

### 1. 开源空白领域（机会最大）

以下方向在 GitHub 上几乎没有开源项目，是最大的机会点：
- **几何光学（小孔成像/全反射）**: GitHub 搜索返回 0 结果
- **圆锥截面 3D**: 现有项目仅 6 Star 且 7 年未更新
- **热力学循环 P-V 图**: 几乎无开源可视化项目
- **傅里叶变换交互式工具**: 有视频但缺乏可交互 Web 工具

### 2. GitHub 教育 topics Star 数普遍偏低

- math-education（68 仓库，最高 18 Star）
- science-education（86 仓库，最高 90 Star）
- interactive-simulation（34 仓库，多偏向 AI/机器人）

说明教育可视化是一个"需求大但供给少"的领域，新项目容易脱颖而出。

### 3. 技术栈推荐

所有 P0 方向均可通过**单 HTML 文件**实现，推荐技术组合：
- **2D 数学/物理**: Canvas + JSXGraph（CDN）或纯 Canvas 自定义渲染
- **3D 几何/化学/生物**: Three.js（CDN）或 3Dmol.js（CDN，化学专用）
- **公式渲染**: KaTeX（CDN，20K+ Star，MIT，无依赖）
- **表达式解析**: math.js（CDN，15K Star，Apache-2.0）
- **符号计算**: nerdamer（CDN，MIT）
- **物理引擎**: Matter.js（CDN，18K Star，MIT）
- **数据可视化**: D3.js（CDN，105K Star，ISC）
- **动画**: anime.js（CDN，71K Star，MIT）
- **音乐交互**: Tone.js（CDN，MIT）
- **色彩**: chroma.js（CDN，BSD）

### 4. 单 HTML 自包含教育工具是蓝海

本次搜索未发现一个成熟的、被广泛命名的"单 HTML 教育工具"生态类别。Trae Skill 这类"零依赖单文件交互件"模式在教育可视化领域有显著的差异化机会。

### 5. PhET 是最佳参考范式

PhET 由诺贝尔物理学奖得主 Carl Wieman 于 2002 年创立，基于广泛教育研究，免费开放，覆盖 100+ HTML5 仿真。中国学术界已发文研究其对标模式。建议参考 PhET 的仿真设计理念（直观、类似游戏的环境、激励探索和发现），但用更轻量的单 HTML 技术栈实现。
