# 景礴 · Skill 列表页设计需求 Brief

> 页面：skills.html
> 输出文件：/Users/a1/Desktop/jingbo.xyz/skills.html

---

## 一、页面定位

**Skill 列表页**是用户浏览和下载所有 Skill 的页面。

它的任务是：
- 让用户按学科找到需要的 Skill
- 讲清楚每个 Skill 能做什么
- 提供便捷的复制/下载功能

> 注：Skill = 知识可视化生成模板。用户把 Skill 复制到 Trae 里，就能用一句话生成对应的可视化课件。

---

## 二、设计要求

### 核心气质
- 延续科学杂志风，但稍微偏"工具说明书"的感觉
- 清晰、高效、有品质
- 不要做成 B 端后台的列表样式
- 要有设计感，同时信息密度合理

### 设计语言
- 配色：赤陶暖调 + 暖米白底
- 字体：标题衬线，正文无衬线
- 引入设计系统 CSS：`/assets/css/design-system.css`

---

## 三、页面结构

### 顶部：导航栏
- 和首页统一的毛玻璃导航栏
- 左侧：← 返回首页 + 景礴 logo
- 中间：Skill 库
- 右侧：搜索框

### 主体：两栏布局

**左侧边栏：学科导航**
- 和展品列表页保持一致
- 学科分类 + 数量
- 按类型筛选（沉浸/讲解/工具/叙事）

**右侧主内容区：Skill 列表**
- 顶部：当前分类标题（如"数学 · 8 个 Skill"）
- 列表形式（不是网格卡片），每行一个 Skill
- 每行包含：
  - Skill 名称（衬线字体，较醒目）
  - 一句话简介（说明这个 Skill 能做什么）
  - 学科标签 + 类型标签
  - "复制 Skill"按钮（主按钮样式）
- 行与行之间有细分隔线
- Hover 时背景微变

---

## 四、Skill 卡片/行设计

### 信息结构（从左到右或从上到下）
1. **Skill 名称**：主标题，衬线字体
2. **简介**：一句话说清楚能做什么
   - 例："输入一道几何证明题，自动生成步骤化解题动画"
3. **标签**：学科 + 呈现类型
4. **操作按钮**：复制 Skill

### 设计细节
- 每行高度适中，不要太挤
- "复制 Skill"按钮要醒目但不抢戏
- 可以加一个小图标表示 Skill 类型（如 3D 图标、书本图标、滑块图标）

---

## 五、交互

- 点击左侧学科 → 右侧列表筛选
- 点击"复制 Skill"按钮 → 复制成功的提示（toast）
- Hover 效果克制

---

## 六、参考方向

- **优质插件市场的列表**——清晰的信息结构 + 精致的视觉
- **设计系统组件库的展示页**——分类清晰，每个组件有说明
- **Notion 的模板库**——卡片式但不花哨，信息层级清楚

---

## 七、技术要求

- 单文件 HTML
- 响应式
- "复制 Skill"功能用 Clipboard API 实现
- 先填入 10 个已有 Skill 的信息（和 Demo 一一对应）
- 保存到：`/Users/a1/Desktop/jingbo.xyz/skills.html`
