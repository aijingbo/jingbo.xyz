# 景礴 · Demo 详情页框架设计需求 Brief

> 页面类型：所有 Demo 详情页的通用外壳框架
> 已有示例参考：demos/ 目录下的 10 个 Demo

---

## 一、页面定位

每个 Demo 都有自己的详情页，是用户真正"体验展品"的地方。

所有 Demo 共享一个统一的**外壳框架**（导航 + 信息栏等），但内部内容根据呈现类型不同分为四种框架。

---

## 二、通用外壳（所有 Demo 共用）

### 顶部导航栏
- **固定在顶部**，毛玻璃半透明效果
- 滚动时轻微收缩/加深
- **左侧**：
  - ← 返回按钮（返回展品列表页）
  - 景礴 logo
- **中间**：Demo 标题（衬线字体）
- **右侧**：
  - 学科标签（小药丸形）
  - "下载 Skill 做同款"按钮（主按钮样式）

### 可选：底部信息条
- 部分框架有，部分没有
- 内容：Skill 名称 + 技术栈标签 + 相关链接

---

## 三、四种呈现框架

### 框架一：沉浸式全屏型

**适用**：3D 分子、DNA、太阳系、地球四季、晶体结构等空间结构类

**布局特点**：
- 全屏就是可视化画布，UI 元素极少
- 深色背景（深灰近黑，不是纯黑）
- 3D 内容"发光"，像博物馆展柜里的展品

**UI 元素**：
- 顶部导航（半透明毛玻璃，深色模式）
- 左下角浮动：播放/暂停按钮（圆形图标按钮）
- 右下角浮动：全屏按钮（圆形图标按钮）
- 可选：右侧图例面板（半透明）
- 底部半透明信息条（Skill 信息 + 技术栈）

**设计要点**：
- UI 元素尽量少且半透明，不抢内容的戏
- 控件用圆形图标按钮，半透明白色背景
- 文字用浅灰色
- 整体感觉：安静、沉浸、像在看一件展品

---

### 框架二：杂志讲解型

**适用**：几何证明、历史时间轴、傅里叶讲解、气候条纹等知识讲解类

**布局特点**：
- 左右分栏，像一篇杂志文章
- 左侧 40%：文字讲解
- 右侧 60%：可视化画面

**左侧文字区**：
- 大标题（衬线字体，醒目）
- 正文段落（行高 1.7，舒适阅读）
- 步骤导航（圆点 + 线条进度）
- 上一步 / 下一步按钮
- 整体排版像杂志内页

**右侧可视化区**：
- 有细边框，像杂志插图
- 随步骤变化而动态更新
- 可以有自己的控制按钮（播放/暂停等）

**设计要点**：
- 背景：暖米白（和首页统一）
- 图文比例协调，不要偏科
- 步骤之间的过渡要流畅
- 感觉：像在读一篇图文并茂的深度文章

---

### 框架三：交互工具型

**适用**：圆锥曲线、抛体运动、排序算法、色彩理论等参数调节类

**布局特点**：
- 上下分栏
- 上方 80%：可视化画布
- 下方 20%：控制面板

**画布区**：
- 占满宽度
- 背景为暖白或淡灰
- 是绝对主角

**控制面板**：
- 背景色：surface-muted（比背景深一点的暖灰色）
- 左侧：参数滑块组（每个滑块带数值显示）
- 右侧：功能按钮组（播放/重置/模式切换等）
- 控件精致，像精密仪器

**设计要点**：
- 滑块要有质感，不要用浏览器默认样式
- 按钮用文字+图标，圆角 6px
- 整体感觉像精密的科学仪器，不花哨
- 交互响应流畅，参数变化实时反馈
- 播放/暂停按钮友好易点

---

### 框架四：时空叙事型

**适用**：历史人物生平+路线、战役进程、丝绸之路等地图+时间类

**布局特点**：
- 左右分栏
- 左侧 70%：地图区域
- 右侧 30%：时间轴面板

**地图区域**：
- 占主体地位
- 用浅色底图，保持杂志感
- 标记点有动画效果
- 信息卡片精致（圆角 + 阴影）

**时间轴面板**：
- 竖线 + 圆点的时间轴样式（杂志感）
- 事件列表，点击切换
- 当前事件高亮
- 可以有年份标签

**交互**：
- 点击时间轴事件 → 地图平滑移动到对应位置 + 弹出信息卡片
- 点击地图标记 → 时间轴跳转到对应事件
- 播放按钮：自动按时间顺序播放

**设计要点**：
- 整体色调偏暖，地图用浅色底图
- 时间轴要有杂志感，不要工程化
- 信息卡片有质感
- 整体有叙事感，像在读一篇带地图的历史故事

---

## 四、设计规范

### 配色
- 浅色模式：暖米白底 + 深炭灰文字 + 赤陶色强调
- 深色模式（沉浸式）：深灰底 + 浅灰文字 + 内容发光
- 学科色仅用于小面积标记

### 字体
- 标题：Noto Serif SC（衬线）
- 正文：Noto Sans SC（无衬线）
- 数据/代码：JetBrains Mono

### 控件
- 按钮：圆角 6px
- 标签：药丸形
- 卡片：圆角 12px
- 图标按钮：圆形

---

## 五、技术要求

- 每个 Demo 是独立的单文件 HTML
- 引入公共设计系统 CSS：`/assets/css/design-system.css`
- 第三方库用 CDN
- 响应式（移动端自适应布局）
- 所有 Demo 统一顶部导航的样式和交互
