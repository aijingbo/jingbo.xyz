## 第二步：Skill 统计与映射

梳理 50 个 Demo 与 Skill 的对应关系，输出一份映射表。

### 梳理规则

- **Skill 是"能力"**：比如"3D 分子结构查看器"是一个 Skill，用户输入一个分子名称就能生成对应的可视化
- **Demo 是"展品"**：是 Skill 的一个具体实例，比如"水分子结构"、"DNA 双螺旋"都是 3D 分子结构 Skill 下的展品
- **有些 Demo 本身就是独立 Skill**：比如"排序算法可视化"，它的输入是算法类型和数据，输出是动画，本身就是一个完整的 Skill
- **有些 Demo 属于同一个 Skill 的不同变体**：比如"傅里叶级数"和"三角函数波形"都可以归到"数学函数可视化"这个大 Skill 下

### 输出文件

在 `/Users/a1/Desktop/jingbo.xyz/docs/04-Skill生成/` 下生成：

**文件名**：`Demo-Skill映射表.md`

内容结构：
1. **统计总览**：50 个 Demo → 归为多少个 Skill？按学科、按框架类型分别统计
2. **Skill 清单**：每个 Skill 的编号、名称、包含的 Demo 列表、学科、框架类型
3. **Demo 到 Skill 的映射表**：每个 Demo 对应哪个 Skill
4. **Skill 优先级建议**：哪些 Skill 是核心（P0），哪些是次级（P1）

### Skill 命名规范

- 格式：`S{三位数字}-{英文短名}`
- 按学科分组编号（S001-S0xx 数学，S1xx 物理，以此类推）
- 英文短名小写连字符

## 第三步：制作内部 Demo 总览页面

做一个内部使用的 Demo 画廊页面，定位是：
- **内部工具**，不是给用户看的
- **一目了然**，快速浏览所有 Demo 的状态
- **方便验收**，能快速跳转和检查

### 页面功能要求

1. **顶部统计栏**
   - 总 Demo 数、已完成数、有问题数、未完成数
   - 按框架类型分类统计
   - 按学科分类统计

2. **筛选和搜索**
   - 按框架类型筛选（沉浸式/杂志讲解/交互工具/时空叙事）
   - 按学科筛选
   - 按状态筛选（完好/有小问题/严重问题/未完成）
   - 关键词搜索

3. **Demo 卡片网格**
   - 每个 Demo 一张卡片
   - 卡片内容：编号、名称、学科标签、框架类型标签、状态标签（颜色区分）
   - 点击卡片跳转到对应 Demo
   - 卡片有缩略图区域（如果没有截图就放占位图标+框架类型标识）

4. **视图切换**
   - 网格视图（默认，适合浏览）
   - 列表视图（适合看详细状态）

5. **状态标注**（后续可以手动更新）
   - ✅ 完好：绿色
   - ⚠️ 有小问题：黄色
   - ❌ 严重问题：红色
   - 🔄 需重做：深红色
   - ⏳ 未开始：灰色

### 技术要求

- **纯单文件 HTML**：所有 CSS 和 JS 都内联在一个文件里，不依赖外部资源（除了设计系统的 CSS）
- **设计风格**：沿用赤陶暖调 + 暖米白底的科学杂志风，但可以做得更"工具向"一些，信息密度更高
- **响应式**：适配不同屏幕宽度
- **数据驱动**：Demo 列表数据用 JS 数组定义，方便后续增删改
- **引用设计系统 CSS**：`<link rel="stylesheet" href="assets/css/design-system.css">`
