# 统一设计系统规范

> **视觉 Thesis**："教科书的严谨遇上博物馆的精致——每一页都是一个可以触摸的知识展品。"

## 1. 色彩系统

### 1.1 基础中性色（全平台统一）

```css
--bg: #f8fafc;
--surface: #ffffff;
--surface-soft: #f1f5f9;
--text: #0f172a;
--muted: #475569;
--border: #e2e8f0;
--ring: rgba(14, 165, 233, 0.24);
```

### 1.2 学科强调色

| 学科 | 变量名 | 色值 | 用于 `--primary` |
|------|--------|------|-------------------|
| 数学 | `--accent-math` | `#0ea5e9` | 天蓝 |
| 物理 | `--accent-physics` | `#8b5cf6` | 紫罗兰 |
| 化学 | `--accent-chem` | `#f59e0b` | 琥珀 |
| 生物 | `--accent-bio` | `#10b981` | 翡翠绿 |

| 跨学科 | `--accent-cross` | `#ec4899` | 品红 |


## 2. 字体系统

两种字体最多（公式渲染器不计入）：

```css
--font-ui: 'Inter', 'PingFang SC', 'Microsoft YaHei', sans-serif;
--font-mono: 'JetBrains Mono', 'SF Mono', monospace;
```

- **UI 字体**：Inter（英文）+ PingFang SC（中文回退）
- **数学公式**：MathJax 或 KaTeX（CDN 加载）
- **代码/数据**：JetBrains Mono

## 3. 通用课件布局

所有 Demo 统一采用以下布局：

```
┌─────────────────────────────────────────────────────┐
│  顶部条 (.topbar)                                    │
│  学科标签 + 题目标题 + 答案卡                        │
├──────────────┬──────────────────────────────────────┤
│  左侧面板     │     右侧可视化区域                    │
│  (.sidebar)  │     (.canvas-area)                   │
│  width:420px │     flex: 1                          │
│              │                                      │
│  - 题面卡    │     Three.js / Canvas 2D             │
│  - 答案卡    │     可旋转/缩放/拖拽                   │
│  - 分步解析  │     参数滑块控制                      │
│  - 控制面板  │     提示气泡                          │
├──────────────┴──────────────────────────────────────┤
│  底部导航 (.nav-bar)                                 │
│  上一步 / 步骤指示点 / 下一步                        │
└─────────────────────────────────────────────────────┘
```

**移动端**（768px 以下）：flex-direction 变为 column-reverse，可视化区域在上（55%），面板在下（45%）。

## 5. 交互模式规范

| 交互类型 | 实现方式 | 适用 Demo |
|----------|----------|-----------|
| 步骤导航 | 上一步/下一步 + 步骤指示器 | 所有解题类 |
| 3D 旋转缩放 | Three.js OrbitControls | M1, P3, C1, C2, B1 |
| 参数滑块 | range input + 实时重绘 | M2, M3, P1, P2 |
| 分步高亮 | 步骤切换时高亮 3D/2D 元素 | M1, M2, C1, C2 |
| 镜头切换 | 步骤切换时移动相机 | M1, P3, B1 |
| 点击交互 | 点击元素显示详情 | B2, H1 |
| 时间轴 | 拖拽时间轴回放 | H1, X1 |
| 挑战模式 | 闯关答题 | P1 |

## 6. 运动效果（3 个有意运动）

每个 Demo 必须包含至少 2 个运动效果：

1. **步骤切换**：内容区 `fade-out + translate-y → fade-in`（0.28s ease）
2. **3D/2D 元素入场**：步骤切换时高亮元素从透明到不透明 + 轻微缩放（0.4s ease-out）
3. **滑块响应**：参数变化时场景实时重绘，无延迟

```css
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(12px); }
  to { opacity: 1; transform: translateY(0); }
}
.fade-in { animation: fadeInUp 0.28s ease; }
```
