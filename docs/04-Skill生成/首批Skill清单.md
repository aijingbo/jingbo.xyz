## 二、首批 50 个 P0 级方向（按学科分组）

### 筛选标准
1. **技术可行性高** — 有成熟 CDN 库，官方示例丰富，1 天内能出 Demo
2. **视觉震撼力强** — 打开即有"哇"的感觉，适合做招牌展品
3. **教学痛点明确** — 传统教学手段难以讲清，可视化后效果立竿见影
4. **科学杂志风适配** — 视觉质感高，适合赤陶暖调 + 暖米白底设计语言
