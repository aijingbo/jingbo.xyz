关于景礡之道

"景礡之道"是一个教育可视化个人网站，秉承"教科书的严谨遇上博物馆的精致"的设计理念。

每个 Demo 都是独立的交互式 HTML 文件，无需安装、即开即玩。每个 Demo 对应一个 Trae Skill，教育工作者下载 Skill 后可通过 Trae Agent 生成个性化课件。

技术栈：Three.js（3D）、Canvas 2D、KaTeX / MathJax（公式），纯前端实现，离线可用。
