# Skill Demo 提示词：波的干涉与衍射模拟

## 任务

创建一个单 HTML 文件的教育可视化 Demo，用于模拟双缝干涉、单缝衍射等波动光学现象。通过 Canvas 实时渲染波纹叠加，帮助学生理解波的干涉原理。

## 技术栈

- **Canvas 2D**（原生，像素级渲染）
- 纯 CSS 样式，单 HTML 文件
- 不需要外部库

## 功能要求

### 核心功能
1. **双缝干涉模拟**：
   - 两个点波源，可调频率、波长、间距
   - 实时渲染波纹叠加（颜色映射振幅）
   - 显示干涉条纹（亮纹/暗纹）
   - 可拖拽波源位置

2. **单缝衍射模拟**：
   - 单缝宽度可调
   - 显示衍射图样
   - 屏幕上显示光强分布曲线

3. **波源参数**：
   - 频率 f（0.5-5 Hz）
   - 波长 λ（20-100 px）
   - 波源间距 d（双缝模式）
   - 缝宽 a（单缝模式）
   - 波速 v

4. **可视化效果**：
   - 波纹用蓝-白-红色彩映射（蓝色=波谷，白色=平衡，红色=波峰）
   - 叠加区域亮度映射振幅大小
   - 干涉条纹在远场屏幕上显示
   - 光强分布曲线实时绘制

5. **控制功能**：
   - 模式切换：双缝干涉 / 单缝衍射
   - 播放/暂停
   - 显示/隐藏波纹
   - 显示/隐藏条纹
   - 显示/隐藏光强曲线

### 物理计算
- 波动方程：y(x,y,t) = A·sin(k·r - ω·t)
- 双源叠加：y_total = y₁ + y₂
- 光强：I = |y_total|²
- 干涉条件：d·sin(θ) = m·λ（亮纹）
- 实时计算并标注条纹间距

### UI 布局
- 顶部：模式切换标签页 + 参数控制栏
- 中部主体（70%）：Canvas 波纹模拟画布
- 右侧（30%）：
  - 实时数据面板（波长/频率/条纹间距）
  - 光强分布曲线（Canvas 绘制）
  - 物理公式显示
- 底部：播放控制

### 视觉风格
- 背景：黑色（#0a0a0a）
- 波纹色彩映射：蓝(#2563eb) → 白(#ffffff) → 红(#dc2626)
- 干涉条纹：黄白色高亮
- 光强曲线：青色（#06b6d4）线条
- 波源：绿色脉冲圆点（#22c55e）
- 缝：白色矩形
- 控制面板：深灰半透明背景（rgba(30,30,30,0.9)）
- 字体：系统无衬线字体

## 性能优化

1. 使用 ImageData 像素级操作渲染波纹
2. 降采样：每 2px 采样一次
3. requestAnimationFrame 驱动动画
4. 避免每帧创建新对象

## 质量要求

1. 波纹渲染流畅（至少 30fps）
2. 物理计算准确，干涉条纹位置正确
3. 参数调节时实时更新
4. 色彩映射平滑无色带
5. 中文注释，代码结构清晰
6. 单 HTML 文件，不超过 80KB
