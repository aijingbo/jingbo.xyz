# Skill Demo 提示词：中外对照交互式时间轴

## 任务

创建一个单 HTML 文件的教育可视化 Demo，使用 vis-timeline 实现中外历史事件对照时间轴。同一时间维度下并置展示中国与世界重大历史事件，支持缩放、筛选、点击查看详情。

## 技术栈

- **vis-timeline** (CDN): `https://cdn.jsdelivr.net/npm/vis-timeline@7/standalone/umd/vis-timeline-graph2d.min.js`
- **vis-timeline CSS**: `https://cdn.jsdelivr.net/npm/vis-timeline@7/styles/vis-timeline-graph2d.css`
- 纯 CSS 样式，单 HTML 文件

## 功能要求

### 核心功能
1. **双轨时间轴**：
   - 上轨：中国历史事件
   - 下轨：世界历史事件
   - 时间范围：公元前 3000 年 — 公元 2026 年
   - 事件按朝代/时代分组

2. **内置事件数据**（至少 40 个事件）：
   - 中国：夏朝建立、商朝、周朝、秦始皇统一、汉武帝、三国、唐宋元明清、鸦片战争、新中国成立等
   - 世界：古埃及、古希腊、罗马帝国、中世纪、文艺复兴、大航海、工业革命、一战二战、冷战等
   - 每个事件包含：时间、标题、简述、分类（政治/文化/科技/军事）

3. **交互功能**：
   - 鼠标滚轮缩放时间轴
   - 拖拽平移时间轴
   - 点击事件弹出详情卡片
   - 按分类筛选（政治/文化/科技/军事）
   - 按时代跳转（下拉菜单选择朝代/时代）

4. **视觉对比**：
   - 同一时间窗口内，中外事件上下对照
   - 相关事件用连线标注（如"郑和下西洋"与"哥伦布发现新大陆"）
   - 重大事件高亮显示

### 事件数据格式
```javascript
const events = [
  {
    id: 1,
    group: "中国",
    start: "0221",
    end: "0207",
    content: "秦始皇统一六国",
    title: "公元前221年，秦始皇统一六国，建立中国历史上第一个中央集权王朝",
    className: "politics",
    type: "range"
  },
  {
    id: 2,
    group: "世界",
    start: "0216",
    content: "第二次布匿战争",
    title: "公元前216年，坎尼会战，汉尼拔击败罗马军队",
    className: "military",
    type: "point"
  }
  // ... 更多事件
];
```

### UI 布局
- 顶部：标题栏 + 时代跳转下拉菜单 + 分类筛选标签
- 中部主体：vis-timeline 双轨时间轴
  - 左侧固定：分组标签（"中国" / "世界"）
  - 右侧可滚动：时间轴内容
- 底部：图例 + 操作提示
- 弹层：事件详情卡片（点击事件时弹出）

### 视觉风格
- 背景：浅色（#f8f9fa）
- 时间轴背景：白色
- 中国事件：红色系（政治=#dc2626, 文化=#ea580c, 科技=#ca8a04, 军事=#991b1b）
- 世界事件：蓝色系（政治=#2563eb, 文化=#0891b2, 科技=#7c3aed, 军事=#1e40af）
- 事件卡片：圆角矩形，hover 时上浮 + 阴影
- 详情弹层：毛玻璃效果卡片
- 字体：系统无衬线字体
- 时间轴刻度：浅灰色

## 质量要求

1. vis-timeline 缩放和平移流畅
2. 事件数据历史准确
3. 分类筛选实时生效
4. 详情卡片动画平滑（300ms）
5. 响应式布局，支持 1024px 以上屏幕
6. 中文 UI 和注释
7. 单 HTML 文件，事件数据内嵌，不超过 100KB
