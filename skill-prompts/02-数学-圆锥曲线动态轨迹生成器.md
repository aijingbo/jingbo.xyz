# Skill Demo 提示词：圆锥曲线动态轨迹生成器

## 任务

创建一个单 HTML 文件的教育可视化 Demo，用于动态展示圆锥曲线（椭圆、双曲线、抛物线）的轨迹生成过程。通过交互式参数调节，让学生直观理解圆锥曲线的定义和性质。

## 技术栈

- **JSXGraph** (CDN): `https://cdn.jsdelivr.net/npm/jsxgraph/distrib/jsxgraphcore.js`
- **JSXGraph CSS**: `https://cdn.jsdelivr.net/npm/jsxgraph/distrib/jsxgraph.css`
- **MathJax** (公式渲染): `https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js`
- 纯 CSS 样式，单 HTML 文件

## 功能要求

### 核心功能
1. **三种曲线模式**（标签页切换）：
   - **椭圆**：到两焦点距离之和为常数 2a
   - **双曲线**：到两焦点距离之差为常数 2a
   - **抛物线**：到焦点距离 = 到准线距离

2. **动态轨迹绘制**：
   - 动点沿曲线轨迹移动，实时绘制路径
   - 显示动点到焦点/准线的连线（距离标记）
   - 椭圆/双曲线：显示两条焦点连线，实时标注距离之和/差
   - 抛物线：显示到焦点和到准线的垂线段，标注等距

3. **参数交互**：
   - 椭圆：滑块调节半长轴 a、半短轴 b、焦点位置
   - 双曲线：滑块调节实轴 a、虚轴 b、焦点位置
   - 抛物线：滑块调节焦准距 p
   - 离心率 e 实时计算并显示
   - 参数变化时曲线平滑过渡

4. **辅助显示**：
   - 坐标轴和网格
   - 焦点、顶点、中心点标注
   - 渐近线（双曲线）
   - 准线（抛物线）
   - 标准方程实时显示（MathJax 渲染）

### UI 布局
- 左侧 65%：JSXGraph 画布
- 右侧 35%：
  - 顶部：曲线类型选择标签页
  - 中部：参数控制滑块面板
  - 下部：实时方程显示 + 性质说明
- 底部：播放/暂停轨迹动画按钮

### 视觉风格
- 背景：浅色（#f8f9fa）
- 画布背景：白色带浅灰网格
- 曲线：蓝色（#2563eb），粗 2.5px
- 焦点：红色圆点（#dc2626），半径 4px
- 准线：绿色虚线（#16a34a）
- 动点：橙色圆点（#ea580c），带拖尾效果
- 距离连线：半透明灰色
- 字体：系统无衬线字体

## 教学场景

教师课堂上投屏使用：
1. 切换曲线类型，展示三种圆锥曲线
2. 拖动滑块，展示参数变化对曲线形状的影响
3. 播放轨迹动画，展示曲线的生成过程
4. 学生课后自主探索参数空间

## 质量要求

1. 滑块拖动时曲线实时更新，无明显延迟
2. 轨迹动画 60fps 流畅
3. MathJax 公式正确渲染，随参数实时更新
4. 所有标注不重叠、不遮挡曲线
5. 支持画布缩放和平移（JSXGraph 内置）
6. 中文注释，代码结构清晰
7. 单 HTML 文件，不超过 80KB
