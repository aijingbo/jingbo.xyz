# Skill Demo 提示词：抛体运动与力的分解

## 任务

创建一个单 HTML 文件的教育可视化 Demo，用于模拟抛体运动（斜抛/平抛），实时展示运动轨迹、分速度矢量和力的分解。帮助学生理解运动的独立性原理。

## 技术栈

- **Canvas 2D**（原生，不依赖外部库）
- **Chart.js** (CDN): `https://cdn.jsdelivr.net/npm/chart.js` — 用于实时速度-时间图表
- 纯 CSS 样式，单 HTML 文件

## 功能要求

### 核心功能
1. **抛体运动模拟**：
   - 可调参数：初速度 v₀（5-50 m/s）、发射角度 θ（0-90°）、重力加速度 g（1-20 m/s²）
   - 实时绘制运动轨迹（带渐变色拖尾）
   - 显示最高点、落地点、射程标注

2. **矢量分解可视化**：
   - 运动过程中实时显示速度矢量（红色箭头）
   - 水平分速度矢量（蓝色箭头）
   - 竖直分速度矢量（绿色箭头）
   - 矢量随时间变化，水平分量恒定、竖直分量先减后增

3. **双视图对比**：
   - 主视图：运动轨迹 + 矢量
   - 副视图：vₓ-t 图和 vᵧ-t 图（Chart.js 实时更新）

4. **控制功能**：
   - 播放/暂停/重置
   - 速度倍率（0.25x / 0.5x / 1x / 2x）
   - 显示/隐藏矢量切换
   - 显示/隐藏轨迹切换
   - 对比模式：同时显示不同角度的轨迹对比

### 物理计算
- 使用标准运动学公式：
  - x(t) = v₀·cos(θ)·t
  - y(t) = v₀·sin(θ)·t - ½·g·t²
  - vₓ(t) = v₀·cos(θ)
  - vᵧ(t) = v₀·sin(θ) - g·t
- 实时显示：当前速度、高度、水平距离、飞行时间
- 理论值标注：最大高度 H、射程 R、飞行时间 T

### UI 布局
- 左侧 65%：Canvas 运动模拟画布
- 右侧 35%：
  - 顶部：参数控制面板（3个滑块 + 数值显示）
  - 中部：实时数据面板（速度/高度/距离/时间）
  - 下部：vₓ-t 和 vᵧ-t 双图表
- 底部：控制按钮栏

### 视觉风格
- 背景：深色画布（#1e293b），突出彩色轨迹
- 网格：半透明白色（rgba(255,255,255,0.1)）
- 轨迹：渐变色（黄→橙→红），带发光效果
- 速度矢量：红色（#ef4444）
- 水平分量：蓝色（#3b82f6）
- 竖直分量：绿色（#22c55e）
- 抛体：白色圆球，带阴影
- 地面：灰色实线
- 字体：系统无衬线字体

## 质量要求

1. Canvas 动画 60fps 流畅
2. 物理计算精确（至少小数点后 2 位）
3. 矢量箭头方向和长度准确
4. Chart.js 图表实时更新无卡顿
5. 滑块拖动时参数实时同步
6. 中文注释，代码结构清晰
7. 单 HTML 文件，不超过 80KB
