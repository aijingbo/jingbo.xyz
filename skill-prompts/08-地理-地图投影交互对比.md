# Skill Demo 提示词：地图投影交互对比

## 任务

创建一个单 HTML 文件的教育可视化 Demo，使用 D3.js 实现多种地图投影的交互式对比。帮助学生理解不同地图投影的变形特征，认识墨卡托投影对高纬度国家面积的夸大。

## 技术栈

- **D3.js v7** (CDN): `https://cdn.jsdelivr.net/npm/d3@7`
- **TopoJSON Client** (CDN): `https://cdn.jsdelivr.net/npm/topojson-client@3`
- 世界地图数据：从 `https://cdn.jsdelivr.net/npm/world-atlas@2/countries-110m.json` 加载
- 纯 CSS 样式，单 HTML 文件

## 功能要求

### 核心功能
1. **多种投影对比**（至少 6 种）：
   - Mercator（墨卡托投影 — 等角，高纬变形大）
   - Equirectangular（等距圆柱投影 — 简单等距）
   - Equal Earth（等积地球投影 — 等积，美观）
   - Orthographic（正射投影 — 地球仪视角）
   - Mollweide（摩尔威德投影 — 等积椭圆）
   - Robinson（罗宾逊投影 — 折中伪圆柱）

2. **交互功能**：
   - 投影切换（点击按钮或标签页）
   - 正射投影可拖拽旋转（模拟地球仪转动）
   - 鼠标悬停国家：高亮 + 显示国家名
   - 点击国家：显示详细信息（名称、面积、所在大洲）

3. **变形可视化**：
   - 切换显示 Tissot 指示线（变形圆），直观展示角度和面积变形
   - 面积对比模式：选择一个国家，在不同投影下并排显示，展示面积差异
   - 格陵兰 vs 非洲面积对比演示（墨卡托下看起来差不多，实际非洲 14 倍于格陵兰）

4. **信息面板**：
   - 当前投影名称和性质（等角/等积/等距/任意）
   - 投影变形特征说明
   - 优缺点和适用场景
   - 国家中选中的国家信息

### UI 布局
- 左侧 70%：D3 SVG 地图画布
- 右侧 30%：
  - 顶部：投影选择按钮组（6 个按钮）
  - 中部：投影性质说明卡片
  - 下部：选中国家信息 / 面积对比演示
- 底部：操作提示 + Tissot 指示线开关

### 视觉风格
- 背景：深色（#1a1a2e）
- 地图区域：海洋为深蓝（#16213e），陆地为暖灰（#e2e8f0）
- 国家边框：深灰细线（#475569, 0.5px）
- 悬停高亮：黄色边框（#fbbf24, 1.5px）+ 半透明填充
- 选中国家：橙色填充（rgba(251, 146, 60, 0.5)）
- Tissot 圆：半透明红色（rgba(239, 68, 68, 0.4)）
- 按钮：深色卡片，选中时蓝色高亮
- 字体：系统无衬线字体

## D3 投影示例代码

```javascript
const projections = {
  mercator: d3.geoMercator(),
  equirectangular: d3.geoEquirectangular(),
  equalEarth: d3.geoEqualEarth(),
  orthographic: d3.geoOrthographic(),
  mollweide: d3.geoMollweide(),
  robinson: d3.geoRobinson()
};

// 加载世界地图
d3.json("https://cdn.jsdelivr.net/npm/world-atlas@2/countries-110m.json")
  .then(world => {
    const countries = topojson.feature(world, world.objects.countries);
    // 渲染地图...
  });
```

## 质量要求

1. D3 地图渲染流畅，投影切换有过渡动画（500ms）
2. 正射投影拖拽旋转流畅
3. Tissot 指示线正确显示变形
4. 国家悬停和点击交互准确
5. 响应式布局
6. 中文 UI 和注释
7. 单 HTML 文件，不超过 80KB
