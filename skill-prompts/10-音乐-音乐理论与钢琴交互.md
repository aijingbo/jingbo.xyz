# Skill Demo 提示词：音乐理论与钢琴交互可视化

## 任务

创建一个单 HTML 文件的教育可视化 Demo，使用 Tone.js 实现交互式钢琴键盘，结合音乐理论可视化（音阶、和弦、五度圈），提供听觉与视觉双重反馈。

## 技术栈

- **Tone.js** (CDN): `https://cdn.jsdelivr.net/npm/tone@14/build/Tone.js`
- **Canvas 2D**（原生，用于五度圈和波形绘制）
- 纯 CSS 样式，单 HTML 文件

## 功能要求

### 核心功能
1. **交互式钢琴键盘**：
   - 3 个八度的钢琴键盘（C3-C6）
   - 鼠标点击/键盘按键弹奏
   - 键盘映射：A=C, W=C#, S=D, E=D#, D=E, F=F, T=F#, G=G, Y=G#, H=A, U=A#, J=B, K=C...
   - 弹奏时琴键高亮 + 发声
   - 可选音色：钢琴、合成器、风琴

2. **音阶可视化**：
   - 选择调式（大调/小调/五声/蓝调）
   - 选择主音（12 个音）
   - 键盘上高亮显示该音阶的所有音符
   - 播放音阶（上行/下行）

3. **和弦可视化**：
   - 选择和弦类型（大三和弦/小三和弦/增三/减三/大七/小七/属七/挂四）
   - 选择根音
   - 键盘上高亮和弦音符
   - 播放和弦（同时发声/琶音模式）
   - 显示和弦标记（如 Cmaj7, Dm7）

4. **五度圈交互**：
   - Canvas 绘制五度圈（12 个调性环形排列）
   - 点击调性 → 键盘高亮该调音阶
   - 显示调号（升号/降号数量）
   - 大调/小调切换（相对小调标注）

5. **实时波形显示**：
   - 弹奏时显示实时波形图
   - 可切换波形/频谱模式

### UI 布局
- 顶部：标题 + 音色选择 + 输出音量
- 左侧 40%：
  - 五度圈 Canvas（上部）
  - 实时波形 Canvas（下部）
- 右侧 60%：
  - 音阶/和弦控制面板（上部）
  - 钢琴键盘（下部，全宽）
- 底部：操作提示 + 键盘映射图

### 视觉风格
- 背景：深色渐变（#1a1a2e → #16213e）
- 白键：白色到浅灰渐变（#f8fafc → #e2e8f0）
- 黑键：深色（#1e293b → #0f172a）
- 按下高亮：蓝色发光（#3b82f6, box-shadow）
- 音阶高亮：绿色（#22c55e, 半透明）
- 和弦高亮：紫色（#a855f7, 半透明）
- 根音标记：红色圆点（#ef4444）
- 五度圈：彩色弧段，每个调性不同颜色
- 波形：青色（#06b6d4）线条
- 控制面板：毛玻璃效果
- 字体：系统无衬线字体

## 质量要求

1. Tone.js 音频播放无延迟
2. 钢琴键盘响应迅速，视觉高亮与音频同步
3. 五度圈交互准确
4. 音阶/和弦高亮位置正确
5. 波形实时绘制流畅（60fps）
6. 键盘映射正确（QWERTY → 钢琴键）
7. 中文 UI 和注释
8. 单 HTML 文件，不超过 80KB
