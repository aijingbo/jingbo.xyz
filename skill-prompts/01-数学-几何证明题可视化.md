# Skill Demo 提示词：几何证明题可视化

## 任务

创建一个单 HTML 文件的教育可视化 Demo，用于中学几何证明题的交互式可视化讲解。使用 JSXGraph 库实现动态几何作图，支持步骤动画回放。

## 技术栈

- **JSXGraph** (CDN): `https://cdn.jsdelivr.net/npm/jsxgraph/distrib/jsxgraphcore.js`
- **JSXGraph CSS**: `https://cdn.jsdelivr.net/npm/jsxgraph/distrib/jsxgraph.css`
- **MathJax** (公式渲染): `https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js`
- **纯 CSS** 做样式，不使用任何 UI 框架
- 单 HTML 文件，浏览器打开即可运行

## 功能要求

### 核心功能
1. **经典题型展示**：内置 3-5 道经典几何证明题，例如：
   - 全等三角形证明（SSS/SAS/ASA/AAS）
   - 勾股定理的面积证明
   - 三角形中线交于一点（重心定理）
   - 圆周角定理
   - 相似三角形判定

2. **步骤化动画**：
   - 每道题分为 4-8 个作图步骤
   - 每步显示：作图动作（如"作辅助线"、"标记等角"）+ 对应证明文字
   - 支持"上一步/下一步/自动播放"控制
   - 辅助线用虚线，已知条件用实线，结论用高亮色

3. **交互探索**：
   - 顶点可拖拽，图形实时更新
   - 拖拽后角度/长度数值实时显示
   - 证明结论在图形变化时仍然成立（动态验证）

### UI 布局
- 左侧 60%：JSXGraph 画布
- 右侧 40%：题目描述 + 证明步骤面板 + 控制按钮
- 顶部：题目选择器（下拉菜单或标签页）
- 底部：步骤控制条（上一步/播放/下一步/进度条）

### 视觉风格
- 背景：浅色（#f8f9fa）
- 画布背景：白色
- 已知线段：深蓝色（#2563eb），粗 2px
- 辅助线：灰色虚线（#94a3b8），粗 1.5px
- 结论高亮：红色（#dc2626），粗 2.5px
- 等长标记：绿色弧线
- 等角标记：橙色弧线
- 字体：系统无衬线字体

## AI 驱动范式（未来 Skill 方向）

这个 Demo 展示的范式是：教师输入题目文字描述 → AI 解析为几何元素 → 生成 JSXGraph 构造脚本 → 前端渲染并逐步动画演示。本 Demo 中使用预设题目数据来模拟 AI 输出。

## 预设数据格式示例

```javascript
const problems = [
  {
    title: "全等三角形证明（SAS）",
    description: "已知：AB = DE，∠B = ∠E，BC = EF。求证：△ABC ≅ △DEF",
    steps: [
      {
        action: "绘制三角形 ABC",
        script: "A = board.create('point', [0, 0]); B = board.create('point', [4, 0]); C = board.create('point', [2, 3]); ...",
        proof: "作三角形 ABC，标记顶点"
      },
      // ... 更多步骤
    ]
  }
];
```

## 质量要求

1. 代码结构清晰，注释完整（中文注释）
2. 响应式布局，至少支持 1024px 以上屏幕
3. 所有按钮和控件都有 hover 效果
4. 动画过渡平滑（300ms ease）
5. MathJax 正确渲染数学公式
6. 拖拽顶点时图形无闪烁
7. 单 HTML 文件大小不超过 100KB
