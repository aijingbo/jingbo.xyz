# Skill Demo 提示词：排序算法可视化

## 任务

创建一个单 HTML 文件的教育可视化 Demo，使用 Canvas 动态可视化多种排序算法的执行过程。支持算法切换、速度调节、步进控制，帮助学生直观理解算法工作原理和性能差异。

## 技术栈

- **Canvas 2D**（原生，不依赖外部库）
- 纯 CSS 样式，单 HTML 文件

## 功能要求

### 核心功能
1. **支持 6 种排序算法**：
   - 冒泡排序 (Bubble Sort)
   - 选择排序 (Selection Sort)
   - 插入排序 (Insertion Sort)
   - 快速排序 (Quick Sort)
   - 归并排序 (Merge Sort)
   - 堆排序 (Heap Sort)

2. **可视化元素**：
   - 柱状图表示数组元素，高度对应数值大小
   - 颜色编码：
     - 默认：蓝色（#3b82f6）
     - 正在比较：黄色（#fbbf24）
     - 正在交换：红色（#ef4444）
     - 已排序：绿色（#22c55e）
     - 当前指针位置：橙色（#f97316）

3. **控制功能**：
   - 算法选择（标签页或下拉菜单）
   - 数组大小调节（10-100 个元素）
   - 动画速度调节（1-100 ms/步）
   - 播放/暂停/单步/重置
   - 随机生成新数组
   - 自定义输入数组（逗号分隔）

4. **数据面板**：
   - 实时统计：比较次数、交换次数、已用时间
   - 算法复杂度信息（最好/平均/最坏时间复杂度）
   - 算法说明文字
   - 当前执行步骤描述（如"比较 arr[3] 和 arr[4]"）

5. **对比模式**：
   - 同时运行两种算法，并排显示
   - 比较相同输入下的执行步骤数

### 算法实现规范

每个算法生成一个步骤序列（generator 模式），每步记录操作类型和涉及的索引：

```javascript
function* bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - i - 1; j++) {
      yield { type: 'compare', indices: [j, j + 1] };
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
        yield { type: 'swap', indices: [j, j + 1], array: [...arr] };
      }
    }
    yield { type: 'sorted', index: n - i - 1 };
  }
  yield { type: 'sorted', index: 0 };
}
```

### UI 布局
- 顶部：标题 + 算法选择标签页
- 中部主体（55%）：Canvas 柱状图可视化
- 右侧（25%）：
  - 参数控制（数组大小/速度滑块）
  - 实时统计面板
  - 算法复杂度信息
- 底部（20%）：控制按钮栏 + 当前步骤描述

### 视觉风格
- 背景：深色（#0f172a）
- Canvas 背景：略深（#1e293b）
- 柱状图默认色：蓝色渐变（#3b82f6）
- 比较中：黄色（#fbbf24）
- 交换中：红色（#ef4444）
- 已排序：绿色（#22c55e）
- 指针标记：橙色三角箭头（#f97316）
- 控制面板：深色卡片，圆角
- 按钮：现代扁平风格，hover 高亮
- 字体：等宽字体用于数字显示，无衬线用于其他

3. 所有控制功能正常工作
4. 数组大小和速度调节实时生效

6. 中文注释和 UI 文案
